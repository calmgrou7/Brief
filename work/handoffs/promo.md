### 1편. "Stay B는 이런 곳" (메시지 ①정보 + ②오프라인) — 20초
| 시간 | 화면 | 자막(EN / KO .srt) |
|---|---|---|
| 0~2초 | 공항 도착장 또는 캐리어 클로즈업 | `New to Busan?` / `부산이 처음인가요?` |
| 2~7초 | 휴대폰 화면: 홈페이지 첫 화면에서 단계 버튼 누르기(시안 화면 녹화) | `Pick your stage. Get simple guides.` / `내 단계를 고르면 쉬운 정보가 나와요.` |
| 7~13초 | 웰컴 키트·멤버십 카드 목업, 모임 장면(뒷모습·손) | `And real help in Busan.` / `그리고 부산에서 직접 받는 도움.` |
| 13~17초 | 아이콘 3개: 설명회 · 첫 주 지원 · 모임 | `Info sessions · First-week help · Meetups` / `설명회 · 첫 주 지원 · 모임` |
| 17~20초 | 엔드카드 | `Your first place to ask in Busan.` / `부산에서 제일 먼저 물어볼 곳.` |
- 필요한 촬영 소스: 캐리어·공항 B롤(무료 스톡 가능), 홈페이지 시안 화면 녹화(`portfolio-site/stay-b/` v2 제작 후), 웰컴 키트·카드 목업 이미지(Heritage Studio B), 모임 B롤(얼굴 없이)
- 소스 없을 때: 단색 배경 + 텍스트 애니메이션 + 아이콘

### 2편. "외국인등록, 이것부터" (메시지 ①정보) — 25초
| 시간 | 화면 | 자막(EN / KO .srt) |
|---|---|---|
| 0~2초 | 서류 더미 앞에서 고민하는 손 | `Just arrived? Do this first.` / `막 도착했나요? 이것부터.` |
| 2~18초 | 체크리스트가 한 줄씩 체크되는 모션(정보 카드 2-1 "정착 중" 내용 그대로, 기간·서류 수치는 감수 전이면 `to be confirmed` 표기) | 체크리스트 항목(기획안 v2 4절 단계 2 카드 문구 사용) |

### 3편. "알바 시작 전에" (메시지 ③안심) — 20초
| 시간 | 화면 | 자막(EN / KO .srt) |
|---|---|---|
| 0~3초 | 식당 앞 "아르바이트 구함" 느낌의 장면(실제 상호 안 보이게) | `"Start tomorrow!" Wait.` / `"내일부터 나와요!" 잠깐만요.` |
| 3~10초 | 친구 메시지 화면 목업: `You don't need permission` | `Your friend says no permission needed. True?` / `친구는 허가 필요 없대요. 정말일까요?` |

- **스스로 정한 가정**: 영어 기본 자막(네팔 학생이 한국어보다 영어가 편하다는 기획안 v2 2절 근거), 1편을 먼저 제작(브랜드 소개가 커뮤니티 공지 1주차와 짝), 2·3편은 행정사 감수 전까지 내부 초안
- **대표 결정이 필요한 것**: 없음(편집 단계). 게시 시점은 공개 여부 결정 후
- **편집 후 순서**: 영상 편집자 → 검토자(법적 경계·저작권 음원 확인) → 비서 보고 포함
