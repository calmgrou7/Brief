## 1. 무드

**한 줄:** 부산에 먼저 온 선배가 건네는 정리 노트, 그리고 그 노트 끝에 적힌 "여기서 만나자".

| 느껴야 할 것 (3단어) | 이렇게 표현 |
|---|---|
| **따뜻함** Warm | 크림색 종이 바탕, 햇살 노랑·흙빛(clay) 포인트, 오프라인 섹션은 엽서 질감 |
| **안심** Reassured | 깊은 바다색(sea) 글자·버튼, 넉넉한 여백, 정돈된 정보 카드, 경고색 없음 |
| **친구 같은 선배** Friendly | 왼쪽 정렬 중심, 짧은 문장, 손글씨 메모(아주 조금), 사람 대신 생활 사물 그림 |

**피할 것:** 관공서·법률사무소(남색+금색, 세리프 제목, 인장·방패·저울 아이콘), B2B 랜딩(큰 숫자·대시보드 그림), 광고 전단(형광색, 느낌표, 빽빽한 배지), AI 템플릿(보라 그라디언트, 이모지 섹션 머리, 전부 가운데 정렬, 모든 상자에 같은 그림자).

**시각적 서명 = "노선(route) 선"**
부산 지하철·페리 노선도처럼 **점선 + 정거장 점**이 페이지 곳곳에서 온라인(정보)과 오프라인(만남)을 잇는다. 섹션 사이를 건너갈 때는 광안대교처럼 **완만한 아치**로 넘어간다. 첫 화면 연결 그림 → `connect` 3단계 → 정보 허브의 "직접 받을 수 있는 도움" 줄 → `offline` 흐름 그림에서 같은 선을 반복한다.

**두 질감 규칙 (온라인 ↔ 오프라인)**
| | 온라인 = 노트 | 오프라인 = 엽서·티켓 |
|---|---|---|
| 바탕 | `--paper` + 아주 옅은 24px 모눈 | `--warm-tint` 전체 폭 띠 |
| 카드 | 흰 면, 1px 선, 모서리 12px, **그림자 없음** | 따뜻한 흰 면, 모서리 20px, **이 섹션에만 그림자** |
| 색 역할 | `--sea` | `--clay` 글자 + `--sun` 포인트 |
| 장식 | 카드 번호(1-1), 체크 상자 | 단계 라벨을 티켓 꼬리표처럼, "Planned" 도장 배지 |

- 연결 그림: 왼쪽 칸 = `--sea-tint` 바탕 노트 모양(작은 줄 3개 아이콘), 오른쪽 칸 = `--warm-tint` 바탕 엽서 모양(핀 아이콘). 두 칸을 2px 점선(`--sea` → `--clay`로 바뀌는 두 반쪽) + 가운데 정거장 점 + Gaegu `connected` 메모로 잇는다. 각 칸 글씨는 큰 줄 15px 600 + 작은 줄 14px.
- **단계 버튼 = 페이지에서 가장 누르고 싶은 것.** 흰 면, 1.5px `--line-strong`, `--r-md`, 왼쪽 정렬. 위: 정거장 번호 원(24px, `--sea` 테두리, 숫자) + 아이콘(가방/열쇠/책·컵/달력). 가운데: 큰 글씨 17–18px 700. 아래: 작은 설명 14px `--ink-muted` (최대 2줄, 넘치면 말줄임 금지 → 버튼 높이 늘림). 오른쪽 아래 화살표 16px.

- 위계: 1 H1 2 단계 버튼 3 연결 그림 4 서브카피 5 질문 링크 6 신뢰 한 줄.

### 3. 이렇게 연결돼요 `connect`
- 모바일: 세로 노선. 왼쪽에 세로 점선, 정거장 원 3개(40px, 아이콘 들어감) 오른쪽에 제목(h3)+한 줄. 정거장 1 `--sea`(노트 아이콘), 2 `--clay`(핀+컵 아이콘), 3 `--sea` 테두리 + `--sun` 안 채움(말풍선 아이콘).

### 4. 정보 허브 `guides` (14장 밀도 처리)

- **정보 카드 (접힌 상태, 모바일):**
  ```

  │ 1-1                 ☑ Checklist │  14px 번호(ink-muted) · 배지
  ```

## 5. 이미지 방향 (사진 없음 전제)

### 5-1. 인라인 SVG 일러스트 스타일
- **선:** 2px `--ink`(다크 모드에서는 `--ink` 토큰 그대로 바뀜), 둥근 끝·둥근 모서리.
- **면:** 토큰 색 3개만 평면 채움 — `--sea-tint`, `--warm-tint`, `--sun`. 그라디언트·그림자·질감 이미지 없음.
- **모티프(은은하게):** 광안대교 아치, 항구 크레인, 언덕 마을의 층층 작은 집(감천 느낌의 네모 집, 창문 점), 물결 두 줄, 페리, 갈매기 한두 마리(작게). 해·달은 `--sun` 원.
- **사람 금지.** 특정 국적 학생 연출 금지. 장면은 사물로: 여권, 교통카드, 유심, 열쇠, 캐리어, 웰컴 키트 상자, 멤버십 카드, 지도, 달력, 학사모, 노트.
- **크기·위치:** 첫 화면 스카이라인 띠(모바일 높이 96px, 데스크톱 오른쪽 큰 그림), `offline` 위 지붕선, `final-cta` 메아리 띠, `off-kit` 이미지 자리, 장면 카드 사물(56px). 그 외에는 그림을 넣지 않는다.
- 장식 SVG는 `aria-hidden="true"`. 뜻이 있는 그림(연결 그림)은 `role="img"` + `aria-label`(EN/KO 전환).
- 무게: SVG 전체 합 30KB 이하, 경로 단순하게.

### 5-2. 아이콘
- 24px 격자, 선 1.75px, `currentColor`, 둥근 끝. **직접 그린 인라인 SVG**가 기본.
- 시간이 부족하면 **Lucide(ISC 라이선스)**만 허용, 인라인으로 붙이고 파일 상단에 `<!-- Icons: Lucide, ISC License -->` 주석. 그 외 아이콘 세트·폰트 아이콘·이모지 사용 금지.
- 필요한 아이콘: 가방, 열쇠(집), 책+컵, 달력, 노트(온라인), 핀(만남), 말풍선(연결), 체크, 체크 상자, 시계, 화살표, 펼침, 닫기, 메뉴, 정보 원, 비행기, 펜·문서, 전화 말풍선, 여러 말풍선, 유심, 학사모.

### 5-3. 사진 자리표시 규칙
- 사진은 **받으면 넣는 구조**(기획안 6절 8번). 받기 전에는 아래 자리 상자를 쓰되, 일러스트로 충분한 곳(첫 화면·final-cta)은 자리 상자를 띄우지 않는다. 자리 상자는 `off-kit` 한 곳만 화면에 보인다.
- 자리 상자: 비율 고정(`aspect-ratio: 4/3`, 데스크톱 첫 화면용은 `5/4`), `--r-lg`, 1.5px 점선 `--ph-line`, 바탕 `--paper-2`, 가운데 사물 SVG + `[자리표시: …]` 칩. `role="img"` + `aria-label="Image placeholder: …"`.
- 실제 사진: WebP, `loading="lazy"`(첫 화면 제외), `width/height` 지정, `object-fit: cover`, `--r-lg`, 필터·오버레이 없음. 얼굴 없는 사진 또는 본인 동의 받은 것만. 스톡·생성 사진 금지.

## 7. 접근성 점검표
- [ ] 글자 대비 4.5:1 이상(2-1 표의 계산값), 큰 글씨·아이콘 3:1 이상. `--sun`에는 `--ink`만 올린다. `--sea-tint` 위 작은 글자는 `--sea-strong`.
- [ ] 터치 영역 44×44px 이상(칩·닫기·텍스트 링크 포함, 필요하면 padding으로). 단계 버튼 84px, 고정 바 버튼 48px.
- [ ] 포커스 링 3px `--focus`, offset 3px. 푸터·토스트 위는 다크 값. 절대 `outline: none` 단독 금지.
- [ ] 색만으로 뜻을 전하지 않는다: 선택 탭 = 색 + 번호 채움, 오류 = 색 + 아이콘 + 문장, 체크리스트 = 배지 글자.
- [ ] 본문 17px, 최소 14px. 줄 길이 최대 70ch.
- [ ] `prefers-reduced-motion` 존중. 자동 재생·자동 넘김 없음.
- [ ] 장식 SVG `aria-hidden`, 의미 있는 그림 `role="img"`+이름. 언어 전환 시 aria-label도 전환.
- [ ] 한국어 고정 문구 `lang="ko"`, 네팔어 버튼 `lang="ne"`.
- [ ] 360 / 400 / 768 / 1280px 가로 넘침 0.

## 8. 디자이너가 스스로 정한 것 (인계 메모에도 기록)
1. 색 방향: v1 남색+주황 → **바다 청록(sea) + 햇살 노랑(sun) + 흙빛(clay) on 크림 종이**. 관공서 느낌을 빼고 부산 바다·언덕 마을의 따뜻함으로.
2. 글꼴: Bricolage Grotesque(제목) + Figtree(본문) + Noto Sans KR + Noto Sans Devanagari(지금은 `नेपाली` 글자만) + Gaegu(손글씨 메모 3곳, 글자 한정 로드).
3. 시각적 서명은 "노선 점선 + 정거장 점 + 대교 아치".
4. 푸터 브릿지노드 표기는 텍스트만(로고 이미지 미사용). 기획안 4-12와 다름 → 실장 지시 우선.
5. WhatsApp·Viber는 이름 텍스트만, 로고·브랜드색 미사용(상표).
6. 정보 허브 모바일 탭은 섹션 안에서 고정(sticky) — 카드 14장을 단계별로 나눠 보여 주는 핵심 장치.
7. 사진 자리 상자는 `off-kit` 한 곳만 화면에 보이게, 나머지는 일러스트로 완성.
8. Stay B 심볼(문 모양 + 대교 아치 + 물결)은 **제안**. 이름·브랜드는 대표 결정 사항이라 확정 전까지 시안용.
