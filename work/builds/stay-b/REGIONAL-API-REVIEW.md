# 스테이B 부산·경남 — 홈페이지와 공공 API 검수

검수일 2026년 11월 14일. 학생은 입국 전에도 영어로 접근할 수 있고, 한국에 도착하면 한국어 주소를 지도나 학교에 그대로 보여줄 수 있게 한다. 첫 화면은 네 단계로 나눈 학생 여정을 유지한다. 지역 생활정보는 학교와 기관을 찾는 용도이고, 개별 허가나 장학금 자격을 판정하는 기능은 없다.

## 원본과 적용 경로

- 공개된 학생 메인, 협력기관 페이지, 공통 자산 10개의 내용을 실제 배포 소스와 대조했다. 수정 대상은 calmgrou7/Brief 저장소의 `portfolio-site/stay-b/`다. Render가 참조하는 브랜치는 `ccr-43ae7ad4-yf895e`다.
- 클로드가 남긴 사업계획서 학생용 발췌, 협업 제안서 텍스트, v2 홈페이지 기획, 제작 인계 메모를 대조했다. 학생용 4단계 가이드 15개, 현장 지원 7개, 협력기관의 별도 페이지와 문의 동선을 유지했다.
- 새 지역 안내는 학생 페이지의 `#local-desk`에 놓았다. 헤더·모바일 메뉴·협력기관 페이지에서 들어간다. 영어가 첫 방문 기본값이며 한국어 전환과 선택 기억을 지원한다. 네팔어는 준비 중이다. 정착, 건강보험, 체류 안내에서 불확실한 서류·수수료·자격 문구 일부를 공식 원문 확인으로 교체했다.

## 코드와 갱신

저장소 루트에서 아래 명령을 실행한다. 외부 패키지 설치가 필요 없다. 변경된 스냅숏을 사이트와 함께 배포하면 방문자는 공공기관 서버에 연결하지 않아도 검색할 수 있다.

```sh
python3 work/builds/stay-b/sync_campuses.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory portfolio-site
```

기본 경로는 포털의 공개 JSON 다운로드 기능이다. 기준 데이터와 필드 목록을 읽은 뒤 전체 페이지를 확인한다. HTTP 또는 스키마 오류, 누락된 학교가 있으면 이전 자료를 보존한다. 기관 홈페이지는 원자료가 제공하는 대학 공식 도메인만 연결한다.

인증키를 받은 환경은 `DATA_GO_KR_SERVICE_KEY`에 **디코딩된 키**를 서버 환경변수로 두고 `--source api`로 같은 결과를 갱신할 수 있다. 공식 표준 API는 `https://api.data.go.kr/openapi/tn_pubr_public_univ_info_api`이며 `CTPV_NM`으로 두 시도를 조회한다. 무인증 표준 API 요청은 HTTP 400이었다. 승인 키를 사용한 REST 응답은 아직 미검증이다. 다운로드용 JSON 경로는 포털의 파일 배포 인터페이스에 의존한다. 양 경로의 실패 시 운영 데이터를 빈 목록으로 덮어쓰지 않는다. 정기 실행은 설치되어 있지 않다.

문의는 기존 시안의 입력 검증·데모 완료 흐름이다. 실제 송신과 운영기관의 참가 확정은 별도다. 이번 외부자료는 관광객 개인화나 동의 없는 위치정보 수집에 쓰이지 않는다.
