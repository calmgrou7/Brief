# BRIDGENODE 브랜드

- 로고: 다리(교각 2개 + 아치) 마크 + 넓은 자간의 굵은 대문자 워드마크 `BRIDGENODE`
- 메인 컬러: 오렌지레드 `#FF4410` (마크), 잉크 `#161616` (워드마크)
- 파일
  - `bridgenode-mark.svg`: 마크만 (도형, 파비콘·아이콘용)
  - `bridgenode-logo.svg`: 마크 + 워드마크 (워드마크는 Montserrat 700 근사치)
- 주의: 대표가 채팅으로 보낸 원본 이미지를 보고 다시 그린 근사 벡터다. 원본 파일(AI/SVG/PNG)을 받으면 이 폴더에 넣고 교체한다.
- 어두운 배경에서는 워드마크를 흰색(`#FFFFFF`)으로, 마크 색은 그대로.
