# BRIDGENODE 브랜드

- 로고: 다리(교각 2개 + 아치) 마크 + 넓은 자간의 굵은 대문자 워드마크 `BRIDGENODE`
- 메인 컬러: 오렌지레드 `#FF4410`(마크), 잉크 `#161616`(워드마크)

## 파일 (2026-11-14 대표 원본 반영)
- `bridgenode-logo-source.webp`: 대표가 준 원본(2000×667, 투명 배경). **기준 파일**
- `bridgenode-logo.png`: 원본에서 여백만 잘라낸 고해상도(1822×218, 투명)
- `bridgenode-logo-600.png`: 웹용 축소본(600×72, 투명)
- `bridgenode-mark.png`, `bridgenode-mark-128.png`: 마크만(파비콘·아이콘용)
- `bridgenode-logo.svg`, `bridgenode-mark.svg`: 원본 받기 전 실장이 다시 그린 근사 벡터. 원본과 글자체가 다르므로 **쓰지 않는다**(벡터가 꼭 필요할 때만 참고)

## 쓰는 법
- 밝은 배경: 그대로 사용
- 어두운 배경: 워드마크가 검정이라 보이지 않으므로 흰색 판(라운드) 위에 올려 쓴다. 마크만 쓸 때는 그대로 사용 가능
