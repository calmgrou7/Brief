# upbit 프로젝트

개인 PAPER 검증 워크벤치입니다. 거래소 공식 서비스나 제휴 제품이 아닙니다.

Brief PR #3 설계를 기반으로 만든 **실행 가능한 초기 수직 슬라이스**입니다.
전체 PRD 완료/실시간 자동매매/수익성 검증을 뜻하지 않습니다. Lighter paperlab 및 채움 컨설팅 앱과 별개입니다.

## 실행

Python 3.12+, uv, Node.js(정적 JS 문법 검사)에 대해:

```sh
cd aegis-trade-ai
make install
make lint test build
make run
# 내 컴퓨터 브라우저에서 http://127.0.0.1:8765
```

단일 프로세스/1 worker만 허용합니다. SQLite 파일 잠금으로 중복 인스턴스를 거절합니다.
기본 `aegis-demo.sqlite3`에 모드·포지션·리스크 상태 및 감사 이벤트가 저장됩니다.
`AEGIS_DB`로 별도 로컬 DB 경로를 정할 수 있습니다. `TRADING_MODE`는 PAPER만 허용합니다.

## 화면에서 해볼 일

1. **DEMO** 표시를 확인합니다. 차트는 재현 가능한 합성 캔들이며 실시간/과거 거래소 데이터가 아닙니다.
2. 손절 기준가격을 입력해 모의 매수를 제안합니다. 즉시 체결하지 않고 **다음 봉 시가**를 기다립니다.
3. 다음 4H 봉으로 진행하면 Risk Gate가 다시 검증하고 동일 비용모델로 모의 체결합니다.
4. 정지/재개, 손절, 수수료 차감 손익, 거래 내역과 감사로그를 확인합니다.
5. 비상정지에서 재개하면 SAFE_PAUSED로만 이동합니다. 다시 확인해야 PAPER가 됩니다.
6. RESET 확인은 모의 계좌 상태만 초기화합니다. 이전 감사 이벤트는 삭제하지 않습니다.

## 구현한 안전 기준

- Decimal, 소수점 8자리 내림, 왕복 슬리피지와 실제 체결대금 수수료를 포함한 0.5% 위험예산.
- 기본 수수료 0.05%, 슬리피지 0.1%. 10% 상한은 최신 PRD r2의 **슬리피지·수수료 포함 실제 지출** 기준입니다. 공통 `config/costs.yaml`(JSON 호환 YAML)을 사용합니다.
- 추가매수 금지, 최소 체결대금 5,000원, 현금 한도, 갭 손절.
- 일일 −2% 차단은 회복하더라도 해당 합성 날짜 동안 유지. −8% 낙폭은 SAFE_PAUSED.
- 3연패 후 합성시간 24시간 차단, 이후 2연패는 수동 재개 필요. 일반 pause/resume은 연패를 지우지 않습니다.
- 일일 경계는 KST. 4H 합성자료에는 정확한 자정 가격이 없으므로 자정을 넘는 봉 직전 완료봉 평가액을 새 일자의 기준으로 보수적으로 사용합니다. 실제 시세 운영의 자정 스냅샷과 동일하다고 주장하지 않습니다.
- 진행/중복/역순/결측/OHLC 이상 캔들 거절. UI에는 현재 시점까지의 완료봉만 전달합니다.
- 루프백 전용 호스트/클라이언트 제한, same-origin/CSRF, CSP. 로그인 없는 **로컬 전용** 작업도구이며 공개 서버로 노출하면 안 됩니다.
- 네트워크 주문 코드/자격증명/거래소 계정 연동이 없습니다. 기존 화면 데이터는 합성입니다. 별도 공개시세/오프라인 연구 CLI는 아래 문서를 참고하세요.

## 아직 없는 것 / 다음 구현 전제

실제 공개시세 연결 실측·웹소켓·호가 신선도·3년 백필, 전략 A/B/C·워크포워드·벤치마크·Parity, 30일 운영, 텔레그램/외부 하트비트, 배포용 인증, 분리된 정규화 주문/체결 테이블과 Alembic 마이그레이션은 미구현입니다. 수동 PAPER 제안 UI는 선택된 자동 전략이 아니며 전략 수익률을 표시하지 않습니다. STOP 파일 감시도 미구현이므로 이 로컬 화면/API의 비상정지만 제공합니다.

기존 PR-01/02 전용 인수인계와 달리 사용자의 앱 구현 요청에 따라 통합된 로컬 검증 슬라이스를 먼저 만들었습니다. 전체 PRD를 대체하지 않으며, 공개 배포와 실거래는 승인 범위가 아닙니다. SQL 스키마는 새 로컬 데모 DB만 생성합니다.

## 공개시세 어댑터 및 오프라인 연구 CLI

[실행 방법·모드 구분·검증 범위](docs/PUBLIC_REPLAY.md)를 참고하세요. 공개 캔들/현재가 조회 코드와 재현 가능한 SMA 기준전략 재생을 추가했습니다. 실시간 모의자동매매는 아직 연결하지 않았으며, 실제 API 접속은 현재 환경의 네트워크 허용목록 제한으로 미검증입니다. 기존 DEMO 화면과 사이트는 변경하지 않았습니다.
