# 시공·대리점형 홈페이지 제작 스킬

이 저장소 자체가 템플릿이다. **먼저 `manual/홈페이지-제작-매뉴얼.md`를 끝까지 읽고**, 그 문서의 구성·디자인 수치·모션 사양·QA 체크리스트를 기준으로 작업한다.

## 입력
- 인자로 업체명 또는 브리프가 오면 사용한다.
- 브리프가 없으면 매뉴얼 10-1 양식의 항목 중 **업종 / 취급 브랜드 / 주력 제품 / 연락처** 정도만 짧게 묻고, 나머지는 자리표시(`000`)로 진행한다. 자료가 없다는 이유로 멈추지 않는다.

## 절차
1. 브랜치 `site/<업체영문명>` 생성 (사용자가 지정한 브랜치가 있으면 그것을 사용).
2. `js/config.js` 회사 정보·연락처 교체.
3. `index.html` 교체: `<title>`·메타·OG, 메인 카피(매뉴얼 2장 카피 공식), 쇼케이스 3장(매뉴얼 0장 업종표 참고), 제품 탭·카드, 강점 4칸, 푸터.
   - 사양·수치·인증은 브리프에 있는 것만. 없으면 "현장 실측 후 안내".
   - 브랜드 "공식/Authorized" 표현은 브리프에서 확인된 경우만.
4. 사진
   - 실제 사진이 있으면 매뉴얼 6장의 ffmpeg 규격으로 `images/real/`에 변환.
   - 없으면 Canva `generate-image`로 16:9 실사풍 3장 생성 → 16:9 디자인에 넣고 (사용자 승인 후) 저장 → JPG 1920×1080 내보내기 → 다운로드. 라벨에 "AI 생성 샘플 이미지" 표기.
   - 카드용 800×600, 부분 확대 크롭으로 시공사례 6장 구성.
5. `--accent` 색을 업종 분위기에 맞게 조정.
6. CSS/JS 링크의 `?v=` 버전을 오늘 날짜로 갱신.
7. 로컬 서버(`python3 -m http.server`) + Playwright로 PC(1440)·모바일(iPhone 13) 스크린샷, 스크롤 녹화, 매뉴얼 8장 QA 체크리스트 점검. 콘솔 오류·깨진 이미지·가로 스크롤 0 확인.
8. 커밋·푸시 → Render API로 정적 사이트 생성(publishPath `.`, 해당 브랜치, autoDeploy, `X-Robots-Tag: noindex` 헤더) → 배포 완료 후 배포 주소에서 같은 검수 반복.

## 보고
- 배포 주소, 스크린샷·스크롤 영상
- 남은 자리표시 목록, AI 샘플 이미지 사용 여부
- 업체에 받아야 할 자료 목록 (매뉴얼 1장 체크리스트에서 빠진 것)

## 하지 말 것
- 참고 사이트의 문구·사진·영상·로고 복제
- `background-attachment: fixed` 사용 (모바일 사파리 깨짐 — sticky 방식 유지)
- AI 이미지를 실제 시공사례처럼 표기
- 확인되지 않은 수치·인증·브랜드 관계 게재
