# 고객 프로젝트 폴더

고객 1명 = 폴더 1개 (`projects/<고객-slug>/`). PM이 자동으로 만든다.

```
projects/<고객-slug>/
├── 00-status.md      PM 진행 현황판
├── 01-brief.md       기획서 (목적·타깃·사이트맵)      ← 승인 ①
├── 02-copy.md        페이지별 원고
├── 03-DESIGN.md      디자인 기준서                    ← 승인 ②
├── site/             실제 홈페이지 코드
├── 05-qa-report.md   검수 보고서
├── qa-shots/         모바일·PC 스크린샷
└── 06-deploy.md      배포 기록 / 공개 URL            ← 승인 ③
```
