# 수학의 신 (Math God) — 기획 패키지

직장인·성인을 위한 "생각하는 수학" 두뇌 게임 웹앱의 정식 기획서입니다.
이 폴더를 새 저장소의 루트로 복사한 뒤 Codex에게 넘기면 됩니다.

## Codex에게 줄 첫 지시문 (복사해서 사용)
```
AGENTS.md와 docs/ 문서를 순서대로 모두 읽어라.
docs/06-roadmap-tasks.md의 M0부터 순서대로 구현하라.
각 작업의 완료 기준을 만족하고 lint/typecheck/test가 통과하면 커밋한 뒤 다음 작업으로 넘어가라.
문서에 없는 결정은 docs/DECISIONS.md에 기록하라.
마일스톤 하나를 끝낼 때마다 무엇을 했는지, 무엇이 남았는지 요약해서 보고하라.
```

## 문서 구성
| 파일 | 내용 |
