# 01. 제품 요구사항 정의서 (PRD) — 수학의 신

## 1. 개요
| 항목 | 내용 |
|---|---|
| 앱 이름 | 수학의 신 |
| 한 줄 소개 | 계산은 계산기가, 생각은 당신이. 출퇴근 5분 두뇌 대결 |
| 타깃 | 25~45세 직장인·성인. 퍼즐, 두뇌 게임, 자기계발에 관심 있는 사람 |
| 플랫폼 | 1단계 모바일 우선 웹앱(PWA) → 2단계 앱 포장(Capacitor, iOS/Android) |
| 수익 | 광고(배너, 보상형). 유료 결제는 MVP 범위 밖 |
| 운영 | 1인 운영. 문제 생성, 검증, 랭킹 정산, 알림은 모두 자동 |

## 2. 문제 정의와 가치
- 기존 두뇌 게임은 단순 암산과 반응 속도 위주라 금방 질린다.
- 성인은 "수학 공부"는 부담스러워하지만, "이 문제 맞히면 상위 3%"라는 자극에는 반응한다.
- **가치**: 하루 5분, 공식 없이 생각만으로 풀 수 있는 문제로 "아하!" 하는 순간과 경쟁심을 준다.

## 3. 핵심 원칙
1. **생각 > 계산**: 계산기 없이 풀 수 있어야 한다. 숫자가 커지면 생각이 아니라 계산이 되므로, 템플릿 변수 범위를 제한한다.
2. **짧게**: 문제 하나는 평균 30초~3분. 한 판(세션)은 5분 안에 끝난다.
3. **공정한 경쟁**: 실력(두뇌지수)과 노력(레벨)을 분리해서 보여 준다.
4. **혼자 운영 가능**: 사람이 손대야 하는 기능은 만들지 않는다.

## 4. 사용자 여정
1. 랜딩 화면에서 "가입 없이 바로 풀기"를 누르면 익명 계정이 생성된다.
2. **두뇌 레벨 체크(배치고사)**: 10문제를 풀면 두뇌지수와 "상위 n%" 결과 카드가 나온다. 이 카드는 공유할 수 있다.
3. 결과 화면에서 "기록을 저장하려면 카카오로 3초 가입"을 띄운다. 익명 계정을 정식 계정으로 전환하며, 기록은 그대로 유지된다.
4. 매일 들어와서 오늘의 문제 3개를 풀고, 연습 모드로 XP를 쌓아 레벨을 올린다.
5. 랭킹에서 내 순위가 실시간으로 바뀌는 걸 확인하고, 연속일을 지킨다.

## 5. 기능 범위

### 5.1 MVP (반드시 구현)
| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 익명 시작 + 소셜 가입 | Supabase 익명 로그인 → 카카오/구글 계정 연결 시 기록 유지 |
| F-02 | 닉네임 설정 | 2~12자, 중복 불가, 금칙어 필터 |
| F-03 | 두뇌 레벨 체크 | 적응형 10문제 배치고사(02 문서 §5). 결과는 두뇌지수, 백분위, 카테고리별 강약 |
| F-04 | 오늘의 문제 | 매일 00:00(KST)에 전원 공통 3문제. 정답 수와 소요 시간으로 일간 순위 |
| F-05 | 연습 모드 | 5개 카테고리 중 하나 또는 "섞어서". 내 두뇌지수에 맞는 난이도를 자동 출제 |
| F-06 | 힌트 3단계 | 힌트 1, 힌트 2, 정답 공개. 힌트를 쓸수록 XP 감소 |
| F-07 | 해설 | 정답/오답 후 풀이 해설 표시. "생각의 핵심" 한 줄 강조 |
| F-08 | XP, 레벨, 칭호 | 02 문서의 레벨표. 레벨업 시 전체 화면 연출 |
| F-09 | 두뇌지수 | Elo 기반 실력 점수, 티어 표시 |
| F-10 | 실시간 랭킹 | 오늘의 문제 / 주간 XP / 전체 레벨 / 두뇌지수 4종. Supabase Realtime으로 즉시 반영 |
| F-11 | 실시간 활동 표시 | "지금 n명이 푸는 중", 홈 화면 레벨업 피드 ("○○님이 가우스 등급 달성") |
| F-12 | 연속일(스트릭) | 하루 1문제 이상 풀면 유지. 보상형 광고로 "스트릭 보호" 1회 |
| F-13 | 프로필 | 레벨, 칭호, 두뇌지수 추이, 카테고리별 레이더 차트, 정답률 |
| F-14 | 광고 | 결과/랭킹 화면 배너, 보상형 광고(힌트, 스트릭 보호). 05 문서 §8 |
| F-15 | 문제 신고 | "문제가 이상해요" 버튼. 신고가 누적되면 자동 격리(03 문서 §6) |
| F-16 | 관리자 검수 화면 | 격리된 문제, 생성 실패 로그, 지표를 보는 간단한 화면(운영자 1명) |
| F-17 | PWA | 홈 화면 추가, 오프라인 안내 페이지, 웹 푸시(오늘의 문제 알림, 스트릭 경고) |

### 5.2 이후 단계 (MVP 범위 밖, 구조만 고려)
- 1:1 실시간 대결: 회원 수가 늘면 진행. DB에 `match_id` 확장이 가능하도록 attempts를 설계한다.
- 친구/회사 리그: 초대 코드로 소그룹 랭킹
- 확장팩: 고등수학, 물리·화학 응용
- 앱스토어 출시: Capacitor + AdMob
- 광고 제거 구독

## 6. 화면 목록 (라우트)
| 라우트 | 화면 | 주요 요소 |
|---|---|---|
| `/` | 랜딩 / 홈 | 비로그인 시 소개와 "바로 풀기", 로그인 시 홈 대시보드 |
| `/home` | 홈 대시보드 | 오늘의 문제 카드(남은 시간), 레벨 진행 바, 연속일, 두뇌지수, "연습 이어하기", 실시간 레벨업 피드, 접속자 수 |
| `/check` | 두뇌 레벨 체크 | 진행 바(1/10), 문제, 결과 카드(공유 이미지) |
| `/daily` | 오늘의 문제 | 3문제 연속. 종료 후 내 일간 순위 |
| `/practice` | 카테고리 선택 | 5개 카테고리와 "섞어서", 카테고리별 내 정답률 |
| `/play/[sessionId]` | 문제 풀이 | 문제 본문, 답 입력, 힌트 버튼, 메모장(스크래치 패드), 경과 시간(작게). **광고 없음** |
| `/result/[attemptId]` | 결과 | 정답/오답, XP 획득 애니메이션, 두뇌지수 변화, 해설, 다음 문제, 배너 광고 |
| `/ranking` | 랭킹 | 탭 4개(오늘/주간/레벨/두뇌지수). 상위 100명과 하단 고정 내 순위. 실시간 갱신 |
| `/profile/[nickname]` | 프로필 | 칭호 배지, 레벨, 그래프, 레이더 차트 |
| `/settings` | 설정 | 계정 연결, 알림, 로그아웃, 탈퇴 |
| `/admin` | 관리자 | 운영자 이메일만 접근. 격리 문제, 생성 로그, 지표 |

### 문제 풀이 화면 상세 (`/play`)
- 상단: 카테고리 아이콘, 난이도 별(1~5), 경과 시간
- 본문: 문제 텍스트와 필요할 때 SVG 그림(기하 템플릿은 SVG를 생성)
- 답 입력은 답 형식에 따라 달라진다.
  - 정수/소수: 숫자 키패드(자체 키패드, 모바일 키보드 사용 안 함)
  - 분수: 분자/분모 입력
  - 객관식: 버튼 2~5개
  - 추정(어림): 숫자와 단위 배수 버튼(천, 만, 억)
- 힌트 버튼: "힌트 1 (XP -30%)" 식으로 비용을 항상 표시
- 오답 처리: 연습 모드는 1회 재도전을 허용하며 재도전 정답 시 XP 50%. 오늘의 문제와 레벨 체크는 1회만.

## 7. 톤 & 디자인
- 다크 모드 기본, 네온 포인트 컬러(보라, 청록). "두뇌 게임" 느낌이고 교과서 느낌은 피한다.
- 폰트: Pretendard(본문), 숫자는 tabular-nums
- 문구 예시
  - 정답: "정답! 상위 12%만 맞힌 문제예요"
  - 오답: "아깝네요. 생각의 핵심은 '절반이 되는 시점은 끝나기 1분 전'이에요"
  - 레벨업: "피타고라스 등급에 올랐어요"
  - 스트릭 경고 푸시: "7일 연속 기록이 3시간 뒤 끊겨요. 1문제만 풀어도 지켜집니다"

## 8. 성공 지표 (KPI)
| 지표 | MVP 목표 |
|---|---|
| 레벨 체크 완료율(시작 대비) | 70% 이상 |
| 익명 → 가입 전환율 | 30% 이상 |
| D1 / D7 / D30 리텐션 | 40% / 20% / 10% |
| 1인당 하루 풀이 수 | 8문제 이상 |
| 문제 신고율 | 0.5% 미만 |
| 광고 ARPDAU | 측정 후 기준선 설정 |

모든 지표는 `events` 테이블(05 문서)로 수집하고 `/admin`에서 본다.
