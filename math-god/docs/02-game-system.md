# 02. 게임 시스템 — XP, 레벨, 두뇌지수, 랭킹

모든 공식은 `src/lib/game/`에 순수 함수로 구현하고, 아래 예시값을 테스트 케이스로 사용한다.
상수는 `src/lib/game/constants.ts` 한 곳에 모은다(밸런스 조정 시 이 파일만 수정).

## 1. 두 가지 성장 축
| 축 | 의미 | 감소 여부 | 보여 주는 곳 |
|---|---|---|---|
| **레벨 (XP)** | 노력, 꾸준함 | 감소 없음 | 칭호, 레벨 랭킹, 주간 XP 랭킹 |
| **두뇌지수 (Rating)** | 실력 | 오답 시 감소 | 티어, 두뇌지수 랭킹, 출제 난이도 |

## 2. 난이도
- 난이도는 1~5단계(별)로 표시하며, 내부적으로는 **문제 레이팅** 값을 쓴다.
- 레이팅 → 별 변환: `<900: 1`, `900–1099: 2`, `1100–1299: 3`, `1300–1499: 4`, `≥1500: 5`
- 템플릿마다 `difficulty` 파라미터(1~5)로 초기 레이팅을 정한다: `initial = 700 + 200 × difficulty` (900, 1100, …, 1700)

## 3. XP 공식
```
baseXP(stars)   = [10, 20, 35, 55, 80][stars-1]
hintMult(h)     = [1.0, 0.7, 0.4, 0.0][h]        // h = 사용한 힌트 단계, 3 = 정답 공개
retryMult       = 재도전 정답이면 0.5, 첫 시도 정답이면 1.0
comboMult(c)    = 1 + min(c, 10) × 0.05           // c = 직전까지 연속 정답 수(세션 내), 최대 1.5
gapMult         = 문제 레이팅이 내 두뇌지수보다 400 이상 낮으면 0.5 (쉬운 문제 반복 방지)
estimateMult    = 추정 문제에서 부분 정답이면 0.5 (03 문서 §3)

XP = round(baseXP × hintMult × retryMult × comboMult × gapMult × estimateMult)
오답 = 0 XP
```
- 오늘의 문제 보너스: 문제당 XP ×1.5, 3문제 모두 정답이면 +50 XP
- 레벨 체크(배치고사)는 문제당 고정 10 XP
- **하루 연습 XP 상한은 없다**(광고 노출이 늘어나므로). 대신 gapMult로 어뷰징을 막는다.

예시 테스트
| stars | 힌트 | 재도전 | combo | gap | XP |
|---|---|---|---|---|---|
| 3 | 0 | 아니오 | 0 | 정상 | 35 |
| 3 | 1 | 아니오 | 4 | 정상 | round(35×0.7×1.2)=29 |
| 5 | 0 | 예 | 10 | 정상 | round(80×0.5×1.5)=60 |
| 1 | 0 | 아니오 | 0 | 낮음 | 5 |

## 4. 레벨표
```
xpToNext(n) = floor(60 × n^1.25)        // 레벨 n → n+1에 필요한 XP
totalXP(L)  = Σ_{n=1}^{L-1} xpToNext(n)  // 레벨 L 도달 누적 XP
최대 레벨 = 80
```
누적 XP 기준값(테스트용): Lv2=60, Lv5=777, Lv10=4,213, Lv20=21,291, Lv30=54,061, Lv50=173,277, Lv80=503,212
하루 30문제(평균 40XP)를 풀면 Lv80까지 약 1년이 걸리도록 설계했다.

## 5. 두뇌지수 (Elo)
```
expected(Ru, Rp) = 1 / (1 + 10^((Rp - Ru) / 400))
score S         = 정답 1, 추정 부분정답 0.5, 오답·정답공개 0
                  (힌트 1 사용 시 S 최대 0.75, 힌트 2 사용 시 최대 0.5)
사용자:  Ru' = Ru + Ku × (S - expected)
문제:    Rp' = Rp - Kp × (S - expected)
Ku = 48 (풀이 30회 미만), 32 (그 이후)
Kp = 16 (문제 풀이 50회 미만), 8 (그 이후)
초기 사용자 두뇌지수 = 1000, 하한 100
```
- 문제 레이팅의 단위: 파라미터 템플릿은 **(template_id, difficulty) 버킷** 단위로 레이팅을 관리한다(인스턴스는 매번 다르기 때문). AI 원본 문제는 문제별로 관리한다.
- 재도전 정답은 S = 0.25로 계산한다.
- 오늘의 문제와 레벨 체크도 두뇌지수에 반영한다.

### 티어 (두뇌지수)
| 두뇌지수 | 티어 |
|---|---|
| < 900 | 브론즈 |
| 900–1099 | 실버 |
| 1100–1299 | 골드 |
| 1300–1499 | 플래티넘 |
| 1500–1699 | 다이아 |
| ≥ 1700 | 마스터 |

### 백분위
- `상위 n%` = 활성 사용자(최근 30일 내 풀이) 중 내 두뇌지수 백분위. 10분마다 집계한 테이블에서 조회한다.

## 6. 출제 알고리즘 (연습 모드)
1. 목표 레이팅 = 내 두뇌지수 + 정규분포 노이즈(σ=100). 목표 정답률은 약 60~65%.
2. 선택한 카테고리(또는 전체) 중에서 목표 레이팅과 가장 가까운 버킷을 고른다. 후보 상위 5개 중 무작위로 하나.
3. 최근 20문제에서 쓴 템플릿은 가중치를 낮춰 반복을 피한다.
4. 파라미터 템플릿이면 서버에서 새 시드로 인스턴스를 생성한다. AI 원본 문제라면 아직 풀지 않은 승인된 문제를 꺼낸다.

## 7. 두뇌 레벨 체크 (적응형 배치고사)
- 10문제. 5개 카테고리에서 각 2문제.
- 1번 문제는 레이팅 1000. 이후 정답이면 +150, 오답이면 −150으로 다음 문제 레이팅을 정하고, 간격은 문제마다 15%씩 줄인다.
- 종료 후 두뇌지수 = 10문제 Elo 업데이트 결과(Ku=64 고정). 결과 카드에는 두뇌지수, 티어, 상위 n%, 카테고리별 강약(5축 레이더)을 담는다.
- 30일마다 다시 응시할 수 있다(재측정용, 선택 사항).

## 8. 오늘의 문제
- 매일 00:00 KST에 pg_cron이 3문제를 확정한다(난이도 별 2, 3, 4 각 1개, 서로 다른 카테고리). 전원 같은 인스턴스(같은 시드)를 받는다.
- 문제마다 1회만 제출할 수 있다. 소요 시간은 서버가 기록한 `served_at` → `submitted_at` 간격이다.
- 일간 순위: 정답 수 내림차순 → 총 소요 시간 오름차순 → 먼저 제출한 순
- 23:59:59까지 참여할 수 있고, 다음 날 00:00에 순위를 확정하고 상위 3명에게 배지를 준다.

## 9. 랭킹과 실시간 레벨 체크
| 랭킹 | 기준 | 리셋 |
|---|---|---|
| 오늘 | §8 일간 순위 | 매일 00:00 KST |
| 주간 XP | 이번 주(월 00:00 KST~) 획득 XP | 매주 월요일, 상위 10명 배지 |
| 레벨 | 누적 XP | 없음 |
| 두뇌지수 | 현재 두뇌지수(최소 30문제 풀이자만) | 없음 |

**실시간 요구사항 (MVP의 "실시간 레벨 체크")**
- 문제를 제출하면 1초 안에 내 XP, 레벨, 두뇌지수, 각 랭킹의 내 순위가 갱신되어야 한다.
- 랭킹 화면을 열어 둔 다른 사용자에게도 순위 변동이 실시간으로 반영된다(Supabase Realtime, 05 문서 §6).
- 홈 화면의 **레벨업 피드**: 칭호 변경, 티어 승급, 오늘의 문제 만점을 실시간으로 흘려 보낸다(최근 20개).
- **접속자 표시**: Realtime Presence로 "지금 n명이 푸는 중"을 보여 준다.
- 내 순위가 10계단 이상 오르면 결과 화면에 "랭킹 ▲12" 토스트를 띄운다.

## 10. 연속일 (스트릭)
- KST 기준 하루에 1문제 이상(어떤 모드든) 제출하면 유지된다.
- 하루를 빠지면 0으로 리셋된다. 단, **스트릭 보호권**이 있으면 자동으로 소모되고 유지된다.
- 보호권: 보상형 광고 1회 시청 시 1개 지급, 최대 2개 보유.
- 7, 30, 100, 365일 달성 시 배지를 준다.
- 21:00 KST까지 오늘 기록이 없으면 웹 푸시로 알린다(알림 동의자만).

## 11. 어뷰징 방지
- 제출 간격이 템플릿별 `min_solve_seconds`보다 짧은 정답이 연속 5회 나오면 의심 플래그를 단다. 이 경우 두뇌지수 반영을 중단하고 관리자 화면에 표시한다.
- 같은 사용자는 분당 최대 20회까지 제출할 수 있다(rate limit).
- 오늘의 문제는 정답을 제출 마감(자정) 전에는 공개하지 않는다. 해설은 제출 직후 본인에게만 보여 준다.
- 익명 계정은 랭킹에 표시하되 닉네임을 "익명 ○○○○"으로 표시하고, 오늘의 문제 배지는 받을 수 없다.
