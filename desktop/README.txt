채움 통합대시보드 - 바탕화면 아이콘 만들기 (Windows)

1. 이 압축 파일을 풀어 주세요. (마우스 오른쪽 클릭 → 압축 풀기)
2. 풀린 폴더에서 install.bat 을 더블클릭하세요.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
3. 바탕화면에 [채움 통합대시보드] 아이콘이 생깁니다.
   아이콘을 누르면 주소창 없는 앱 창으로 고객 관리 화면이 바로 열립니다.

· 앱 파일은 내 PC(%LOCALAPPDATA%\Chaeum)에 복사됩니다. 압축 푼 폴더는 지워도 됩니다.
· 새 버전을 받으면 같은 방법으로 install.bat 을 다시 실행하세요. 고객 자료는 그대로 남습니다.
· 고객 자료는 이 PC의 브라우저에 저장됩니다. 고객 관리 화면의 [백업 파일 저장]으로 정기 백업하세요.
· 크롬 또는 엣지가 있으면 그 브라우저로 열립니다(출력 버튼 사용 가능).
