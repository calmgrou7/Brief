# AGENTS.md

이 저장소는 식약처 공공데이터 기반의 "같이 먹으면 안 되는 약" 확인 앱 "약궁합"이다. **작업 전에 반드시 `PLAN.md`를 읽고 그 명세를 따른다.**

## 규칙
- 스택은 Next.js(App Router) + TypeScript + Tailwind + Supabase다. 패키지 매니저는 pnpm을 쓴다.
- 교차 점검 판정 로직은 `lib/engine/`의 순수 함수에만 둔다. DB 접근과 UI 코드를 넣지 않는다.
- 공공데이터 API 엔드포인트와 필드 매핑은 `scripts/sync/sources.ts`에만 둔다.
- 앱 런타임에서 공공데이터 API를 직접 호출하지 않는다. 동기화 배치가 채운 자체 DB만 조회한다.
- 의학적 사실(실제 약·성분의 금기 여부)을 코드나 테스트에 하드코딩하지 않는다. 단위 테스트는 `tests/fixtures`의 가상 데이터만 쓴다.
- 결과 문구에서 "안전합니다", "드세요", "끊으세요" 같은 단정·지시 표현을 쓰지 않는다(PLAN §14).
- 복용 약과 프로필(나이, 임신)은 기기 로컬에만 저장한다. 서버로 전송하거나 공유 링크에 넣지 않는다.
- `DATA_GO_KR_KEY`, `SUPABASE_SERVICE_ROLE_KEY` 같은 비밀값은 환경변수와 GitHub Secrets에서만 쓴다. 클라이언트 번들에 넣지 않는다.
- 커밋 전 `pnpm lint && pnpm test`가 통과해야 한다.
- UI 문구는 한국어로 쓰고, 모바일 360px과 큰 글씨 모드에서 확인한다.
- 지금 작업 중인 마일스톤(PLAN §13) 범위 밖의 기능은 만들지 않는다.
