# DM 응대 · 신청 폼 · 자동화

## 1. 키워드 DM 자동응답

**도구**: Meta 공식 기능(비즈니스 계정의 자동 응답 / FAQ) 또는 Meta 공식 파트너 도구(예: ManyChat). 비공식 봇은 쓰지 않습니다.

### 키워드 `분석`
```
안녕하세요, ○○○입니다 😊
보장분석 신청해주셔서 감사해요.

아래 링크에 기본 정보만 남겨주시면
24시간 안에 연락드릴게요. (2분이면 끝나요)
👉 [신청 폼 링크]

※ 건강 정보나 증권 사진은 지금 보내지 않으셔도 돼요.
   상담할 때 동의 절차를 거쳐 안전하게 확인할게요.
```

### 키워드 `체크`
```
체크리스트 보내드려요 📋
👉 [내 보험 셀프 점검 10문항 PDF]

체크해보시고 "잘 모르겠다"가 3개 이상이면
DM으로 "분석"이라고 보내주세요. 같이 봐드릴게요.
```

### 일반 질문 응답 템플릿
| 상황 | 답변 방향 |
|---|---|
| 개념 질문 ("갱신형이 뭐예요?") | 짧게 답변 → `가입하신 게 어떤 구조인지 보려면 분석이 제일 정확해요` |
| 청구 질문 | 일반 절차 안내 → `막히는 부분 있으면 같이 봐드릴게요` |
| 상품 추천 요청 | DM으로 특정 상품 추천은 하지 않음 → 상담으로 연결 |
| 가격 문의 | `보장분석 상담은 무료예요` (소속사 기준 확인) |

## 2. 보장분석 신청 폼 (구글폼 기준)

**최소 정보만 받습니다.** 민감정보는 받지 않습니다.

1. 이름 (또는 닉네임)
2. 연락처
3. 연령대 (20대 / 30대 / 40대 / 50대 이상)
4. 분석 대상 (본인 / 배우자 / 부모님 / 자녀)
5. 가입한 보험 개수 (대략)
6. 월 보험료 총액 (대략, 구간 선택)
7. 가장 궁금한 점 (중복 / 빠진 보장 / 보험료 / 청구 / 기타)
8. 상담 희망 방식 (전화 / 대면 / 화상) · 희망 시간대
9. ☑️ 개인정보 수집·이용 동의 (목적: 상담 연락 / 보유기간 명시)

## 3. 자동화 흐름 (단계별 도입)

### 1단계: 바로 가능, 비용 0원
```
DM 키워드 → 자동응답(폼 링크)
구글폼 제출 → 구글시트 기록 → Gmail 알림
구글 캘린더 "예약 일정" 링크로 상담 예약
```

### 2단계: Claude 정기 작업
- **매주 월요일 아침**: 지난주 신청 건수와 문의 유형을 요약하고, 이번 주 게시물 캡션 초안 3개를 만들어 Gmail이나 Drive에 넣어 둡니다.
- **매월 말**: 다음 달 캘린더 초안을 받은 질문을 반영해서 만듭니다.

### 3단계: Instagram Graph API (이 저장소에 구축)
- 예약 게시 (승인한 콘텐츠만)
- 게시물별 인사이트 수집 → 주간 리포트 (저장 수, 프로필 방문, DM 유입)
- 댓글 키워드 감지 → 답변 초안 생성 (**발송은 사람이 승인**)
- 필요한 것: 비즈니스·크리에이터 계정, 연결된 Facebook 페이지, Meta 개발자 앱

> 고객 응대 메시지는 **사람이 최종 승인하는 구조**를 유지합니다. 보험은 표현 하나가 규제 문제로 이어질 수 있기 때문입니다.
