# 적정단가 노트 (Google Apps Script 테스트 버전)

원가율·마진율 계산 미니앱. 두 가지 모드:
- **세트 원가**: 견적서·주문내역의 자재를 1회성/회차 기본/개당으로 나눠 세트당 원가, 원가율, 첫 생산비 회수 세트 수, 최저가, 추천가 계산
- **간단 단가**: 재료비 + 내 시간 + 고정비로 적정가·최저가·손익분기 건수, 지금 가격의 실제 마진율 진단

## 파일
| 파일 | 역할 |
|---|---|
| `Code.gs` | 웹앱 진입점(doGet), 구글 시트 저장·조회·삭제 |
| `Index.html` | 화면 + 계산 로직 (단독으로 브라우저에서 열어도 동작, 이때는 기기에 저장) |
| `appsscript.json` | 시간대·권한·웹앱 설정 |

## 배포 (5분)
1. https://script.google.com → **새 프로젝트**
2. `Code.gs` 내용을 붙여넣기
3. 왼쪽 **파일 +** → HTML → 이름 `Index` → `Index.html` 내용 붙여넣기
4. (선택) 프로젝트 설정 → "appsscript.json 표시" 체크 → 내용 붙여넣기
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (테스트 고객이 로그인 없이 사용)
6. 권한 승인 → 나온 `/exec` 주소가 테스트 링크
7. 처음 "결과 저장"을 누르면 내 드라이브에 `적정단가 노트 - 계산기록` 시트가 자동 생성됩니다.
   (편집기에서 `showSheetUrl` 실행 → 로그에 시트 주소)

> 실행 사용자가 "나"이므로 모든 사용자의 저장 기록이 내 시트에 쌓입니다 = 테스트 고객 데이터·리드 수집.
> 고객에게 이 점을 안내하거나, 개인정보를 받기 전에 동의 문구를 추가하세요.
