# 시공·대리점형 홈페이지 제작 매뉴얼 v1

> 기준 사례: **예스시스템** (바튼 폴딩도어 2차 판매·시공점) — https://yes-system-sample.onrender.com
> 이 저장소 전체가 템플릿입니다. 새 업체는 **복사 → 설정 파일 교체 → 사진 교체 → 배포** 순서로 만듭니다.
> 목표 소요 시간: 자료가 다 모였을 때 **반나절**, 자료 없이 시안만이면 **1~2시간**.

---

## 0. 이 매뉴얼이 맞는 업체

**제조사(브랜드) 제품을 받아 상담·실측·시공·A/S까지 하는 지역 시공점·대리점**에 최적화되어 있습니다.

| 업종 예시 | 쇼케이스 3장 예시 |
|---|---|
| 폴딩도어·창호 (기준 사례) | 글라스 폴딩도어 / 프레임 폴딩도어 / 썬룸 |
| 현관 중문 | 슬림 3연동 / 원슬라이딩 / 스윙도어 |
| 시스템창호 리모델링 | 거실 확장창 / 단열 시스템창 / 방화창 |
| 인테리어 필름·도장 | 주방 리폼 / 현관·몰딩 / 상가 인테리어 |
| 시스템 에어컨·환기 | 아파트 천장형 / 상가 / 전열교환기 |
| 태양광·ESS | 주택 지붕형 / 공장 지붕형 / 주차장형 |
| 조경·데크·캐노피 | 데크 / 캐노피·어닝 / 정원 조경 |

공통점: **"제품은 브랜드가, 결과는 시공이 만든다"** → 사이트의 핵심 메시지는 *정품 + 같은 담당자 + 투명 견적 + 빠른 A/S*.

## 1. 사전 수집 체크리스트 (업체에 보낼 목록)

복사해서 카톡·문자로 그대로 보내도 됩니다.

```
[홈페이지 제작 자료 요청]
1. 상호 / 대표자 / 사업자등록번호 / 주소
2. 대표 전화 / 카카오톡 채널 주소 / 이메일 / 상담 시간
3. 시공 가능 지역
4. 취급 브랜드명과 관계 (공식 대리점? 2차 판매점?)
   → 브랜드 로고·제품명·카탈로그 사진을 써도 되는지 본사 허락 여부
5. 주력 제품 3~6개와 각 특징 한 줄
6. 시공 사진 10~20장 (가로 사진 우선, 현장 지역·공간 메모)
7. 시공 영상 5~15초 (있으면) — 휴대폰 가로 촬영, 천천히 걷거나 문 여는 장면
8. 특허·인증·수상 내역 (있으면)
9. 도메인 (있음 / 새로 구매 / 당분간 없음)
10. 원하는 분위기 (예: 고급·차분 / 밝고 친근 / 모던·블랙)
```

> **자료가 없어도 시작 가능**: 회사 정보는 `000` 자리표시로, 사진은 AI 실사풍 이미지(6장 참고)로 시안을 먼저 만들어 보여주고 자료를 받는 방식이 계약 전환에 유리합니다.

## 2. 화면 구성 (섹션 설계도)

한 페이지 스크롤형. 위에서 아래 순서 그대로 유지하는 것을 권장합니다.

| # | 섹션 | 목적 | 핵심 요소 |
|---|---|---|---|
| 1 | **메인(히어로)** | 3초 안에 "무엇을, 누가" | 전체화면 배경(영상/사진 슬라이드), 한 줄 카피, 견적 버튼 2개, 신뢰 지표 3개 |
| 2 | **쇼케이스 ×3** | 제품의 '분위기' 판매 | 화면 고정 + 다음 장이 덮는 전환, 큰 영문 제목 + 한글 카피 + "제품 보기" |
| 3 | **제품** | 비교·선택 | 탭(제품군) + 카드(이름·한 줄 설명·#태그), "사양·가격은 실측 후 안내" 문구 |
| 4 | **왜 우리인가** | 시공점 차별화 | 어두운 배경 4칸: 정품 / 같은 담당자 / 투명 견적 / 빠른 A/S |
| 5 | **시공 과정** | 불안 해소 | 5단계: 신청 → 실측 → 견적·계약 → 제작·시공 → 검수·A/S |
| 6 | **시공사례** | 증거 | 분류 필터 + 카드 그리드(사진이 천천히 움직임) |
| 7 | **견적 문의** | 전환 | 왼쪽 연락처, 오른쪽 폼(이름·연락처·지역·관심제품·공간·시기·요청사항·동의) |
| 8 | **푸터** | 법적 정보 | 사업자 정보, 개인정보 수집 안내, 상표 고지 |
| + | **상담 버튼(고정)** | 어디서든 전환 | 모바일 하단 바 3칸 / PC 오른쪽 아래 떠 있는 버튼 3개 |

### 카피 공식
- 메인: **"[제품을 쓰면 생기는 변화] + [시공점의 약속]"**
  예) "열면 공간이 되고, 닫으면 풍경이 됩니다." / "끝난 뒤의 A/S까지 같은 팀이 책임집니다."
- 쇼케이스: 영문 2줄(카테고리명, 얇은 굵기 200) + 한글 2줄(장면) + 설명 1문장
- 제품 카드: 이름 / 누구에게 좋은지 1문장 / #용도 태그 2~3개
- **수치·사양은 확인된 것만** 씁니다. 모르면 "현장 실측 후 안내".

## 3. 디자인 시스템 (수치 그대로 사용)

### 색 (css/style.css `:root`)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#faf9f6` | 기본 배경(따뜻한 아이보리) |
| `--ink` | `#1b1c1e` | 본문·버튼 |
| `--ink2` | `#55585e` | 보조 텍스트 |
| `--line` | `#e3e1dc` | 테두리 |
| `--soft` | `#f1efea` | 시공사례 배경 |
| `--dark` | `#16181b` | 강점 섹션·푸터 |
| `--accent` | `#b48a56` | 소제목(eyebrow)·태그 |
| `--accent2` | `#d9c3a3` | 어두운 배경 위 포인트 |

업종별로 `--accent` 만 바꿔도 분위기가 바뀝니다: 친환경 `#5f7f5a` / 신뢰·기술 `#4a6a8a` / 고급 블랙 `#9a8f80`.

### 글꼴·크기
- 글꼴: **Pretendard** (CDN), 대체 Apple SD Gothic Neo / 맑은 고딕
- 메인 제목 `clamp(34px, 5.4vw, 64px)`, 섹션 제목 `clamp(28px, 3.6vw, 44px)`, 쇼케이스 영문 `clamp(40px, 7vw, 104px)` 굵기 200
- 자간 `-0.03em` 내외, 한글 줄바꿈 `word-break: keep-all`

### 레이아웃
- 최대 폭 1200px, 좌우 여백 20px, 섹션 위아래 120px(모바일 84px)
- 모서리 14px(카드), 버튼은 완전한 알약형(999px), 버튼 높이 54px
- 모바일 우선: 900px 이하 1단, 560px 이하 카드 1열

## 5. 업무 자동화 (1인 운영 핵심)

| 자동화 | 방법 | 상태 |
|---|---|---|
| 견적 문의 자동 저장 | 폼 → Supabase `leads` 테이블 (`supabase/schema.sql`) | 코드 완료, 키 입력 시 작동 |
| 문의 상태 관리 | `status`: 신규→상담중→실측예약→견적발송→계약→보류→종료 | Supabase 대시보드에서 관리 |
| 보안 | 방문자는 '등록'만, 조회·수정은 로그인 사용자만 (RLS) | 완료 |
| 새 문의 알림 | Supabase Database Webhook 또는 Zapier → 카톡·메일·슬랙 | 다음 단계 |
| 유입 경로 추적 | 폼에 `source`(도메인), `utm`(광고 파라미터) 자동 저장 | 완료 |
| 시공사례 추가 | `js/cases.js` 한 줄 추가 | 완료 |
| 회사 정보 변경 | `js/config.js` 한 파일 | 완료 |

**연결 순서**: Supabase 프로젝트 → SQL Editor에 `schema.sql` 실행 → `config.js`에 URL·publishable 키 입력 → 테스트 문의 1건 → 테이블 확인.

## 6. 사진·영상 파이프라인

### 실제 사진이 있을 때
1. 가로 사진 우선, 원본을 `images/real/`에 넣기
2. 배경용 1920×1080 (장당 400KB 이하), 카드용 800×600 (장당 80KB 이하)로 변환
   ```bash
   ffmpeg -i 원본.jpg -vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080" -q:v 4 living.jpg
   ffmpeg -i 원본.jpg -vf "scale=1067:600:force_original_aspect_ratio=increase,crop=800:600" -q:v 4 living-card.jpg
   ```
3. `config.js > hero.photos`, `index.html .show__bg img`, `cases.js > img` 경로 교체

### 사진이 없을 때 (시안용 AI 실사풍)
1. Canva AI 이미지 생성으로 16:9 실사풍 3장 (거실/상가/외부 등 공간 다르게)
   - 프롬프트 공식: **"사진처럼 사실적인 [건축/실내] 사진: [공간], [제품 + 프레임 색 + 열린 상태], [조명·시간대], [소품], 글자나 로고 없음"**
2. 생성 결과는 썸네일만 오므로 → Canva 16:9 디자인에 넣고 저장 → JPG 1920×1080으로 내보내기
3. **라벨에 "AI 생성 샘플 이미지" 표기**, 정식 오픈 전 실제 사진으로 교체 (시공사례를 실제처럼 보이게 하면 안 됨)

### 영상
```bash
tools/make-hero-video.sh 원본.mp4 0 12
```
→ PC용(16:9, 1920) + 휴대폰용(9:16, 720) + 포스터 자동 생성, 소리 제거, 보통 1~2MB.
사진을 영상으로: AI 영상 도구(Veo·Runway·Kling)에 사진 + "카메라가 천천히 앞으로, 폴딩도어가 부드럽게 열림" → 5~8초.

## 7. 배포 (도메인 없이 → 도메인 연결)

1. 새 업체용 브랜치 생성 후 push
2. **Render → Static Site** (Build command 비움, Publish directory `.`, Branch = 해당 브랜치, Auto deploy ON)
3. 시안 단계: 응답 헤더 `X-Robots-Tag: noindex` → 검색 노출 차단
4. CSS/JS 주소에 `?v=날짜` 버전 → 수정 후 캐시 때문에 옛 화면 보이는 문제 방지 (Render CDN 5분 캐시)
5. 정식 오픈: Custom Domain 연결 → noindex 제거 → 네이버 서치어드바이저·구글 서치콘솔 등록

```

[ ] 제품 탭 전환, "제품 보기" → 해당 탭 열림
[ ] 시공사례 필터, 사진 움직임
[ ] 견적 폼: 빈칸 검증, 동의 체크, 전송 성공 메시지 / Supabase 저장 확인
[ ] 전화 버튼 tel: 링크, 카톡 버튼 채널 링크
[ ] 깨진 이미지 0, 콘솔 오류 0
[ ] 이미지 용량: 배경 400KB↓, 카드 80KB↓
[ ] 메타 설명(description)·OG 태그 업체에 맞게 수정
[ ] 푸터 사업자 정보·개인정보 안내 실제 값
[ ] AI 이미지 라벨 / 자리표시(000) 남아있지 않은지 (정식 오픈 시)
```

자동 점검: Playwright 스크립트로 PC·모바일 스크린샷 + 스크롤 녹화 → 업체 컨펌용으로 그대로 전달.

## 9. 법·신뢰 주의사항

- **참고 사이트 복제 금지**: 구성·흐름만 참고, 문구·사진·영상·로고는 쓰지 않음
- **브랜드 표기**: "공식/Authorized" 문구와 브랜드 로고는 본사 허락이 확인된 경우만. 푸터에 "OOO은 해당 제조사의 상표입니다" 고지
- **AI 이미지**: 시안에만 사용하고 표기, 시공사례에는 실제 사진만
- **개인정보**: 수집 항목·목적·보유기간 고지 + 동의 체크 필수
- **수치·인증**: 업체가 증빙할 수 있는 것만 게재

```
이 저장소(calmgrou7/Brief, 예스시스템 템플릿)를 기준으로 아래 브리프의 업체 홈페이지를 만들어줘.
manual/홈페이지-제작-매뉴얼.md 의 구성·디자인 수치·모션 사양·QA 체크리스트를 그대로 따를 것.

[브리프]
(10-1 양식 붙여넣기)

[작업 순서]
1. 새 브랜치 site/<업체영문명> 생성
2. js/config.js 회사 정보·연락처 교체 (모르는 값은 000 자리표시)
3. index.html: 타이틀·메타·OG, 메인 카피, 쇼케이스 3장, 제품 탭·카드, 강점, 푸터를 업종에 맞게 교체
   - 수치·사양은 브리프에 있는 것만, 나머지는 "현장 실측 후 안내"
4. 사진: 있으면 규격 변환해 교체 / 없으면 Canva AI 실사풍 3장 생성 → 1920 JPG 내보내기 → "AI 생성 샘플 이미지" 라벨
5. 포인트 색(--accent) 조정
6. 로컬 Playwright로 PC·모바일 스크린샷 + 스크롤 녹화, QA 체크리스트 점검
7. 커밋·푸시 → Render 정적 사이트 생성(noindex) → 배포 주소에서 재검수
8. 결과: 배포 주소, 스크린샷, 남은 자리표시 목록, 업체에 받을 자료 목록 보고
```
