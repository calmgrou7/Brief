# 기획서 (SPEC)

## 목적
1인 앱개발사 **브릿지노드**가 진행하는 모든 프로젝트(미니앱·웹앱·토스 인앱)를 기획 단계부터 출시·운영까지 총괄 관리한다.
나중에 지속 관리가 가능하도록 운영 계정(아이디/비밀번호), 서버, 도메인 정보까지 한 곳에 정리한다.

## 사용자
- 대표 1인(관리자). 고객사·외주 공유는 이후 단계.
- 핵심 가치: **업무 자동화**와 **누락 방지**(검수 결과 확인, 도메인·서버 갱신 놓치지 않기).

## 핵심 화면
| 화면 | 요구사항 |
|---|---|
| 개요 | 전체 진행률(%), 트랙별 진행률, 상태별 건수, 다음 절차, 전체 파이프라인 |
| 프로젝트 | 트랙별 단계 체크로 진행률 자동 계산, 다음 절차, 기간·URL·메모 |
| 출시·업데이트 | 몇 번째 업데이트인지, 서버 배포 내역, 출시/검수중/진행중 표시 |
| 도메인·서버 | 도메인 갱신 기간 관리, SSL, 서버 비용·갱신일 |
| 계정 보관함 | 아이디/비밀번호 암호화 보관, 프로젝트 연결 |
| 백업·설정 | 백업/복원, 자동화 입력(출시 이력 병합), 초기화, 활동 기록 |

## 트랙별 단계 템플릿
- 미니앱: 기획 → 디자인 → 개발 → 테스트 → 플랫폼 심사 → 출시
- 웹앱: 기획 → 디자인 → 개발 → 서버·도메인 연결 → QA → 오픈
- 토스 인앱: 기획 → 디자인(TDS) → SDK 연동 개발 → 샌드박스 테스트 → 검수 요청 → 출시

## 규칙
- 진행률 = 완료 단계 / 전체 단계. 트랙·전체는 보류 제외 평균.
- 상태: 보류 > 검수중(최근 기록 검수요청·검수중) > 반려 대응 > 출시·운영중(출시완료 1건 이상 + 100%) > 기획중(첫 단계 미완료) > 진행중.
- 업데이트 차수: 출시완료 1건 = 최초 출시, n건 = (n-1)차 업데이트.
- 다음 절차 알림 기준: 도메인 60일(30일 이내 긴급), SSL 30일, 서버 30일(7일 이내 긴급).
