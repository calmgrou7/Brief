# 한장견적 업데이트 기획안

> 작성일: 2026-11-26 · 대상: 토스 미니앱 「한장견적」 (calmgrou-onequote)
> 기준 자료: 토스 미니앱 공개 페이지 (앱 내부 화면은 확인하지 못함 → 현재 기능은 추정 포함)

---

## 1. 현재 상태 (공개 페이지 기준)

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | "견적서 작성부터 입금 관리까지" |
| 순위 | 일·비즈니스 카테고리 54위 |
| 리뷰 | 1건 (★5.0, "사용하기편하고 견적서 낼때 도움되네요^^") |
| 상세 설명 | **없음** (한 줄 소개뿐), 스크린샷 5장 |
| 같은 제작자 앱 | 페이스디, 두잇, 오늘의 영업 플래너 |

**진단**
- 쓴 사람은 만족하지만 **노출·리뷰 수가 적어** 순위가 오르지 않는 단계.
- "입금 관리까지"라는 약속이 핵심 차별점 → 이 흐름을 **자동화**로 끝까지 연결하는 게 업데이트의 축.

---

## 2. 업데이트 방향 한 문장

> **"견적 보내면, 나머지는 한장견적이 챙긴다."**
> 견적 → 고객 확인 → 청구 → 입금 확인 → 리마인드까지, 1인 사업자가 손으로 챙기던 일을 줄인다.

---

## 3. 기능 로드맵

### P0 — 다음 업데이트 (재사용·전환에 직결)

| 기능 | 왜 필요한가 | 자동화 포인트 |
|---|---|---|
| **고객·품목 저장 & 불러오기** | 매번 같은 정보 재입력이 가장 큰 이탈 원인 | 한 번 입력 → 자동완성 |
| **견적 복제 / 템플릿** | 비슷한 견적 반복이 대부분 | "지난 견적 복사해서 수정" 1탭 |
| **링크 공유 + 열람 확인** | 카톡으로 보내고 "봤나?" 궁금함 | 고객이 열면 '열람됨' 표시 |
| **견적 → 청구서/거래명세서 전환** | 같은 내용 다시 만들 필요 없음 | 버튼 하나로 문서 변환 |
| **입금 상태 보드** | "입금 관리" 약속의 실체 | 대기 / 부분입금 / 완료 / 연체 자동 분류 |
| **부가세·할인 자동 계산** | 계산 실수 = 신뢰 하락 | 공급가/부가세/합계 자동 |

### P1 — 그다음 (차별화)

| 기능 | 설명 |
|---|---|
| **고객 승인(서명) 버튼** | 고객이 링크에서 "승인" → 사실상 간이 계약 완료, 상태 자동 변경 |
| **미입금 리마인드** | 기한 지난 건 알림 + 고객에게 보낼 정중한 안내 문구 자동 생성 |
| **토스 송금/결제 연결** | 견적서 안에서 바로 입금 → 입금 확인 자동화 *(토스 미니앱 SDK 지원 범위 확인 필요)* |
| **사업자 정보·도장 이미지 저장** | 문서 신뢰도 ↑, 매번 입력 X |
| **월간 대시보드** | 이번 달 견적액 / 수주율 / 미수금 한눈에 |
| **PDF·이미지 저장** | 이메일·관공서 제출용 |

### P2 — 중장기 (업그레이드)

| 기능 | 설명 |
|---|---|
| **AI 견적 초안** | "욕실 타일 3평 교체" 입력 → 품목·단가 초안 자동 작성 |
| **업종별 템플릿** | 인테리어, 디자인, 촬영, 청소, 교육 등 |
| **세금계산서 발행 연동** | 외부 발행 API(바로빌·팝빌 등) 연계 검토 |
| **오늘의 영업 플래너 연동** | "보낸 견적 후속 연락"을 플래너 할 일로 자동 등록 — 자사 앱 묶음 효과 |

## 4. 성장 장치 (순위 54위 → 상위권)

1. **바이럴 루프**: 공유된 견적서 하단에 "한장견적으로 1분 만에 만든 견적서" + 링크 → 받은 고객(대부분 또 다른 사업자)이 유입.
2. **리뷰 요청 타이밍**: 견적 3건 작성 or 첫 '입금 완료' 처리 직후에 리뷰 요청 (만족 순간).
3. **미니앱 상세 설명 채우기**: 현재 한 줄뿐 → 핵심 기능 3개 + 대상(1인 사업자·프리랜서) 명시.
4. **스크린샷 재구성**: 1장 = 1메시지 ("1분 작성" / "카톡 공유" / "입금 자동 관리" / "미수금 알림" / "무료").

## 5. 확인할 지표

| 지표 | 의미 |
|---|---|
| 첫 견적 완성률 | 온보딩이 쉬운가 |
| 공유율 (작성 대비 공유) | 실제 업무에 쓰는가 |
| 열람률 / 승인률 | 고객 쪽 경험 |
| 입금 완료 처리율 | "입금 관리" 기능이 쓰이는가 |
| 7일·30일 재방문 | 습관화 여부 |
| 공유 링크 경유 신규 유입 | 바이럴 루프 효과 |

## 6. 업데이트 공지 문구 초안

> - 고객이 견적서를 열어보면 바로 알 수 있어요
> - 견적서를 청구서로 한 번에 바꿔보세요
> - 입금 대기·완료·연체를 한눈에 관리하세요
