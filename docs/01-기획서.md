# Brief — 법인 컨설팅 설계사용 상담 솔루션 기획서 (v0.1)

> 법인 영업 보험설계사가 **중소기업 대표님 첫 미팅 전에 진단 리포트를 만들고**,
> **상담 중에 시뮬레이션을 보여주고**, **상담 후 후속 제안까지 이어가는** 유료 웹앱.

---

## 1. 문제 정의

| 설계사가 지금 겪는 문제 | Brief가 해결하는 방식 |
|---|---|
| 초회 면담 준비에 재무제표 분석·자료 작성으로 반나절 이상 소요 | 재무제표 업로드 → 10분 안에 **초회 면담 리포트(PDF)** 자동 생성 |
| 가결산 비율 분석·비상장주식 가치·상속세 계산을 엑셀로 각자 따로 함 | 하나의 기업 데이터로 **모든 시뮬레이션이 연결**됨 |
| 세무·법무 지식 편차가 커서 신입은 법인 영업 진입이 어려움 | 진단 결과에 **"상담 포인트·질문 스크립트"**까지 같이 제시 |
| 상담 후 관리가 안 됨 (재무제표는 매년 바뀜) | 기업별 **연차 히스토리 + 다음 상담 알림** |

## 2. 타깃 사용자

- **1차 고객(결제자):** 법인 영업 보험설계사 (GA 소속 개인, 법인영업팀)
- **2차 고객:** GA 법인사업부 / 지점 단위 팀 라이선스
- **최종 수혜자:** 설계사가 상담하는 중소기업 대표 (앱에 직접 로그인하지 않음 — 리포트·공유 링크로만 접함)

## 3. 핵심 모듈 (요청하신 8개 영역 정리)

모든 모듈은 **하나의 "기업 프로필"** 을 공유합니다. 재무제표를 한 번 넣으면 아래 모듈이 같은 숫자로 계산됩니다.

```
                ┌──────────────────────────┐
                │  기업 프로필 (공통 데이터)  │
                │ 재무제표 3개년·주주명부·임원·정관·인증현황 │
                └────────────┬─────────────┘
   ┌──────────┬──────────┬───┴──────┬──────────┬──────────┬──────────┐
   ▼          ▼          ▼          ▼          ▼          ▼          ▼
 ①재무진단  ②가결산     ③주식가치  ④상속·증여  ⑤정관·임원  ⑥기업인증  ⑦정책자금
   └──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
                              ▼
                    ⑧ 초회 면담 리포트 / 제안서
```

| # | 모듈 | 주요 기능 | 영업 연결 포인트 |
|---|---|---|---|
| ① | **재무제표 진단** | 3개년 추이, 안정성·수익성·성장성 지표, 업종 평균 비교, 이익잉여금·부채비율 경고 | "이익잉여금이 쌓이면 주식가치가 오릅니다" |
| ② | **가결산 (연말 결산 전 재무구조 관리)** ★ | 9~10월 재무상태표·손익계산서로 연말 예상치 산출 → 목적별(대출·정책자금·입찰·인증·승계) 목표 비율과 차이 진단 → 매출·매입·대출·증자·감자·주주 변동·가지급금 정리 시나리오 비교 → 대표용 리포트 + 회계사무실 요청서. 상세: [`02-가결산-모듈.md`](02-가결산-모듈.md) | **매년 10~12월 반복 방문 명분**, 결산 전 액션 제안 |
| ③ | **비상장주식 평가·주식 이동** | 상증법 보충적 평가(순손익가치·순자산가치 가중), 최대주주 할증, 차명주식 점검, 증여·양도·자기주식 취득 시 세금 비교 | 지분 이전 타이밍, 가업승계 |
| ④ | **상속·증여 시뮬레이션** | 상속세/증여세 계산, 10년 합산, 가업상속공제·증여세 과세특례 요건 체크, 납부 재원(유동성) 부족액 산출 | **상속세 재원 = 종신보험 니즈** |
| ⑤ | **정관·임원 구성** | 정관 체크리스트(임원 보수·퇴직금 지급규정, 유족보상, 중간배당, 자기주식 취득, 주식양도 제한 등), 임원 구성·보수 적정성 | 임원 퇴직금 규정 → CEO 플랜 |
| ⑥ | **기업 인증** | 벤처·이노비즈·메인비즈·기업부설연구소 요건 자가진단, 미충족 항목 안내, 사업계획서 초안(AI) | 인증 → 세제 혜택·정책자금 가점 |
| ⑦ | **정책자금 매칭** | 재무구조(부채비율, 이자보상배율 등) + 인증 + 기술력 기반 신청 가능 자금 추천(중진공·지역신보·기보 등), 결격사유 체크 | 대표와 장기 관계 형성 |
| ⑧ | **초회 면담 리포트** | 위 결과를 요약한 대표용 PDF(10~15p), 설계사용 상담 스크립트 별도 | **첫 미팅 문 열기** |

> 가지급금은 별도 모듈이 아니라 가결산 안의 점검 항목(인정이자, 신용평가 감점, 정리 시나리오)으로 포함합니다.

## 4. 사용 흐름 (설계사 입장)

1. **기업 등록** — 사업자번호 입력 → 기본정보 자동 조회
2. **자료 넣기** — 표준재무제표증명 PDF/엑셀 업로드 → AI가 계정과목 자동 추출 → 설계사가 확인만
3. **추가 정보** — 주주명부, 임원 현황, 대표 가족관계(상속 시뮬용), 보유 인증 (없으면 빈칸으로 두고 리포트에 "확인 필요"로 표시)
4. **진단 실행** — 8개 모듈 결과 대시보드
5. **리포트 출력** — 대표용 PDF / 설계사용 상담노트 / 카카오톡 공유 링크
6. **사후 관리** — 다음 해 재무제표 업데이트 알림, 상담 이력 메모

## 5. 반드시 지켜야 할 규제·리스크 (설계 단계부터 반영)

| 리스크 | 대응 설계 |
|---|---|
| **세무사법·변호사법** — 설계사가 세무대리·법률 자문을 하는 것으로 비치면 문제 | 모든 결과물에 "시뮬레이션·참고용, 실제 신고는 세무사 확인" 고지. 문구를 "자문"이 아닌 **"진단·시뮬레이션"** 으로 통일. 제휴 세무사·노무사 연결 기능(장기적으로 수익원) |
| **개인정보보호법·신용정보** — 대표 가족관계, 재무 데이터 | 고객 동의서 전자서명 플로우, 암호화 저장, 설계사별 데이터 격리, 보관기간·파기 정책 |
| **금융소비자보호법** — 리포트가 특정 보험상품 권유로 직결되면 광고 심의 이슈 | 리포트 본문은 "재원 부족액·리스크"까지만, 상품명 노출 금지. 상품 제안은 설계사가 별도로 |
| **세법 개정** — 매년 바뀌는 세율·공제 요건 | 세율·한도를 코드가 아닌 **연도별 설정 테이블**로 관리, 연 1회 업데이트 |

## 8. 기술 구성 (운영 부담 최소화)

- **프론트/백엔드:** Next.js (웹 + 태블릿 상담 화면 겸용)
- **DB·인증·파일:** Supabase (Postgres, 로그인, 재무제표 파일 저장, 행 단위 보안으로 설계사별 데이터 격리)
- **AI:** Claude API — 재무제표 PDF 계정과목 추출, 리포트 문장 생성, 사업계획서 초안
- **계산 엔진:** 세금·주식가치 계산은 AI가 아닌 **검증 가능한 코드(테스트 포함)** 로 작성 — 숫자는 틀리면 안 되므로
- **PDF:** 서버에서 HTML → PDF 렌더링 (설계사 브랜딩 적용)
- **결제:** 토스페이먼츠 정기결제
- **외부 데이터(추후):** 기업정보 API, 홈택스 연동(CODEF 등, 고객 동의 기반)

## 9. 데이터 모델 (초안)

```
advisors (설계사)        ─┐
companies (기업)          ├─ advisor_id 로 격리
  ├ financial_statements (연도별 재무제표, 계정과목 JSON)
  ├ shareholders         (주주명부: 이름, 관계, 지분율, 취득가)
  ├ officers             (임원: 직위, 보수, 재직기간)
  ├ articles_checklist   (정관 항목별 보유 여부)
  ├ certifications       (보유/목표 인증)
  ├ family_members       (상속 시뮬용 가족관계)
  ├ simulations          (모듈별 계산 결과 스냅샷)
  └ reports              (생성된 리포트 PDF, 공유 링크)
tax_parameters (연도별 세율·공제 한도 설정 테이블)
consents (고객 정보 이용 동의 기록)
```

## 10. 함께 결정해야 할 것 (다음 논의)

1. MVP 첫 모듈 우선순위 — 현재 실제 영업에서 **가장 많이 쓰는 대화 소재**가 무엇인지 → **가결산을 최우선으로 확정** (10~12월 시즌성, 매년 반복 방문 명분)
2. 초회 면담 리포트 샘플 — 지금 쓰고 계신 자료(엑셀/PPT)가 있으면 그 구조를 기준으로 템플릿화
3. 재무제표 입력 방식 — 업로드 자동추출 vs. 핵심 계정 20개 수기 입력(초기엔 수기가 더 빠르고 정확할 수 있음)
4. 상담 환경 — 노트북/태블릿 중 실제 대표님 앞에서 무엇을 쓰는지
5. 판매 채널 — 개인 설계사 직접 판매 vs. GA 제휴
