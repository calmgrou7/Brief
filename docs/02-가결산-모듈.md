# 가결산 모듈 상세 설계 (v0.1)

> 10월 무렵 **재무상태표 + 손익계산서**만으로 연말 재무구조를 미리 보고,
> 대표가 **올해 안에 할 일과 내년으로 넘길 일**을 정할 수 있게 돕는 모듈.
> 결과물은 ① 대표용 가결산 리포트 ② 회계사무실 협조 요청서 ③ 설계사 상담노트.

---

## 1. 연간 사이클 (영업 관점)

```
 9~10월            11~12월              다음해 1~3월          다음해 4~9월
 가결산 진단  →  결산 전 조치 실행  →  결산·법인세 신고  →  실적 대비 점검(반기)
 (리포트 제출)    (매출·매입·대출·      (회계사무실에 목표     (다음 가결산 준비)
                  증자/감자·지분)       비율 전달)
```

같은 기업을 매년 같은 시기에 다시 찾아갈 이유가 생기므로, 이 모듈은 **설계사 앱을 계속 구독할 이유**가 됩니다.

## 2. 입력

| 구분 | 필수/선택 | 형태 | 비고 |
|---|---|---|---|
| 가결산 기준일 재무상태표 | 필수 | 업로드(PDF·엑셀) 또는 핵심 계정 수기 입력 | 회계사무실 **합계잔액시산표**도 받도록 지원 (현장에서 가장 흔히 넘어오는 자료) |
| 가결산 기준일 누적 손익계산서 (1월~기준월) | 필수 | 동일 | |
| 전기(작년) 결산 재무제표 | 필수 | 동일 | 연환산 패턴 + 추정 현금흐름 계산에 사용 |
| 전전기 결산 재무제표 | 선택 | 동일 | 3개년 추세 |
| 대표 예상치 (남은 기간 매출·대형 매입·대출 계획) | 선택 | 질문지 | 비어 있으면 자동 연환산 |
| 진단 목적 | 필수 | 선택 (복수 가능) | 아래 4장 |

**최소 입력용 핵심 계정 (수기 입력 시 약 20개)**
- 재무상태표: 현금성자산, 매출채권, 재고자산, 가지급금(단기대여금), 기타 유동자산, 유형자산, 무형자산, 기타 비유동자산 / 매입채무, 단기차입금, 유동성장기부채, 가수금, 기타 유동부채, 장기차입금, 퇴직급여충당부채, 기타 비유동부채 / 자본금, 이익잉여금(결손금), 기타 자본
- 손익계산서: 매출액, 매출원가, 판매비와관리비(인건비 따로), 영업외수익, 이자비용, 기타 영업외비용, 법인세비용

## 3. 연말 예상치 산출 (연환산)

설계사가 세 가지 방식 중 하나를 고르고, 결과를 나란히 보여줍니다.

| 방식 | 계산 | 맞는 업종 |
|---|---|---|
| 단순 연환산 | 누적 실적 × 12 / 경과 월수 | 매출이 고른 업종 |
| 전년 패턴 | 누적 실적 ÷ (전년 같은 기간 비중) | 계절성 있는 업종 (전년 월별 자료가 있을 때) |
| 대표 예상 | 누적 실적 + 대표가 말한 남은 기간 예상치 | 수주·건설·대형 납품 |

- 재무상태표는 기준일 잔액을 그대로 연말로 보되, 연말 예상 이익(세후)만큼 이익잉여금을 늘림
- 법인세는 연도별 세율표(`tax_parameters`)로 **추정 법인세**를 계산해 반영

## 4. 진단 목적별 지표 세트

대표의 목적에 따라 **봐야 할 비율과 목표치가 다릅니다.** 목표치는 기본값을 두되 설계사가 수정 가능하게 하고, 기본값은 업계 통상 기준·기관 공고를 바탕으로 연 1회 검토합니다.

| 목적 | 핵심 지표 |
|---|---|
| 은행 대출(신규·연장) | 부채비율, 차입금의존도, 이자보상배율, 영업이익률, 가지급금 비중 |
| 정책자금·보증 | 자본잠식 여부, 부채비율, 이자보상배율, 매출성장률, 업종 평균 대비 |
| 관급 입찰·건설업 | 경영상태 평가 비율(부채비율·유동비율·자기자본·매출액순이익률 등), 실질자본금 |
| 인증(벤처·이노비즈 등) | 연구개발비 비중, 매출·자본 요건, 재무 결격사유 |
| 가업승계·지분 이전 | 순손익가치·순자산가치 → **비상장주식 평가액 변화** (모듈 ③과 연결) |

### 기본 지표 목록

| 분류 | 지표 | 계산식 |
|---|---|---|
| 안정성 | 부채비율 | 부채총계 ÷ 자본총계 |
| | 유동비율 | 유동자산 ÷ 유동부채 |
| | 당좌비율 | (유동자산 − 재고자산) ÷ 유동부채 |
| | 자기자본비율 | 자본총계 ÷ 자산총계 |
| | 차입금의존도 | 총차입금 ÷ 자산총계 |
| | 자본잠식률 | (자본금 − 자본총계) ÷ 자본금 |
| 수익성 | 매출액영업이익률 | 영업이익 ÷ 매출액 |
| | 매출액순이익률 | 당기순이익 ÷ 매출액 |
| | ROA / ROE | 당기순이익 ÷ 자산 / 자본 |
| | 이자보상배율 | 영업이익 ÷ 이자비용 |
| 성장성 | 매출액증가율, 영업이익증가율, 총자산증가율 | 전년 대비 |
| 활동성 | 매출채권회전일수, 재고자산회전일수 | 잔액 ÷ (매출 또는 원가) × 365 |
| 자산 건전성 | 가지급금 비중, 인정이자 추정액 | 가지급금 ÷ 자산총계 / 가지급금 × 인정이자율 × 경과일 |

신호등 표시: 🟢 목표 충족 / 🟡 경계(목표 대비 일정 범위 이내) / 🔴 미달

## 5. 추정 현금흐름표 (회계사무실 자료 없이)

회계사무실에서 현금흐름표가 잘 넘어오지 않는 문제를 **간접법으로 자동 추정**해 해결합니다.

```
영업활동 현금흐름 ≈ 당기순이익(누적) + 감가상각비
                  − 매출채권 증가 − 재고자산 증가 + 매입채무 증가 ± 기타 운전자본 변동
투자활동 현금흐름 ≈ −(유형·무형자산 증가 + 감가상각비) − 가지급금 증가
재무활동 현금흐름 ≈ 차입금 증감 + 증자 − 감자 − 배당
검증: 기초 현금 + 위 합계 ≈ 기준일 현금 (차이는 '기타'로 표시)
```

- 리포트에는 **"추정치"** 로 명시
- 대표에게 보여줄 메시지: "이익은 났는데 돈이 어디로 갔는지" (매출채권·재고·가지급금으로 묶인 돈)

## 6. 시나리오 레버 (핵심 기능)

대표 앞에서 슬라이더·입력값을 바꾸면 **지표가 바로 다시 계산**됩니다. 각 레버의 회계 처리:

| 레버 | 재무상태표 영향 | 손익 영향 | 주로 좋아지는 것 / 나빠지는 것 |
|---|---|---|---|
| 매출 추가 (현금/외상 선택) | 현금 또는 매출채권 ↑ | 매출·이익 ↑ → 법인세 ↑ | 수익성·성장성 ↑ / 세금 ↑, **주식가치 ↑** |
| 매입 추가 — 재고 | 재고자산 ↑, 현금↓ 또는 매입채무 ↑ | 없음 (판매 전) | 거의 영향 없음 — 오해가 많은 부분이라 명시 |
| 비용 추가 — 원가·판관비 | 현금↓ 또는 미지급 ↑ | 이익 ↓ → 법인세 ↓ | 세금·주식가치 ↓ / 수익성·대출 평가 ↓ |
| 대출 실행 (단기/장기, 올해/내년) | 현금 ↑, 차입금 ↑ | 이자비용 ↑ (실행 시점부터) | 유동성 ↑ / 부채비율·차입금의존도 ↑ |
| 대출 상환 | 현금 ↓, 차입금 ↓ | 이자비용 ↓ | 부채비율 ↓ / 유동성 ↓ |
| 유상증자 | 현금 ↑, 자본금 ↑ | 없음 | 부채비율 ↓, 자본잠식 해소 |
| 유상감자 | 현금 ↓, 자본 ↓ | 없음 | 주주에게 자금 회수 / 부채비율 ↑ (의제배당 과세 검토 필요 표시) |
| 무상감자 | 자본금 ↓, 결손금 ↓ (자본총계 동일) | 없음 | 자본잠식률 개선 |
| 주주 변동 (양도·증여) | 변동 없음 | 없음 | 비율 영향 없음 → **지분율·주식가치·세금은 모듈 ③④로 연결** |
| 가지급금 정리 (상환·상여·배당·퇴직금 등) | 가지급금 ↓ | 방식별 비용 처리 | 자산 건전성 ↑ / 방식별 대표 소득세 표시 |

### 반드시 보여줄 상충 관계

> **이익을 늘리면 대출·정책자금엔 유리하지만, 법인세와 비상장주식 가치가 올라 승계·증여엔 불리하다.**

시나리오 화면에서 "대출 평가 지표"와 "주식가치·세금"을 **한 화면에 나란히** 보여주는 것이 이 앱의 차별점입니다. 대표가 어느 쪽을 우선할지 고르면, 그 방향으로 추천 액션을 정리합니다.

### 시나리오 비교

- 최대 3개 시나리오(A: 현재 유지 / B: 대출 확보형 / C: 승계 대비형 등)를 저장해 표로 비교
- 각 시나리오에 **올해 안에 / 내년 상반기** 실행 시점 표시

## 7. 출력물

### ① 대표용 가결산 리포트 (6~8쪽)
1. 한 장 요약 — 연말 예상 핵심 지표 신호등 + 대표님께 드리는 세 줄 결론
2. 3개년 추이 + 올해 예상
3. 목적별 목표 대비 차이
4. 돈의 흐름 (추정 현금흐름)
5. 시나리오 비교와 추천 액션 (올해 / 내년)
6. 다음 점검 일정, 고지 문구 ("시뮬레이션 자료이며 실제 결산·신고는 세무대리인 확인")

### ② 회계사무실 협조 요청서 (1쪽)
- 대표 명의로 전달하는 형식
- "올해 결산 시 아래 비율 유지를 목표로 검토 부탁드립니다" + 목표 지표표 + 확인 요청 사항(가지급금 처리, 감가상각 방법, 결산 조정 항목)
- 설계사가 세무 판단을 대신하지 않고 **회계사무실과 협업하는 구조**로 만들어 법적 리스크와 회계사무실 반발을 줄임

### ③ 설계사 상담노트 (대표에게는 보이지 않음)
- 질문 스크립트 ("올해 남은 기간 큰 수주 계획 있으세요?")
- 연결 가능한 후속 상담 주제 (주식 이동, 임원 퇴직금 규정, 상속세 재원)

## 8. 화면 구성 (MVP)

1. **자료 입력** — 업로드 또는 핵심 20개 계정 입력, 전기 자료 불러오기
2. **연말 예상** — 연환산 방식 선택, 예상 재무제표
3. **진단 대시보드** — 목적 선택 → 지표 신호등, 3개년 추이 그래프
4. **시나리오** — 레버 조정, 상충 관계 패널, A/B/C 저장
5. **리포트** — 대표용·회계사무실용·상담노트 PDF 출력

## 9. 계산 엔진 원칙

- 모든 계산은 **순수 함수 + 단위 테스트** (입력 재무제표 → 지표·시나리오 결과)
- 시나리오 레버마다 **차변·대변이 맞는지(자산 = 부채 + 자본)** 자동 검증
- 세율·인정이자율·목표 기본값은 연도별 설정표에서 읽음 — 코드 수정 없이 매년 갱신
