# 채움 업그레이드 로드맵 (ver2.0 이후, 아이디어 단계)

## 1. 고객 관리 — 두 단계로 나눈다

| 단계 | 내용 | 필요한 것 | 난이도 |
|---|---|---|---|
| **1단계: 기기 안 고객 관리** | 고객 목록 대시보드, 상담 단계·다음 일정·메모, 연도별 재무제표 보관(결산·가결산), 백업/복원 파일 | 없음 (지금 구조 그대로) | 중 |
| **2단계: 클라우드 고객 관리** | 로그인, 어느 기기에서나 같은 고객 자료, 자동 백업, 설계사별 데이터 격리, 이후 구독 결제 | 호스팅(웹 주소), DB(Supabase 등), 개인정보 처리방침·동의 절차 | 중상 |

### 고객 대시보드 구성(안)
- 상단 요약: 관리 고객 수 · 이번 달 상담 예정 · 가결산 미진행 고객 · 경고 지표가 많은 고객
- 고객 표: 회사 · 대표 · 진단 목적 · 최근 진단일 · 미달 지표 수 · 상담 단계 · 다음 일정
- 상담 단계: 첫 면담 → 자료 수령 → 진단 완료 → 제안 → 실행 관리 → 연간 관리
- 연간 관리 일정 자동 생성: 3월 확정 결산 점검 · 9~10월 가결산 · 12월 결산 전 실행 확인

## 2. 컨설팅 기능 — 넣을 것

| 우선 | 기능 | 영업 연결 |
|---|---|---|
| 1 | **연도별 히스토리**: 확정 결산 추가 → 3개년 추이, 가결산 예측 vs 실제 결산 비교 | 매년 다시 찾아갈 명분, 신뢰 |
| 2 | **가지급금 심화**: 인정이자, 정리 방법별(상환·급여·상여·배당·퇴직금·자기주식) 법인·대표 세금 비교, 정리 로드맵 | 가장 많이 걸리는 문제 |
| 3 | **임원 퇴직금·정관 점검**: 정관 규정 체크리스트, 퇴직금 지급 한도·예상액 계산 | CEO 퇴직 재원 |
| 4 | **상속·증여 시뮬레이션**: 상속세 추정, 납부 재원 부족액 | 상속세 재원 니즈 |
| 5 | **정책자금·인증 체크리스트**: 자금별 결격 사유, 벤처·이노비즈·연구소 요건 자가진단 | 장기 관계 |
| 6 | **고객 공유 링크**: 대표에게 리포트 읽기 전용 링크 전달 | 카톡 전달 편의 |

## 3. 넣지 않을 것(또는 조심할 것)
- 세무조정 수준의 정밀 신고 계산 — 세무사 영역(세무사법), 앱은 "진단·시뮬레이션"까지
- 리포트 안 보험 상품명·설계 연동 — 금융소비자보호법, 리포트는 "재원 부족액"까지
- 홈택스 직접 로그인·스크래핑 — 보안·인증 부담, 필요하면 나중에 정식 API
- 모듈 과다 — 1인 운영 유지보수 부담, 실제 상담에서 쓰는 것만
