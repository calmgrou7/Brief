# 로타리클럽 사무장용 회원관리 서비스 기획안 (v2)

> PLANNING.md(범용 단체 버전)를 **로타리클럽 전용**으로 구체화한 문서
> 판매 대상: 로타리클럽 사무장 (예: 영도 로타리, 금강산 로타리 등)
> 가격: **클럽당 월 50,000원** 정액 구독
> 작성일: 2026-11-11

---

## 1. 서비스 정의

"신입 회원 입회부터 회원 수첩, 연락처 공유, 입회비·연회비 관리, 행사 관리까지
사무장님 업무를 하나로 묶은 **로타리클럽 전용 사무국 프로그램**."

## 2. 사업성

| 클럽 수 | 월 매출 | 월 운영비(예상) | 비고 |
|---|---|---|---|
| 5곳 | 25만 원 | 약 5만 원 | 파일럿 이후 첫 목표 |
| 20곳 | 100만 원 | 약 7만 원 | 지구 내 입소문 단계 |
| 50곳 | 250만 원 | 약 10~15만 원 | 지구 단위 소개 확보 시 |

- 로타리는 **지구 단위**(한 지구에 수십 개 클럽)로 묶여 있고 사무장님끼리 교류가 많아서, 한 클럽에서 성공 사례가 나오면 같은 지구로 퍼지기 쉬운 구조입니다.
- 멀티테넌트(서버 하나에 여러 클럽) 구조라 클럽이 늘어도 운영비는 거의 늘지 않습니다.

## 3. 로타리에 맞춘 설계 포인트

| 항목 | 반영 내용 |
|---|---|
| **회기** | 로타리 회기(7/1 ~ 다음 해 6/30)에 맞춰 임원 접근 코드 만료일을 **6월 30일**로 설정. 회장·임원이 바뀌는 시점에 권한도 자연스럽게 정리됨 |
| **회원 항목** | 성명, **아호**, 직업분류, 사업체명·직함, 입회일, **추천인(스폰서)**, 생년월일, 배우자 이름·결혼기념일(선택), 연락처, 이메일, 주소, 얼굴 사진, 명함 앞뒷면 |
| **직책** | 회장, 직전회장, 차기회장, 총무, 재무, 이사, 위원장 등 회기별 직책 이력 |
| **연혁** | 역대 회장, 클럽 창립일, 주요 봉사 활동, 자매클럽 |
| **행사** | 주회(정기 모임), 이사회, 봉사활동, 지구대회, 회장 이·취임식 |

## 4. 핵심 기능

### 4-1. QR 셀프 입회 등록
1. 사무장이 클럽 전용 **입회 QR**(또는 링크)을 생성
2. 신입 회원이 휴대폰으로 QR을 스캔해서 **본인 정보 입력, 얼굴 사진·명함 촬영 업로드**
3. 개인정보 수집 동의와 회원 간 공유 동의를 체크
4. 사무장 화면에 **"승인 대기"**로 표시되고, 확인 후 승인하면 정식 회원으로 등록
5. 승인되면 회원 카드·수첩·연락처 파일에 자동으로 반영

- 기존 회원 정보를 고칠 때는 **회원별 1회용 수정 링크**를 카톡으로 보내서 본인이 직접 최신화
- QR 링크는 유효기간(예: 7일)과 횟수 제한을 걸어 외부 유출에 대비

### 4-2. 회원 자료 내보내기
| 형식 | 용도 |
|---|---|
| **PDF 회원 수첩** | 전체 회원을 사진 + 아호 + 직업분류 + 연락처로 정리한 책자형 PDF. 인쇄용 |
| **PNG 회원 카드** | 회원 1명당 이미지 1장. 카톡으로 바로 공유 (신입 회원 소개용으로 특히 좋음) |
| **연락처 파일(vCard .vcf)** | 열면 휴대폰 연락처에 바로 저장됨. **개별 저장** 또는 **전체 회원 일괄 저장** 모두 지원. 사진·직함·회사명 포함 |
| **회원 카드 속 QR** | 회원 카드 이미지에 QR을 넣어서, 찍으면 연락처가 바로 저장되게 함 |
| **엑셀** | 사무장이 언제든 전체 명단을 내려받을 수 있음 (데이터 종속 걱정을 줄여 영업에 유리) |

- 연락처 이름 형식 옵션: `홍길동 (영도RC)`처럼 클럽명을 붙여 저장 → 휴대폰에서 클럽별로 찾기 쉬움
- PDF·PNG에는 클럽 로고와 "회원 외 배포 금지" 워터마크 옵션 제공

### 4-3. 입회비·회비 현황
- 청구 항목: **입회비, 연회비(반기/분기), 특별회비, 행사비**
- 회원별 청구액, 납부액, 납부일, 납부 방식, 잔액
- 대시보드: 이번 회기 **납부율**, **미납자 목록**, 신입 회원 입회비 현황
- **미납 안내 자동 발송**: 일정 기한이 지나면 카톡/문자/메일로 정중한 안내 문구 발송 (사무장 승인 후 발송 옵션)
- **은행 거래내역 엑셀 업로드 → 입금자명·금액으로 자동 매칭** (자동화 포인트. 사무장님 수작업 대폭 감소)
- 1차에서는 실제 결제(카드 수납)는 넣지 않고 **기록·현황 관리**만 함. 계좌이체 문화에 맞추고 결제 수수료와 규제 부담을 피함

### 4-4. 신입 회원 현황
- 이번 회기 신입 회원 수, 추천인별 입회 실적, 입회 단계(가입 신청 → 승인 → 입회식 → 입회비 납부)를 한눈에

### 4-5. 행사 관리
- 주회·이사회·봉사활동 캘린더, 참석 여부 체크(출석률), 행사 사진
- 행사가 끝나면 연혁에 자동 기록
- (2차) 회원 생일·결혼기념일 알림 → 사무장이 축하 문자를 놓치지 않음

### 4-6. 접근 권한
| 역할 | 권한 |
|---|---|
| 운영자(나) | 전체 클럽 관리, 백업, 장애 대응 |
| 사무장 | 모든 기능 |
| 회장·임원 | 열람 + 내보내기 (회기 종료일까지) |
| 일반 회원 | 로그인 없음. QR로 본인 정보 입력·수정만 가능 |

## 5. 백업과 운영 관리 (운영자 콘솔)

- **자동 백업 2중 구조**
  1. DB 서비스(Supabase Pro) 자체 일일 백업
  2. 매일 새벽 별도 저장소(예: Cloudflare R2 / AWS S3)로 **DB 덤프 + 사진 파일 자동 백업**, 30일 보관
- **운영자 콘솔**: 클럽별 회원 수, 저장 용량, 마지막 접속일, 구독 결제 상태, 오류 로그를 한 화면에서 확인
- **클럽 단위 복원**: 사무장이 실수로 삭제해도 특정 클럽 데이터만 되돌릴 수 있게 설계
- 삭제는 바로 지우지 않고 **휴지통(30일)**으로 이동

## 6. 개인정보 (로타리 버전 주의점)

- 회원 수첩·연락처 파일을 **전체 회원에게 나눠 주는 것**이 핵심 기능이라, 입회 시 **"회원 간 연락처 공유 동의"**를 꼭 따로 받아야 함
- 동의하지 않은 회원은 수첩·연락처 파일에서 자동으로 제외하거나 연락처를 가림
- 클럽(사무장)이 개인정보 처리자, 서비스(나)는 처리 수탁자 → 이용약관에 위탁 조항 포함
- 사진·명함 파일은 비공개 저장, 서명된 URL로만 열람

## 7. 구독 요금 구성

| 구분 | 내용 |
|---|---|
| 기본 | 월 50,000원 (회원 수 무제한, 임원 계정 15개) |
| 연간 결제 | 50만 원 (2개월 할인), 세금계산서 발행 |
| 도입 지원 | 첫 달 무료 + **기존 엑셀 명단·사진 이전 대행** (도입 장벽 제거) |
| 옵션 | 문자·알림톡 발송비는 사용량만큼 실비 |

> 클럽 회계는 회기 단위라 **7월 회기 시작에 맞춘 연간 결제** 제안이 가장 자연스럽습니다.

## 8. 개발 순서

| 단계 | 기간 | 내용 |
|---|---|---|
| 0. 인터뷰 | 1주 | 사무장님 2~3명: 현재 회원 명부 양식, 회비 관리 방식, 수첩 제작 방식 확인 |
| 1. MVP | 5~6주 | 회원 카드, QR 셀프 입회, PDF/PNG/vCard 내보내기, 회비 현황, 행사 캘린더, 자동 백업 |
| 2. 파일럿 | 2개월 | 1개 클럽 무료 운영. 명단 이전 직접 지원 |
| 3. 확장 | 이후 | 은행 내역 자동 매칭, 알림톡, 출석률, 생일 알림, 같은 지구 클럽 영업 |

## 9. 결정이 필요한 질문

1. 첫 파일럿 클럽은 어디로 할지 (그 클럽의 현재 회원 명부가 기본 양식이 됨)
2. 회비 항목과 납부 주기 (연 1회 / 반기 / 분기)
3. 미납 안내를 **자동 발송**할지, **사무장 확인 후 발송**할지
4. 회원 수첩 PDF 디자인을 클럽마다 다르게 할지, 공통 디자인 1종으로 할지
