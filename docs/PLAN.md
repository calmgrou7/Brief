# 정우회 회원 플랫폼 — 기획서 v0.1

> 작성일: 2026-11-10 · 상태: 초안 (결정 필요 항목은 §10 참고)

## 1. 한 줄 정의

**정우회 기업가 대표들이 서로의 회사·제품을 한눈에 보고, 운영진은 회원·임원·행사·자료를 대시보드 한 곳에서 관리하는 비공개 회원 플랫폼.**

### 목표
| 구분 | 목표 |
|---|---|
| 회원 | 다른 회원의 회사/제품/연락처를 명함 카드처럼 빠르게 찾고, 사업 연결(소개·거래)을 늘린다 |
| 운영진 | 엑셀·카톡으로 흩어진 회원명부, 추천(가디언) 이력, 임원 직책, 행사 자료를 한 곳으로 모은다 |
| 자동화 | 추천 횟수 집계, 직책 이력, 회원 카드 생성, 행사 아카이브를 **수작업 없이** 자동 반영한다 |

### 지금 쓰는 자료 → 플랫폼 기능 매핑
| 현재 (이미지 자료) | 플랫폼에서 |
|---|---|
| 회원 소개 카드 (사진·출생연도·회사 이미지·명함·제품·입회연도·추천회원) | **회원 프로필 카드** (§4-3) |
| 입회월/회원/추천인 엑셀 표 | **회원명부** (§4-2) — 필터·정렬·엑셀 내보내기 |
| 추천인별 횟수 표 | **가디언 랭킹** (§4-4) — DB에서 자동 집계, 손으로 세지 않음 |

## 2. 사용자 역할과 권한

| 역할 | 누구 | 할 수 있는 것 |
|---|---|---|
| **관리자(운영자)** | 사무국/총무, 플랫폼 운영 담당 | 전체 CRUD, 회원 승인·탈퇴, 임원 직책 변경, 권한 부여 |
| **임원** | 회장·부회장·총무·감사 등 | 행사 등록/자료 업로드, 연혁 작성, 회원 정보 열람 |
| **일반회원** | 정회원 | 본인 프로필 수정, 회원명부·프로필 열람, 행사·연혁·자료 열람 |
| (선택) 예비회원 | 추천받아 가입 대기 중 | 본인 프로필 작성만 가능, 승인 후 정회원 전환 |

- 권한은 **"회원 구분(임원/일반)"과 "시스템 권한(관리자 여부)"을 분리**한다. 임원이 바뀌어도 관리자 권한은 별도로 유지/회수 가능.
- 외부 비공개: 로그인한 회원만 접근 (회원 정보는 개인정보이므로 공개 페이지 없음).

## 4. 화면별 기능 정의

### 4-1. 대시보드 (홈)
- **KPI 카드**: 총 회원 수 · 올해 신규 입회 · 임원 수 · 다음 행사 D-day
- **월별 입회 추이** 막대 차트 (예: 2026.03 6명 / 06 6명 / 07 3명 / 08 5명 / 09 2명 / 10 1명)
- **가디언 TOP 5** (예: 김동관 8회, 김상원·김영진·정일태·황시완 각 2회)
- **최근 입회 회원** 카드 3~5개
- **다가오는 행사** 리스트 + 최근 업로드된 자료

### 4-2. 회원명부
- 보기 전환: **표(엑셀형)** ↔ **카드(명함형)**
- 컬럼: 사진 · 이름 · 회사명 · 업종/제품 · 구분(임원/일반) · 직책 · 입회월 · 가디언
- 필터: 입회연도/월, 구분(임원/일반), 업종, 가디언
- 검색: 이름·회사명·제품 키워드 ("위생용품" 검색 → 박홍진/영진종합유통)
- 내보내기: 엑셀(.xlsx), PDF 회원수첩 (인쇄용)

### 4-3. 회원 프로필 카드 (상세)
현재 쓰는 소개 카드 레이아웃을 그대로 웹으로 옮긴다.

```
┌──────────────┬──────────────┐
│   [인물사진]   │  [회사 이미지]  │
│    박홍진      │    1981       │   ← 이름 / 출생연도
├──────────────┴──────────────┤
│         [명함 이미지]           │   ← 클릭 시 확대
├─────────────────────────────┤
│ 회사   영진종합유통  · 영업이사      │
│ 제품   위생용품, 일회용품, 식품 등   │
│ 연락처  ☎ / ✉ / 주소 (권한별 노출)  │
├────────┬──────┬────────┬─────┤
│ 입회연도 │ 2026 │ 추천회원 │ 김상원 │  ← 가디언 클릭 시 해당 회원으로 이동
├────────┴──────┴────────┴─────┤
│ 구분: 일반회원   직책: -           │
│ 이 회원이 추천한 회원: (자동 목록)   │
└─────────────────────────────┘
```
- 회원 본인이 수정 가능 / 구분·직책·가디언은 관리자만 수정
- **"카드 이미지로 저장"** 버튼 → 지금처럼 PPT·카톡에 붙여 쓰는 소개 카드 PNG 자동 생성

### 4-4. 가디언 (추천인)
- **가디언 = 신규 회원을 추천한 기존 회원** (추천회원 필드)
- **랭킹 표**: 추천인 · 횟수 · 추천한 회원 목록 — `members.guardian_id` 기준 **자동 집계** (지금의 횟수 표를 대체)
- **추천 관계 트리**: 김동관 → 전기철 → 이성호 처럼 추천이 이어지는 계보 시각화
- 참고: 현재 자료상 김동관·김상원·김영진 등 일부 추천인은 회원 목록(2026 입회)에 없음 → **창립/기존 회원도 회원으로 등록**해야 연결이 끊기지 않음 (§10)

### 4-5. 임원진
- **현 임원 조직도**: 회장 → 부회장 → 총무/감사/사무국장 …
- **직책 변경**: 관리자가 회원 선택 → 직책·임기 시작일 지정 → 저장
  - 변경 시 이전 직책은 자동으로 **이력(종료일 기록)** 으로 이동 → "역대 임원" 페이지 자동 생성
- 직책 목록은 설정에서 추가/삭제/순서 변경 가능 (하드코딩 X)

### 4-6. 행사 (연간)
- **연간 캘린더 / 리스트** (정기총회, 월례회, 송년회, 워크숍 등)
- 행사별 보관 항목:
  - 기본정보: 일시·장소·주관 임원·참석 인원
  - **문구**: 초대 문자, 공지문, 인사말 (텍스트 그대로 복사 가능)
  - **서류**: 예산안, 결산서, 회의록, 참석자 명단 (PDF/엑셀/한글)
  - **사진**: 행사 사진 앨범
- "작년 행사 복제" 기능 → 매년 반복되는 행사는 문구·체크리스트를 그대로 가져와 날짜만 수정

### 4-7. 연혁·히스토리
- 연도별 타임라인 (창립, 회장 취임, 주요 행사, 회원 수 돌파 등)
- 행사·임원 변경 이력에서 **자동으로 연혁 항목 후보 생성** → 임원이 확인만 하면 게시

### 4-8. 자료실 (외부 저장소)
- 파일 원본은 **외부 저장소**에 두고 플랫폼은 메타데이터(제목·분류·연도·링크)만 관리
- 저장소 옵션 (§6): Supabase Storage(기본) 또는 Google Drive 공유 폴더 연동

## 5. 데이터 모델 (초안)

```
members                 회원
├ id, name, birth_year, photo_url
├ company_name, company_image_url, business_card_url
├ title_in_company      (예: 영업이사)
├ products              (예: 위생용품, 일회용품, 식품 등)
├ industry, phone, email, address, website
├ joined_at             (입회월, 예: 2026-08)
├ guardian_id  ──────▶ members.id   (추천회원, 자기참조)
├ member_type           ('officer' | 'regular' | 'pending')
├ status                ('active' | 'inactive')
└ user_id  ──────────▶ auth.users  (로그인 계정)

positions               직책 마스터 (회장, 부회장, 총무, 감사 …)
├ id, name, sort_order

officer_terms           임원 임기/직책 이력
├ id, member_id, position_id
├ started_at, ended_at  (ended_at NULL = 현직)

events                  행사
├ id, title, category, starts_at, location, host_member_id
├ notes (문구/공지 텍스트), attendee_count

event_attendees         행사 참석자 (member_id, event_id)

documents               자료 (행사 서류, 회칙, 양식 등)
├ id, title, category, year, event_id (nullable)
├ storage_provider ('supabase' | 'gdrive'), file_url, uploaded_by

history_items           연혁
├ id, date, title, description, source ('manual' | 'event' | 'officer')

v_guardian_ranking      (뷰) guardian별 추천 횟수 자동 집계
```

- **임원/일반 구분**은 `officer_terms`에 현직(ended_at IS NULL) 기록이 있으면 임원으로 자동 판정 → 수동 플래그 불일치 방지
- **직책 변경 = 기존 행 종료 + 새 행 추가** → 이력 자동 보존

## 6. 기술 스택 추천 (1인 운영 기준)

운영자 혼자 유지보수할 수 있도록 **서버 관리 0, 월 비용 최소**를 기준으로 고름.

| 영역 | 추천 | 이유 |
|---|---|---|
| 프론트 | **Next.js + Tailwind + shadcn/ui** | 대시보드 UI 빠르게 구성, 모바일 대응 |
| DB·로그인·파일 | **Supabase** (Postgres + Auth + Storage) | 회원 로그인(카카오/이메일 매직링크), 권한(RLS), 파일 저장 한 번에. 무료 티어로 시작 가능 |
| 배포 | **Vercel** 또는 **Render** | Git push = 자동 배포 |
| 외부 저장소(선택) | Google Drive 공유 폴더 | 기존 자료가 드라이브에 있다면 링크 연동 |
| 알림(2단계) | 카카오 알림톡 / 이메일 | 행사 공지·신규 회원 알림 자동 발송 |

## 7. 자동화 포인트 (운영 시간 줄이는 부분)

| # | 자동화 | 효과 |
|---|---|---|
| A1 | **엑셀 일괄 업로드** — 지금 쓰는 회원명부 엑셀을 그대로 올리면 회원·가디언 관계 자동 생성 | 초기 이관 1회로 끝 |
| A2 | **가디언 횟수 자동 집계** | 추천 횟수 표 수작업 제거 |
| A3 | **명함 사진 → 정보 자동 입력** (AI OCR) — 명함만 찍어 올리면 회사명·직함·연락처 채움 | 신규 회원 등록 1분 |
| A4 | **회원 소개 카드 PNG 자동 생성** | 행사 PPT·카톡 소개 자료 제작 시간 제거 |
| A5 | **직책 변경 → 이력·연혁 자동 기록** | 역대 임원표 따로 관리 안 함 |
| A6 | **작년 행사 복제** + D-7 / D-1 공지 자동 발송 | 반복 행사 준비 시간 단축 |
| A7 | **회원수첩 PDF 원클릭 출력** | 연말 회원수첩 제작 자동화 |

## 8. 단계별 로드맵

| 단계 | 범위 | 산출물 |
|---|---|---|
| **1단계 MVP** (2~3주) | 로그인, 회원명부(표/카드), 회원 프로필 카드, 가디언 랭킹, 임원 구분·직책 변경, 엑셀 업로드(A1·A2·A5) | 회원들이 실제로 접속해 명부를 보는 상태 |

## 10. 결정이 필요한 항목

1. **창립/기존 회원 등록 범위** — 추천인 중 김동관·김상원·김영진·김현식·신동찬·황성광·고영득·노승권·전효찬·정일태·황시완은 2026 입회 명단에 없음. 기존 회원 명단도 함께 등록할지?
2. **로그인 방식** — 카카오 로그인 vs 이메일 매직링크 vs 관리자가 발급한 ID/비밀번호
3. **연락처 공개 범위** — 회원 간 전화번호 전체 공개 / 임원만 / 본인 선택
4. **임원 직책 목록** — 회장·부회장·총무·감사 외 사용하는 직책
5. **자료 저장소** — Supabase Storage로 새로 시작 vs 기존 Google Drive 폴더 연동
6. **도메인·이름** — 예: jungwoo.kr 등 사용 여부
7. **회비 관리** 포함 여부 (현재 범위 밖, 3단계 이후 후보)
