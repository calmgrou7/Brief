# 수학의 신 (God of Math) — 서비스 기획서

> 책과 이론으로 겨루는 수학 — 중학교부터 연구실까지
> 버전 0.1 (MVP 프로토타입) · 2026-11

## 1. 한 줄 정의
일반적인 계산 연습이 아니라 **고전 교재와 정리(theorem)에 근거한 문제**를 한국어·영어로 풀고, Elo 레이팅으로 순위를 다투며, 고레벨 사용자가 직접 문제를 **출제·심사하는 '수학연구원'** 등급까지 올라가는 수학 커뮤니티 게임 앱.

## 2. 타깃 사용자
| 세그먼트 | 니즈 | 진입 단계 |
|---|---|---|
| 수학을 좋아하는 중·고등학생 | 교과서 밖의 '진짜 수학', 친구와 경쟁 | 중등·고등 |
| 수학과·공대 학부생 | 전공 개념 복습, 과 친구와 대결 | 학부 |
| 대학원생·연구원 | 취미로 다른 분야 정리 탐험, 출제로 기여 | 대학원·연구 |
| 수학 애호가(직장인) | 출퇴근 길 5분 두뇌 운동 | 전 단계 |

## 3. 핵심 기능 (MVP 구현 완료)
1. **회원가입/로그인** — 닉네임·이메일·비밀번호 (데모는 로컬, 운영은 Supabase Auth)
2. **5단계 문제은행** — 중등 / 고등 / 학부 / 대학원 / 연구, 40문항. 각 문항에 *근거 책·이론*(예: Euclid *Elements* VII, Sylow 정리, Kervaire–Milnor) 표기, KaTeX 수식, 힌트·해설 한/영
3. **채점 유형** — 수치(분수 입력 `-1/12` 가능), 객관식, 단답
4. **레벨 · XP** — 레벨 L 누적 XP = `25·L·(L−1)`. 첫 정답에만 XP, 오답·해설 미리보기 시 감액, 연속 학습(스트릭) 보너스
5. **레이팅(Elo)** — 사용자 vs 문제 난이도. 미해결 문제에만 반영 → 반복 풀이로 점수 파밍 불가
6. **레이팅 대결** — 5문제 × 90초, 정답 100점 + 남은 초. 승/무/패 Elo(K=32) + XP
7. **랭킹** — 레이팅 / 경험치 / 연구원(승인 문제 수) 3종, 포디움 + 내 순위
8. **연구소 (출제 · 심사)** — Lv.10부터 문제 출제, 다른 출제자들이 심사(승인/반려+의견)
9. **연구원 트랙** — 레벨과 별개의 칭호: 승인 3개 *수학연구원* → 10개 *수석연구원* → 25개 *펠로우*
10. **다국어** — 한국어/English 즉시 전환, 문제·해설 모두 이중 언어

## 4. 등급 체계
| 레벨 | 칭호 | 권한 |
|---|---|---|
| 1–4 | 입문자 Novice | 풀이·대결 |
| 5–9 | 탐구자 Explorer | — |
| 10–14 | 출제자 Composer | **출제·심사 권한** |
| 15–19 | 증명가 Prover | (예정) 심사 가중치 ×2 |
| 20+ | 석학 Scholar | (예정) 시즌 문제 큐레이션 |

연구원 트랙(별도 배지): 승인 문제 수 3 / 10 / 25 → 수학연구원 / 수석연구원 / 펠로우

## 5. 점수 설계 근거
- **XP**(누적, 성실도) 와 **레이팅**(실력, 오르내림)을 분리 → 오래 한 사람과 잘하는 사람 모두 보상
- 문제마다 레이팅이 있어서 사용자 실력에 맞는 '이어서 풀기' 추천이 자동으로 됨
- 커뮤니티 문제가 풀릴 때마다 출제자 +5 XP → 좋은 문제를 만들 동기

## 6. 화면 구성 (IA)
```
랜딩/로그인
└─ 홈 (레벨 링, 레이팅·스트릭·해결·정확도, 오늘의 문제, 빠른 대결, 이어서 풀기, 단계별 진행)
   ├─ 문제 (단계 탭: 전체/중등/고등/학부/대학원/연구/커뮤니티) → 문제 풀이
   ├─ 대결 (로비 → 매칭 → 5라운드 → 결과 · 최근 전적)
   ├─ 랭킹 (레이팅/경험치/연구원)
   ├─ 연구소 (잠김 화면 | 문제 출제 · 심사 · 내 출제)
   └─ 프로필 (칭호, 통계, 단계별 해결, 언어, 로그아웃)
```
모바일은 하단 탭바, 데스크톱은 상단 내비게이션.

## 7. 디자인 시스템
- 로고 컬러에서 가져온 색: 딥그린 `#123F33`, 라임 `#DCFB7B`, 스파크 화이트 `#FAF8EF`
- 기본은 다크 테마(로고와 같은 분위기), 기기 설정이 라이트면 라이트 테마 자동 적용
- 단계별 색: 중등 하늘 / 고등 초록 / 학부 골드 / 대학원 오렌지 / 연구 퍼플 / 커뮤니티 라임
- 서체: Pretendard(한글) + KaTeX(수식) + 모노(점수)

## 8. 기술 구조
| 영역 | MVP (현재) | 운영 단계 |
|---|---|---|
| 프런트 | React 18 + TypeScript + Vite, PWA 매니페스트 | 동일 + Capacitor로 iOS/Android 앱 출시 |
| 데이터 | `src/lib/store.ts` (localStorage) | Supabase (`supabase/schema.sql`) — 같은 함수 시그니처로 교체 |
| 인증 | SHA-256 + salt 로컬 계정 | Supabase Auth (이메일, Google, Apple, 카카오) |
| 채점 | 클라이언트 | **서버 함수 `submit_answer`** — 정답이 클라이언트로 노출되지 않음 |
| 대결 | 레이팅 기반 AI 상대 | Supabase Realtime 채널로 실시간 1:1 매칭 |
| 배포 | 정적 호스팅 (Vercel/Netlify/GitHub Pages) | 동일 |

## 9. 1인 운영 자동화 포인트
1인 사업자가 운영 인력 없이 굴러가게 하는 장치들:
1. **콘텐츠 자동 공급** — 출제·심사를 커뮤니티가 맡음. 운영자는 반려 이의제기만 확인
2. **AI 1차 검수** — 출제가 들어오면 Claude API로 정답 검증·중복 확인·번역 초안 생성 → 사람 심사자는 최종 승인만 (Supabase Edge Function + DB 트리거)
3. **시즌 자동화** — 매월 1일 레이팅 시즌 리셋 + 상위권 배지 지급을 스케줄 작업(pg_cron)으로
4. **리텐션 자동화** — 스트릭이 끊기기 전날 푸시 알림, 주간 랭킹 리포트 이메일
5. **지표 대시보드** — DAU, 문항별 정답률(너무 쉽거나 어려운 문제 자동 표시), 대결 매칭 대기시간

## 12. 콘텐츠 원칙 (저작권)
- 교재 원문·연습문제를 **그대로 옮기지 않는다**. 정리·이론을 근거로 새로 쓴 문제만 수록하고 '근거'로 출처를 밝힌다.
- 커뮤니티 출제 시 약관에 "본인 창작 또는 퍼블릭 도메인"을 명시하고 신고 기능을 둔다.
