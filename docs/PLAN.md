# 진로산사 — 테스트 버전(v0.1) 기획서

> "나는 어떤 사람이 될까? 나는 무엇을 해야 할까?"
> 중·고등학생이 하루 한 질문씩, 조용히 걸으며 스스로 답을 찾아가는 온라인 진로 코칭 공간

---

## 1. 왜 '산사 느낌'인가

온라인 절 '산사'가 사흘 만에 60만 명을 모은 이유를 진로 코칭에 그대로 옮깁니다.

| 산사의 성공 공식 | 진로산사에 적용 |
|---|---|
| 가입·설치 없이 바로 입장 | 링크 하나로 입장, 자동 닉네임 (개인정보 수집 0) |
| 행동 하나로 끝나는 단순한 의식 (절하기) | **숨 고르기 → 질문 하나 → 종 치기** 3분 의식 |
| 혼자지만 함께하는 느낌 (법당 정원 100명) | "지금 N명이 함께 생각하는 중" + 다른 사람이 종을 칠 때 등불이 켜짐 |
| 채팅 없음 → 고요함, 악성 댓글 없음 | 학생 간 텍스트 교류 없음 (미성년자 안전) |
| 108배 카운터 → 반복 방문 동기 | 7알 염주(7일 과정) + 완주 시 '나의 길 카드' |

진로 고민은 무겁습니다. 학생들은 "꿈이 뭐야?"라는 질문에 부담을 느끼죠.
**질문을 잘게 쪼개고, 고르기만 해도 답이 되게 하고, 결과를 부드러운 코칭 문장으로 돌려주는 것**이 핵심입니다.

## 2. 타깃과 사용 상황

- **주 사용자**: 중학교 2학년 ~ 고등학교 2학년. 진로를 정하지 못했거나, 정했지만 막연한 학생
- **구매자/도입자(향후)**: 진로 코치(1인 사업자 본인), 학원, 진로전담교사, 학부모
- **사용 상황**: 하교 후 / 잠들기 전 3~5분, 진로 수업 시간에 다 같이

## 3. 사용자 흐름 (하루 3~5분)

```
산문(입구) ─▶ 숨 고르기(3회) ─▶ 오늘의 질문 ─▶ 종 치기 ─▶ 길잡이의 한마디 ─▶ 염주(진행 현황)
                                  (칩 선택 + 한 줄 쓰기)        (코칭 피드백 + 오늘의 작은 실천)
                                                                         │
                                                         7일째 완주 ─▶ 나의 길 카드 (이미지 저장)
```

## 4. 7일 커리큘럼 — "나 → 원하는 것 → 할 일"

| 일차 | 주제 | 질문 | 얻는 것 |
|---|---|---|---|
| 1 | 흥미 | 시간 가는 줄 모르고 했던 일은? | 흥미 영역(RIASEC) |
| 2 | 강점 | 친구들이 나에게 자주 부탁하는 것은? | 강점, 흥미 보정 |
| 3 | 가치 | 내 삶에서 가장 중요한 것 3가지는? | 가치관 |
| 4 | 에너지 | 언제 에너지가 차오르나요? | 일하는 방식 선호 |
| 5 | 롤모델 | 닮고 싶은 사람, 그 이유는? | 되고 싶은 모습 |
| 6 | 미래의 나 | 10년 뒤 평범한 하루, 어디서 무엇을? | 일의 환경 |
| 7 | 첫 걸음 | 이번 주 할 수 있는 가장 작은 한 걸음은? | 실행 계획 |

- 각 질문은 **선택 칩(최대 3개)** + **한 줄 쓰기(선택)** 로 구성 → 글쓰기 부담 없이 답할 수 있음
- 흥미·강점 칩은 홀랜드 RIASEC 6유형에 매핑 → 완주 시 어울리는 분야·학과 예시 제안
  (진단이 아닌 **대화의 출발점**으로 표현하고, 커리어넷 정식 검사로 연결)

## 5. v0.1 기능 범위

### 포함 (이번 테스트 버전)
- [x] 자동 닉네임 ("고요한 은행나무"), 가입 없음
- [x] 숨 고르기 애니메이션 (건너뛰기 가능)
- [x] 7일 질문, 선택 칩 + 한 줄 쓰기
- [x] 종 치기 (Web Audio로 합성한 종소리, 파일 불필요) + 등불 켜짐
- [x] 규칙 기반 코칭 피드백 + 오늘의 작은 실천
- [x] 염주(7알) 진행 표시, 하루 한 질문씩 열림
- [x] 완주 시 '나의 길 카드' (흥미/강점/가치/롤모델/미래/첫 걸음 + 추천 분야) → PNG 저장, 텍스트 복사
- [x] "함께 하는 느낌": Supabase Realtime 설정 시 실시간 동시 접속 수, 다른 사람의 종소리 → 등불
      (설정 없으면 '혼자 걷는 중'으로 정직하게 표시)
- [x] 테스트 모드 (`?test=1`): 하루 제한 없이 7일을 바로 체험

### 제외 (다음 버전으로)
- 로그인 / 서버 저장 (지금은 **답변이 학생 기기에만 저장**됨 → 개인정보 이슈 없음)
- AI 코칭 (Claude API) — v0.2
- 코치용 대시보드, 학부모 리포트 — v0.3
- 결제 — v0.3

## 6. 미성년자 안전 & 개인정보 원칙

- 만 14세 미만은 개인정보 수집 시 법정대리인 동의가 필요 → **v0.1은 아무 개인정보도 서버로 보내지 않음**
- 학생 간 텍스트 공유·채팅 없음 (산사처럼 '고요함'이 기능이자 안전장치)
- 실시간 기능은 닉네임(자동 생성)과 '종을 쳤다'는 신호만 주고받음
- 위기 신호(자해 등) 대응: 자유 서술에서 위험 키워드 감지 시 청소년상담 1388 안내 (v0.1 포함)

## 7. 테스트 계획 (1~2주)

| 단계 | 대상 | 방법 | 확인할 것 |
|---|---|---|---|
| 1차 | 지인 학생 5~10명 | `?test=1`로 7일 몰아서 체험 후 인터뷰 | 질문이 이해되는지, 칩이 충분한지, 피드백이 와닿는지 |
| 2차 | 학생 30명 내외 | 실제 하루 1질문으로 7일 | **완주율**, 재방문율, 카드 저장/공유율 |
| 3차 | 진로 수업 1반 | 수업 시간에 동시 입장 | 실시간 '함께하는 느낌' 반응 |

**성공 기준(가설)**: 7일 완주율 30% 이상, 카드 저장 50% 이상, "다음에도 하고 싶다" 60% 이상
