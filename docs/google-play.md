# 구글플레이 출시 가이드 — 기업지원사업

웹앱(PWA)을 **TWA(Trusted Web Activity)** 로 감싸 안드로이드 앱으로 등록합니다.
앱 안의 화면은 Render에 배포된 웹앱 그대로 사용하므로, **웹을 고치면 앱도 자동으로 바뀝니다** (재심사 불필요).

---

## 전체 일정 한눈에

| 단계 | 소요 | 비용 |
|---|---|---|
| 0. Render 배포 완료 (HTTPS 주소) | 완료 후 진행 | 월 약 $7 |
| 1. 구글플레이 개발자 계정 | 1~3일 (본인 인증) | **$25 1회** |
| 2. PWABuilder로 앱 파일(.aab) 생성 | 30분 | 무료 |
| 3. 앱-도메인 연결 (assetlinks) | 10분 | — |
| 4. 스토어 정보·정책 설문 입력 | 1~2시간 | — |
| 5. **비공개 테스트 12명 × 14일** (개인 계정만) | 2주+ | — |
| 6. 프로덕션 심사 | 보통 1~7일 | — |

> ⚠️ **개인 개발자 계정**은 정식 출시 전 **테스터 12명 이상이 14일 연속** 비공개 테스트에 참여해야 합니다.
> **조직(사업자) 계정**은 이 조건이 없지만 **D-U-N-S 번호**(무료, 발급 수일~수주)가 필요합니다.
> 사업자등록증이 있으니 **조직 계정을 권장**합니다. 신뢰도도 높고(개발자명에 상호 노출), 테스트 2주를 건너뜁니다.

## 1단계. 개발자 계정 만들기

1. https://play.google.com/console 접속 → 사업용 구글 계정으로 로그인
2. 계정 유형 선택
   - **조직** (권장): 상호, 사업자 주소, D-U-N-S 번호 입력
     D-U-N-S 번호가 없으면 → 화면 안내 링크에서 무료 신청 (한국은 NICE평가정보 대행)
   - **개인**: 신분증 인증만으로 가능하지만 위의 12명·14일 테스트 필요
3. 등록비 $25 결제 → 본인/사업자 인증 완료 대기

## 2단계. PWABuilder로 앱 파일 만들기

1. https://www.pwabuilder.com 접속
2. Render 앱 주소 입력 (예: `https://policy-fund-app-xxxx.onrender.com`) → **Start**
3. 점수 화면에서 **Package For Stores** → **Android** → **Generate Package**
4. 옵션 입력:

| 항목 | 입력값 |
|---|---|
| Package ID | `kr.chaeum.policyfund` (한 번 정하면 변경 불가 — 회사 도메인 역순 권장) |
| App name | 기업지원사업 |
| Launcher name | 기업지원사업 (12자 이내) |
| Signing key | **Create new** (기본값) |

5. **Download** → zip 파일 안에:
   - `app-release-signed.aab` ← 구글플레이에 올릴 파일
   - `assetlinks.json` ← 3단계에서 사용
   - `signing.keystore` + `signing-key-info.txt` ← **절대 잃어버리면 안 됨!**
     구글 드라이브 비공개 폴더 + USB 등 **두 군데 이상 백업**하세요. 분실 시 앱 업데이트 불가.

## 3단계. 앱-도메인 연결 (주소창 숨기기)

이걸 안 하면 앱 상단에 브라우저 주소창이 보여 "웹사이트 같은 앱"이 됩니다.

1. 구글플레이 콘솔에서 앱을 만든 뒤 **설정 → 앱 무결성 → 앱 서명** 메뉴의
   **SHA-256 인증서 지문**을 복사 (Play 앱 서명 키)
2. PWABuilder가 준 `assetlinks.json`을 메모장으로 열고, `sha256_cert_fingerprints` 배열에
   위 지문을 **추가** (기존 값은 유지 → 지문 2개)
3. Render → 서비스 → **Environment** → `ASSETLINKS_JSON` 값에 파일 내용 전체를 붙여넣기 → 저장(자동 재배포)
4. 확인: 브라우저에서 `https://내주소/.well-known/assetlinks.json` 열어 내용이 보이면 성공

## 4단계. 스토어 등록 정보

### 앱 만들기
- 기본 언어: 한국어 / 앱 또는 게임: **앱** / 무료
- 카테고리: **비즈니스** (금융 X — 금융 카테고리는 추가 심사·서류 요구가 많음)

### 짧은 설명 (80자 이내) — 복사용
```
3분 기업진단으로 우리 회사 맞춤 정책자금 찾기. 새 공고 주간 알림과 전문가 상담까지.
```

### 자세한 설명 — 복사용
```
※ 본 앱은 민간 컨설팅 서비스이며 정부·공공기관과 관련이 없습니다.
※ 공고 정보 출처: 기업마당(https://www.bizinfo.go.kr) 및 각 기관 공식 홈페이지

■ 3분 기업상태 진단
업종·업력·직원 수·매출·자금 용도 등 12개 문항에 답하면, 신청 가능성이 높은 정책자금을 적합도 순으로 보여드립니다.
소상공인시장진흥공단, 중소벤처기업진흥공단, 신용보증기금, 기술보증기금, 지역신용보증재단, 지자체 육성자금 등을 한 번에 확인하세요.

■ 우리 지역 진행 중인 공고
사업장 소재지에 맞는 정책자금 공고를 마감일(D-day)과 함께 보여드립니다.

■ 매주 새 공고 알림
관심 지역과 분야를 설정하면 매주 월요일 새로 나온 공고를 알려드립니다.

■ 정책지원마스터 1:1 상담
서류 준비, 사업계획서 작성, 보증·대출 연계가 어려우시면 상담을 신청하세요. 담당 전문가가 연락드립니다.

[안내]
- 정책자금의 승인 여부는 각 기관의 심사로 결정되며, 본 서비스는 승인을 보장하지 않습니다.
- 자금 조건은 매년 공고에 따라 달라질 수 있으니 반드시 해당 기관 공고를 확인하세요.
```

## 5단계. 정책 설문 (앱 콘텐츠) — 답변 가이드

| 설문 | 답변 |
|---|---|
| 개인정보처리방침 | `https://내주소/privacy` |
| 광고 포함 | 아니요 |
| 앱 액세스 권한 | 모든 기능 제한 없이 이용 가능 (관리자 페이지는 앱 기능 아님) |
| 콘텐츠 등급 | 설문 진행 → 폭력·선정성 등 모두 "아니요" → **전체이용가** |
| 타겟층 | **18세 이상** |
| 뉴스 앱 | 아니요 |
| 정부 앱 | **아니요** (정부기관이 개발·운영하지 않음) |
| 금융 기능 | "개인 대출" 제공 안 함 → **해당 없음/기타** 선택. 대출을 직접 실행·중개하지 않고 정보·상담만 제공함을 명시 |
| 건강 앱 | 아니요 |

### 데이터 보안(Data safety) 답변
- 데이터 수집: **예** / 전송 중 암호화: **예** (HTTPS) / 삭제 요청 방법 제공: **예** (개인정보처리방침 7항)
- 수집 항목:

| 데이터 유형 | 항목 | 목적 | 필수 여부 |
|---|---|---|---|
| 개인 정보 | 이름 | 앱 기능(상담 연락) | 선택 (상담 신청 시에만) |
| 개인 정보 | 전화번호 | 앱 기능(상담 연락) | 선택 |
| 개인 정보 | 이메일 주소 | 앱 기능, 마케팅(동의 시) | 선택 |
| 앱 활동 | 기타 사용자 생성 콘텐츠(진단 응답·문의 내용) | 앱 기능, 분석 | 선택 |
| 기기 ID | 기기 또는 기타 ID (익명 기기ID, 푸시 토큰) | 앱 기능(알림) | 필수 |

- 제3자 공유: **사용자 동의 시에만** 협력 기관에 제공 → "공유함"에 체크하고 사유 기재
  (제3자 제공 동의 기능을 실제로 안 쓸 계획이면 "공유 안 함")

## 6단계. 테스트 → 출시

1. **테스트 → 비공개 테스트** → 트랙 만들기 → `.aab` 업로드
2. 테스터 이메일 목록 추가 (지인 대표님들 12명 이상) → 참여 링크 공유
3. (개인 계정) 14일 경과 후 **프로덕션 액세스 신청** → 설문 작성
4. **프로덕션** → 새 버전 만들기 → 같은 `.aab` 업로드 → 국가: 대한민국 → 검토 제출

## 심사 거절 주의 포인트 (이 앱 특유)

1. **정부 사칭** — 앱 이름에 "정책", "지원사업"이 있어 공공앱으로 오인될 수 있습니다.
   앱 홈 하단·신청 폼·개인정보처리방침·스토어 설명에 "민간 서비스, 정부기관 아님 + 출처"를 이미 넣어뒀습니다.
   아이콘에 태극 문양이나 정부 로고를 쓰지 마세요. 정식 앱 이름은 `○○ 정책자금 진단` 처럼 **민간 브랜드명 포함**을 권장합니다.
2. **"승인 보장", "100% 대출"** 등 표현 금지 (스토어·앱 모두).
3. 서버가 꺼져 있으면 심사자가 빈 화면을 보고 거절 → 심사 기간에는 Render가 정상인지 확인.
4. 개인정보처리방침 URL이 열리지 않으면 거절.

## 앱 업데이트

- 화면·기능 수정: **웹만 배포하면 끝** (앱 재심사 불필요)
- 아이콘·앱 이름·패키지 설정 변경 시에만 PWABuilder에서 **같은 signing.keystore로** 다시 생성 →
  버전 코드를 올려 업로드
