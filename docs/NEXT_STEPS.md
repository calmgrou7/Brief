# 다음 작업 (우선순위 순)

각 항목은 독립 브랜치/PR로 진행하고 `npm test`·`npm run build` 통과 필수.

## B1. 만료 알림 캘린더(.ics) 내보내기
- `GET /api/calendar.ics`: 도메인 만료·SSL·서버 갱신일·프로젝트 마감일 이벤트, 30일/7일 전 VALARM.
- UID는 `레코드ID-종류`로 고정(재가져오기 중복 방지). 구글 캘린더 구독용 비밀 토큰 URL 옵션.
- 완료 기준: 구글 캘린더 가져오기 성공, 테스트로 ICS 형식 검증.

## B2. 출시 이력 자동 기록 API
- `POST /api/hooks/releases` + `RELEASE_HOOK_TOKEN` 환경변수(Bearer). 본문은 기존 병합 포맷.
- GitHub Actions 예시 워크플로(`docs/examples/release-hook.yml`): 태그 push 시 호출.
- 완료 기준: 토큰 없거나 틀리면 401, 맞으면 병합. 테스트 포함.

## B3. 단계별 세부 체크리스트
- `Stage.tasks?: {label, done}[]`. 토스 검수 요청 전 필수 항목 템플릿. 진행률 계산 옵션.
- `sanitize()`에서 하위호환 유지.

## B4. 검색·필터
- 프로젝트·도메인·계정 검색, 상태 필터(검수중만 보기 등).

## B5. 보관함 강화
- 마스터 비밀번호 변경(복호화 → 새 salt로 재암호화), 비밀번호 변경일 90일 경과 경고.

## B6. 메일 알림 (선택)
- 매일 1회 다음 절차 요약 메일. 메일 발송 서비스 계정 결정 필요 → **사용자 확인 후 진행**.

## B7. 클라우드 DB 전환 (선택)
- 팀/고객 공유가 필요해질 때 Supabase로 전환. 보관함은 암호문 그대로 저장. **사용자 승인 후 진행**.
