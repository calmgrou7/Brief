# 인생실록 홈페이지 · 관리자 "단가·마진 관리" 메뉴 기획 (v0.1)

> 목적: 홈페이지에 공개하는 **단가표**와, 관리자만 보는 **원가·마진율**을 한 곳에서 관리한다.
> 원칙: 고객에게는 판매가만, 원가·마진은 관리자 로그인 뒤에서만.

---

## 1. 메뉴 구조

```
관리자
└─ 단가·마진 관리
   ├─ ① 단가표 (상품 목록 + 마진 한눈에)   ← 기본 화면
   ├─ ② 상품 편집 (판매가·구간 단가·구성 자재)
   ├─ ③ 자재 관리 (견적서·주문내역 단가 등록)
   └─ ④ 설정 (과세유형·수수료·시급·목표 원가율)
```

메뉴 4개가 많으면 MVP는 **①+②만** 만들고, 자재는 ② 안에서 바로 입력해도 된다.

---

## 2. 화면별 기획

### ① 단가표 (기본 화면)
상품별로 한 줄. 판매가를 바꾸면 그 자리에서 마진이 다시 계산된다.

| 상품 | 공개 | 판매가 | 세트 원가 | 전체 원가율 | 세트당 이익 | 상태 |
|---|---|---|---|---|---|---|
| 인생실록 기본 세트 | ● | 85,000 | 24,772 | 35.7% | 49,696 | 안정 |
| 10세트 이상 (10%↓) | ● | 76,500 | 24,772 | 39.2% | 42,249 | 안정 |
| 30세트 이상 (20%↓) | ● | 68,000 | 24,772 | 43.7% | 34,802 | 빠듯함 |
| 50세트 이상 (25%↓) | ○ | 63,750 | 24,772 | 46.4% | 31,079 | 빠듯함 |

(예시: 자재 16,272원 + 조립·포장·배송 8,500원, 자사몰 결제수수료 3.3%, 일반과세자. 구간 할인율은 예시값)

- 상단 요약: 평균 원가율, 목표 미달 상품 수, 최근 원가 변경일
- 상태: 안정(≤40%) / 빠듯함(≤55%) / 위험(>55%) / 손해(이익 ≤ 0)
- "공개" 토글 → 홈페이지 단가표 노출 여부
- 채널 선택(자사몰 / 스마트스토어 / 오프라인 강의) → 수수료 바꿔서 마진 비교

### ② 상품 편집
| 영역 | 항목 |
|---|---|
| 기본 | 상품명, 설명(홈페이지 노출용), 대표 이미지, 공개 여부, 정렬 순서 |
| 가격 | 소비자가(VAT 포함), **수량 구간 단가** (예: 1~9 / 10~29 / 30~ ) |
| 구성 자재 | 자재 선택 + 세트당 사용량 (예: 질문카드 1세트, 편지지 10장, 봉투 10장) |
| 추가 비용 | 조립·포장 시간(분), 포장재·배송비, 광고·기타 |
| 결과 패널 | 원가 3기준(첫 생산분 / 실제 투입 / 재주문), 원가율, 최저 판매가, 할인 가능 폭, 목표 원가율 추천가 |

- 저장 시 **가격·원가 이력**을 남김 → "언제 얼마로 바꿨고 그때 마진은 몇 %였나" 확인
- 구간 단가가 최저 판매가보다 낮으면 저장 전에 경고

### ③ 자재 관리
| 자재명 | 거래처 | 구분 | 총금액(공급가) | 구매수량 | 단위 원가 | 재고 | 최근 변경 |
|---|---|---|---|---|---|---|---|
| 질문카드 35종 | 인쇄소 | 개당 | 368,000 | 40 | 9,200 | 0 | 10/30 |
| 케이스 목형 | 인쇄소 | 1회성 | 80,000 | 100세트분 | 800 | — | 11/05 |

- 구분: **1회성**(목형·동판·샘플) / **회차 기본**(톰슨·금박 기본료) / **개당**
- 자재 단가를 바꾸면 → 그 자재를 쓰는 **모든 상품 원가 자동 재계산**
- 재주문 시 "새 견적 등록"으로 이력 보관 (단가 상승 추적)

### ④ 설정
과세유형(일반/간이 + 업종 부가가치율), 채널별 수수료, 기본 시급, 목표 원가율(기본 40%), 경고 기준.

---

## 3. 홈페이지(고객) 쪽 단가표

- 관리자에서 **공개** 켠 상품과 구간 단가만 노출
- 노출 항목: 상품명, 구성, 판매가, 수량별 단가, "단체·기관 문의" 버튼
- **원가·마진 데이터는 고객용 API 응답에 아예 포함하지 않음** (화면에서 숨기는 것만으로는 부족)

---

## 4. 데이터 구조 (어떤 사이트든 공통)

```
settings        과세유형, 부가가치율, 시급, 목표 원가율, 채널별 수수료
materials       id, 이름, 거래처, 구분(once/run/unit), 총금액, 구매수량, 재고, 수정일
products        id, 이름, 설명, 이미지, 공개여부, 정렬, 소비자가,
                조립분, 포장배송비, 기타비용
product_items   product_id, material_id, 세트당 사용량          ← 구성 자재(BOM)
price_tiers     product_id, 최소수량, 판매가 (또는 할인율), 공개여부
price_history   product_id, 일시, 판매가, 세트원가, 원가율       ← 변경 이력
```

계산 로직은 테스트 앱(`apps-script/Index.html`의 `calcSet`)을 그대로 재사용한다.

---

## 5. 자동화 포인트 (1인 운영)

1. 자재 단가 변경 → 연결 상품 원가 일괄 재계산 → 목표 원가율 넘은 상품 **이메일/카톡 알림**
2. 주문 들어올 때 그 시점 원가 스냅샷 저장 → 월말 "실제 매출 기준 마진" 리포트 자동 생성
3. (이후) 인쇄소 주문내역 엑셀 업로드 → 자재 단가 자동 갱신

---

## 6. 단계별 범위

| 단계 | 범위 | 예상 |
|---|---|---|
| P1 | ① 단가표 + ② 상품 편집(구성 자재는 상품 안에서 직접 입력), 관리자 전용 | 3~5일 |
| P2 | 홈페이지 공개 단가표 연동 + 구간 단가 + 가격 이력 | 3일 |
| P3 | ③ 자재 마스터 분리, 원가 변경 알림, 주문 연동 월간 마진 리포트 | 1주 |

## 7. 결정 필요 사항
1. 인생실록 사이트가 무엇으로 만들어졌는지 (직접 개발 코드 / 아임웹·카페24·식스샵 등 빌더 / 구글 사이트)
   - 직접 개발: 관리자 라우트 + DB 테이블 추가
   - 빌더: 관리자 기능은 별도 앱(구글 시트 + Apps Script)으로 두고, 공개 단가표만 임베드
2. 판매 채널: 자사몰만인지, 스마트스토어·강의 현장 판매도 있는지
3. 구간 단가(단체·기관 판매) 운영 여부와 할인율
