# 단가·마진 계산기 미니앱 기획서 (v0.1)

> 대상: 1인 샵·소상공인·프리랜서 등 초기 개인사업자
> 목표: "적정가라고 생각했는데 실은 손해"인 상황을 **3분 안에** 숫자로 보여주고, 손해 안 보는 단가표를 만들게 돕는다.

---

## 1. 문제 정의 — 사장님들이 손해 보는 진짜 이유 5가지

| # | 흔한 실수 | 실제 영향 |
|---|---|---|
| 1 | **마진율과 마크업(원가 대비 이익률)을 혼동** | 원가 10,000원에 "30% 남기자" → 13,000원. 실제 마진율은 23.1%. 30%를 남기려면 14,286원 |
| 2 | **본인 인건비를 0원으로 계산** | 재료비만 원가로 봄 → "90% 남는다"고 착각 |
| 3 | **고정비(임대료·관리비·구독료 등)를 건당으로 나누지 않음** | 월말에 통장이 비는 이유 |
| 4 | **부가세를 내 돈으로 착각** | 받은 가격의 1/11(일반과세자)은 원래 국가 몫 |
| 5 | **카드·플랫폼 수수료, 재료 로스율 누락** | 건당 1~15%가 조용히 사라짐 |

**사례 (네일샵, 일반과세자)**
- 재료비 3,000원 / 시술 60분 / 목표 시급 15,000원
- 월 고정비 100만원 ÷ 월 120건 = 건당 8,333원
- 카드수수료 1.5%
- **총원가 = 26,333원**

| 판매가(VAT 포함) | 사장님 생각 | 실제 순이익(건당) | 실제 마진율 |
|---|---|---|---|
| 30,000원 | "재료비 3천원이니 90% 남음" | **약 490원** | 약 1.8% |
| 37,000원 (앱 추천가) | — | 약 6,700원 | 목표 20% 달성 |

→ 이 "충격 비교" 화면이 앱의 핵심 가치이자 마케팅 소재.

## 2. 핵심 계산 로직

### 2-1. 건당 총원가
```
총원가 C = 재료비 × (1 + 로스율)
         + 소요시간(시간) × 목표 시급          ← 본인 인건비
         + 월 고정비 ÷ 월 예상 판매(시술) 건수   ← 고정비 배분
         + 기타 건당 변동비(포장·배송 등)
```

### 2-2. 적정 판매가 (마진율 기준, 마크업 아님)
```
공급가 기준 목표 마진율 m, 결제/플랫폼 수수료율 f

[일반과세자 · 소비자가에 VAT 포함]
  판매가 P = C ÷ ( (1 − m) ÷ 1.1 − f )

[간이과세자]
  납부세액 ≈ 판매가 × 업종별 부가가치율(15~40%) × 10%
  판매가 P = C ÷ ( 1 − m − f − 업종부가가치율×0.1 )   (근사)

[면세사업자]
  판매가 P = C ÷ ( 1 − m − f )
```

### 2-3. 결과 화면에 보여줄 3가지 숫자
1. **최저가 (손익분기 단가)** — m = 0 일 때. "이 밑으로 받으면 손해"
2. **적정가** — 목표 마진율 적용 + 보기 좋은 단위(1,000원/500원)로 반올림
3. **월 손익분기 건수** — 월 고정비 ÷ (건당 판매가 − 건당 변동비)

### 2-4. 업종별 기본값(프리셋)
| 업종 | 기본 목표 마진율 | 기본 수수료 | 비고 |
|---|---|---|---|
| 뷰티(네일·속눈썹·헤어) | 25~35% | 카드 1.5% | 시간 비중 큼 |
| 공방·핸드메이드 | 30~40% | 스마트스토어 등 5~6% | 재료 로스율 10% 기본 |
| 식음료(카페·디저트) | 15~25% | 배달앱 10~15% | 원재료비율 30% 가이드 |
| 강의·컨설팅·콘텐츠 | 40~60% | 결제 3~4% | 준비시간 포함 |
| 프리랜서(디자인·촬영) | 30~50% | 플랫폼 10~20% | 수정 횟수 반영 |

> ※ 수수료·간이과세 기준(연 매출 1억 400만원 미만, 2024년 개정 기준)·업종별 부가가치율은 법령 개정에 따라 바뀌므로 **설정 파일 한 곳에서 관리**하고 화면에 "기준일"을 표시한다.

## 3. 사용자 흐름 (무료 버전)

```
[1] 업종 선택 ─▶ [2] 상품/서비스 1개 입력 ─▶ [3] 내 시간·고정비 ─▶ [4] 결과
   (프리셋 자동)     재료비, 소요시간          목표 월수입, 월 고정비,     최저가 / 적정가
                                             월 예상 건수, 과세유형      손익분기 건수
                                                                        "지금 가격" 진단
```

- 입력 항목은 **최대 7개**, 모르는 값은 프리셋 기본값으로 채워둔다.
- "목표 시급"을 모르는 분을 위해 → "한 달에 얼마 벌고 싶으세요? ÷ 월 근무시간" 자동 계산.
- 결과에서 **"지금 받는 가격"** 을 넣으면 실제 마진율을 빨강/노랑/초록 신호등으로 진단.
- 마지막에 결과 이미지 저장 + 카카오톡 공유 버튼 (바이럴 루프).

## 4. 무료 vs 유료 구분

원칙: **"한 개 계산"은 무료, "사업 전체 관리"는 유료.**

| 기능 | 무료 | 유료 (월 9,900원 / 연 79,000원 제안) |
|---|---|---|
| 상품 1개 적정가 계산 | ✅ | ✅ |
| 실제 마진율 진단(신호등) | ✅ | ✅ |
| 결과 이미지 저장·공유 | ✅ (워터마크) | ✅ (워터마크 없음) |
| **상품 여러 개 저장 → 단가표 완성** | 3개까지 | 무제한 |
| **단가표 PDF/이미지 출력** (매장 비치·인스타용 디자인) | ❌ | ✅ |
| 고정비 자동 배분 (상품별 판매 비중으로) | ❌ | ✅ |
| 가격 인상 시뮬레이션 ("5천원 올리면 몇 명 빠져도 괜찮나") | ❌ | ✅ |
| 재료비 변동 시 전 상품 단가 일괄 재계산 | ❌ | ✅ |
| 월 매출 입력 → 실제 이익 대시보드 | ❌ | ✅ |
| 견적서 자동 생성 (프리랜서·출장형) | ❌ | ✅ |
| 세금 예측 (부가세·종소세 대략 적립액 안내) | ❌ | ✅ |

### 추가 수익 라인 (2단계 이후)
1. **세무사·컨설턴트용 화이트라벨** — 상담 고객에게 자기 브랜드로 링크 제공 (월 5~10만원)
2. **1:1 가격 진단 컨설팅 업셀** — 결과 화면에서 "전문가 검토 받기" (건당 판매)
3. **소상공인 교육·지원사업 연계** — 지자체·창업센터 교육용 라이선스

> 1인 사업자 관점에서 가장 현실적인 순서: **무료 계산기로 리드 수집 → 컨설팅/교육 업셀 → 반복 매출(구독)**. 구독은 사용자가 수백 명 쌓인 뒤 붙여도 늦지 않다.

## 5. MVP 범위 (2~3주, 혼자서 가능)

### MVP-1 (1주): 무료 계산기 — 정적 웹 1페이지
- 섹션 2의 계산 로직 + 섹션 3의 4단계 흐름
- 업종 프리셋 5종, 과세유형 3종
- 결과 이미지 저장 / 카톡 공유
- **이메일(또는 카카오 채널) 입력 시 "상세 리포트 PDF" 발송** → 리드 수집 장치
- 서버 없음, 브라우저 저장(localStorage) — 운영비 0원

### MVP-2 (1~2주): 유료 단가표 기능 검증
- 로그인 + 상품 여러 개 저장 → 단가표 생성/출력
- 결제는 처음엔 **수동(계좌이체·스마트스토어 이용권)** 으로 검증 후 자동결제 연동
- 검증 지표: 무료 사용자 → 유료 전환 3% 이상이면 자동결제 붙이기

### 기술 스택 제안 (자동화·유지보수 최소화 기준)
| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트 | HTML + JS 단일 파일 → 이후 Next.js | 가장 빠르고 무료 호스팅 가능 |
| 호스팅 | Render / GitHub Pages | 이미 연결된 서비스 활용 |
| 회원·DB | Supabase | 로그인·DB·권한 한 번에, 무료 구간 충분 |
| 결제 | 토스페이먼츠 | 국내 정기결제 |
| 리드 자동화 | Zapier → 구글시트 + 이메일/카카오 발송 | 계산 완료 시 자동 후속 메시지 |
| PDF 출력 | 브라우저 인쇄 CSS 또는 html2pdf | 서버 불필요 |

## 6. 운영 자동화 설계 (1인 운영 기준)

```
사용자 계산 완료
   └─▶ (이메일 입력) ─▶ Zapier ─▶ 구글시트에 업종·가격·마진 기록
                                ├─▶ 즉시: 상세 리포트 메일 발송
                                ├─▶ D+3: "단가표 만들기" 유료 안내
                                └─▶ 실제 마진율 < 10% 인 사용자 → "무료 가격 진단 상담" 우선 안내
```
- 쌓이는 데이터(업종별 평균 단가·마진율)는 그 자체로 **콘텐츠 자산** — "2026 네일샵 평균 마진율 리포트" 같은 블로그/인스타 콘텐츠로 재활용.

## 10. [추가] 세트(BOM) 원가 모드 — 실제 사례 "인생실록" 세트

인쇄소 주문내역·견적서처럼 **여러 자재를 사서 한 세트를 조립하는 상품**은 "자재비 ÷ 수량"만으로는 원가가 틀어진다. 비용을 세 종류로 나눠야 한다.

| 구분 | 정의 | 사례 (케이스 견적, 공급가) |
|---|---|---|
| ① 1회성 개발비 | 재주문 시 다시 안 드는 비용 | 목형 80,000 + 동판 50,000 + 칼선·샘플 30,000 = **160,000원** |
| ② 회차당 기본비 | 주문할 때마다 수량과 무관하게 드는 비용 | 톰슨 기본 70,000, 금박 기본 80,000, 포장 작업비 30,000 |
| ③ 개당 변동비 | 수량에 비례 | 용지, 스티커, 트레싱지, 양면테이프, 질문카드, 안내카드 등 |

### 원가 기준 3가지 (모두 부가세 제외 공급가 기준)
| 기준 | 세트당 원가 | 용도 |
|---|---|---|
| A. 나간 돈 전부 ÷ 40 | 25,279원 | **첫 생산분 현금 회수선** (남는 자재가 안 팔려도 손해 없는 가격) |
| B. 40세트에 실제 들어간 자재만 | 18,672원 | **원가율·가격 책정 기준** (회계상 매출원가, 남은 자재는 재고자산) |
| C. 100세트까지 만들었을 때 | 16,272원 | 규모를 키웠을 때 목표 원가 |

### 판매가별 원가율 (VAT 포함 소비자가 기준)
| 판매가 | 공급가 | 원가율 A | 원가율 B | 원가율 C | B + 수수료 5.5% | 세트당 이익(B) |
|---|---|---|---|---|---|---|
| 39,000 | 35,455 | 71.3% | 52.7% | 45.9% | 58.7% | 14,638 |
| 49,000 | 44,545 | 56.7% | 41.9% | 36.5% | 48.0% | 23,178 |
| 59,000 | 53,636 | 47.1% | 34.8% | 30.3% | 40.9% | 31,719 |
| 69,000 | 62,727 | 40.3% | 29.8% | 25.9% | 35.8% | 40,260 |

목표 원가율로 거꾸로 계산: `판매가(공급가) = 세트원가 ÷ 목표원가율`
- B 기준 원가율 35% → 공급가 53,349원 → 소비자가 약 58,700원
- B 기준 원가율 30% → 공급가 62,240원 → 소비자가 약 68,500원

### 앱 기능화 (유료 핵심 기능 후보)
1. 인쇄소 주문내역 엑셀(다운로드 버튼)·견적서를 업로드 → 품목 자동 추출
2. 품목마다 ①/②/③ 분류 (목형·동판·샘플 등 키워드는 자동 추천)
3. 세트 구성 수량 입력 (예: 질문카드 35장, 편지지 n장, 봉투 n장)
4. 생산 수량별(40/100/300) 세트 원가 곡선 + 판매가별 원가율 표 자동 생성
5. "첫 생산분 회수선(A)"과 "정상 원가(B)"를 같이 보여주고, 판매가가 A보다 낮으면 경고
