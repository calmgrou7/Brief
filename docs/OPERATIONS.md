# 운영 문서

## 환경변수 (`.env.example` 참고)
| 키 | 설명 |
|---|---|
| `ADMIN_PASSWORD` | 관리자 로그인 비밀번호(12자 이상). **필수**. 미설정 시 서버가 시작되지 않음 |
| `SESSION_HOURS` | 로그인 유지 시간, 기본 12 |
| `DATA_DIR` | SQLite 저장 폴더. Render에서는 `/var/data/bridgenode`(영구 디스크) |
| `HOST` / `PORT` | 기본 `127.0.0.1:8787`. Render는 `0.0.0.0` |

## Render 배포
1. 이 저장소를 Render에 연결 → `render.yaml`(Blueprint) 적용.
2. Render 대시보드에서 `ADMIN_PASSWORD`를 직접 입력(저장소에 커밋 금지).
3. 배포 후 `/api/health`가 `{ "ok": true }`인지 확인.
4. 접속 → [백업·설정 → 예시 데이터 비우고 시작] → 실제 데이터 등록.
5. 기존 단일 HTML 버전을 쓰던 경우 그 백업 JSON을 [가져오기].
- 영구 디스크 없는 플랜에서는 재배포 시 데이터가 사라진다. 디스크(1GB) 필수.

## 백업
- 화면: [백업 내보내기]로 JSON 다운로드 → 드라이브 보관(주 1회 권장).
- 서버: `npm run db:backup [폴더]` → SQLite 온라인 스냅샷 + 무결성 검사.
- 계정 보관함은 두 방식 모두 암호문만 포함. 마스터 비밀번호는 별도 보관.

## 보안 수칙
- 관리자 비밀번호와 보관함 마스터 비밀번호를 서로 다르게.
- 공용 PC에서는 보관함 잠금 + 로그아웃.
- 백업 JSON, `.env`, `.data/`를 저장소에 커밋하지 않는다(`.gitignore` 적용됨).
- 저장소는 **비공개(private)** 로 유지.
