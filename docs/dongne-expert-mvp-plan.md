# 동네전문가 앱 — MVP 기획서 (v0.2)

> v0.2 변경: 🚦 전문가 신호등 레벨 시스템(6-A), 실버케어·1인가구 확장 로드맵(16) 추가

> 생활형 동네전문가(CCTV·인터넷·방수·열쇠·도배·이사 등)와 고객을 **실시간으로 연결**하는 플랫폼
> 오픈테스트 지역: **부산광역시** / 수익모델: **입점수수료 + 선결제(소개비) 수수료**
> 전제: 1인 운영 → **사람 손이 덜 가는 구조(자동화)를 MVP 단계부터 설계에 포함**

---

## 1. 서비스 한 줄 정의

"고객이 출장비(소개비)를 먼저 결제하면, 근처 전문가가 콜을 수락하고 반드시 방문한다.
추가 작업비는 현장에서 전문가가 직접 받는다."

### 핵심 원칙 3가지
| 원칙 | 내용 | 효과 |
|---|---|---|
| 선결제 = 소개비 | 고객이 출장비를 앱에서 먼저 결제 → 이게 매칭(연결) 비용 | 허위·장난 요청 차단, 플랫폼 수익 확보 |
| 수락 = 의무 | 전문가가 콜을 수락하면 무조건 방문. 미방문·노쇼 시 페널티 | 고객 신뢰 확보 |
| 추가금 = 현장 직거래 | 자재·추가작업비는 전문가가 현장에서 직접 수령 | 플랫폼은 정산 부담 최소화(1인 운영에 적합) |

## 2. 사용자 유형 (Role)

| 역할 | 설명 | 가입 시 필수 정보 |
|---|---|---|
| 고객 | 서비스를 요청하는 일반 사용자 | 휴대폰 본인인증, 이름, 기본 주소(부산 내), 약관 동의 |
| 전문가 | 출장 서비스를 제공하는 사업자/개인 | 본인인증, 사업자등록증(또는 개인 프리랜서 확인), 분야(복수 선택), 활동지역(구 단위), 경력·자격증, 프로필 사진, 정산계좌, 입점수수료 결제 |
| 관리자(나) | 운영자 | 관리자 웹 접근 권한 |

- 한 계정으로 고객/전문가 **전환 가능**하게 설계 (전문가도 다른 분야는 고객일 수 있음)
- 전문가는 **승인제**: 서류 제출 → 관리자 승인 → 활동 가능 (MVP는 수동 승인, 이후 OCR 자동검증)

## 3. 서비스 카테고리 (MVP)

부산 테스트에서는 **콜 빈도 높고 긴급성 있는 분야**부터 시작 권장.

| 1차 오픈 (긴급·고빈도) | 2차 확장 |
|---|---|
| 🔑 열쇠/도어락 | 🧱 도배·장판 |
| 💧 방수·누수 | 🚚 이사·용달 |
| 🚿 배관·하수구막힘 | 🧹 입주/이사 청소 |
| 📹 CCTV 설치·수리 | ❄️ 에어컨 설치·청소 |
| 🌐 인터넷·공유기·랜선 | 🔌 전기·조명 |
|  | 🪟 방충망·샷시 |

- 카테고리별 **기본 출장비(=소개비) 고정가** 운영 → 고객이 가격 고민 없이 바로 결제
  - 예: 열쇠 15,000원 / 누수탐지 30,000원 / CCTV 20,000원 / 인터넷 15,000원 (테스트하며 조정)
- 관리자 화면에서 카테고리·출장비를 **코드 수정 없이 변경** 가능하게 설계

## 4. 수익 구조

| 수익원 | 부과 대상 | 방식 | MVP 제안 |
|---|---|---|---|
| ① 입점수수료 | 전문가 | 월 구독 or 최초 등록비 | 부산 테스트 기간 **첫 1~2개월 무료 → 월 구독** 전환 (공급자 확보 우선) |
| ② 선결제(소개비) 수수료 | 고객 결제분에서 차감 | 출장비 중 일정 % 플랫폼 수익, 나머지 전문가 정산 | 예: 출장비 20,000원 → 플랫폼 30~50%, 전문가 50~70% |
| (확장) 상단노출/광고 | 전문가 | 검색 상위·추천 배지 | MVP 이후 |
| (확장) 보증금 | 전문가 | 페널티 차감용 예치금 | 페널티 실행력 확보 시 도입 |

> 💡 **정산 단순화 포인트**: 추가금을 현장 직거래로 빼면 플랫폼은 "출장비"만 정산하면 됨.
> PG사의 **분할정산(지급대행) 기능**을 쓰면 수수료 떼고 전문가 계좌로 자동 지급 → 정산 업무 0에 가깝게.

## 5. 핵심 플로우

### 5-1. 고객 → 전문가 호출 (기본 플로우)

```
[고객] 카테고리 선택
  → 주소/증상 입력 (사진 첨부, 희망 시간: 지금 바로 / 예약)
  → 출장비(소개비) 확인 후 선결제
  → 요청 등록 (상태: 매칭대기)
       ├─ A) 전체콜: 반경 내 해당 분야 전문가에게 동시 푸시 → 먼저 수락한 1명 배정
       └─ B) 지정콜: 고객이 지도/목록에서 전문가 직접 골라서 요청 → 해당 전문가 수락/거절
  → [전문가] 수락 (상태: 매칭완료) → 고객·전문가 연락처(안심번호) 공개 + 채팅 오픈
  → [전문가] 출발 → 도착(위치 체크인) → 작업 시작
  → 추가금 발생 시 현장에서 고객 동의 후 전문가가 직접 수령 (앱에 금액 기록만 남김)
  → [전문가] 작업완료 처리 (사진 업로드)
  → [고객] 완료 확인 + 리뷰/별점
  → 출장비 정산 (수수료 차감 후 전문가에게 자동 지급)
```

### 5-2. 전문가 → 고객 찾기 (역방향 콜)
- 전문가 앱에 **"주변 요청 지도/목록"** → 아직 매칭 안 된 요청을 실시간으로 보고 직접 수락
- 고객이 "지금 바로"로 올린 요청이 일정 시간(예: 3분) 내 미매칭 시 반경을 넓혀 재푸시 (자동)

### 5-3. 요청 상태값 (State Machine)
```
결제완료/매칭대기 → 매칭완료 → 이동중 → 도착 → 작업중 → 작업완료 → 고객확인 → 정산완료
        │               │
        ├ 미매칭 타임아웃 → 자동 전액환불
        └ 고객취소 ────── 취소 규정에 따라 환불
                        └ 전문가취소/노쇼 → 고객 전액환불 + 전문가 페널티
```

## 6. 취소·환불·페널티 정책 (MVP 기준안)

### 고객 측
| 시점 | 환불 |
|---|---|
| 매칭 전 취소 | 100% 환불 |
| 매칭 후 ~ 전문가 출발 전 | 100% 또는 소액 차감(예: 수수료분만 차감) |
| 전문가 출발 후 취소 | 출장비 환불 불가 (전문가 출장 보상) |
| 일정 시간 내 미매칭 | **자동 100% 환불** |
| 현장 견적 듣고 작업 안 함 | 출장비 환불 불가 (출장비=방문·진단비 성격임을 결제 전 명확히 고지) |

### 전문가 측 (수락 = 의무)
| 위반 | 페널티 (단계별 자동 적용) |
|---|---|
| 수락 후 취소 | 1회: 경고 + 콜 노출 순위 하락 / 2회: 24시간 콜 수신 정지 |
| 노쇼(미방문) | 즉시 7일 정지 + 고객 100% 환불 (+ 보증금 도입 시 차감) |
| 지각(약속시간 30분 초과, 무연락) | 경고, 누적 시 노출 하락 |
| 현장 과다청구 신고 | 관리자 검토 후 정지/퇴출 |
| 누적 3회 중대위반 | 영구 퇴출 |

- **"전문가 신뢰점수"** 자동 계산: 수락률·완료율·노쇼·별점 → 콜 배정 우선순위에 반영 (운영자 개입 없이 품질 관리)
- 노쇼 판단: 약속시간 + N분 지나도 **도착 체크인(GPS)** 없으면 자동으로 고객에게 "전문가 도착했나요?" 푸시 → 고객 '미도착' 응답 시 자동 노쇼 처리

## 6-A. 전문가 레벨 — 신호등 표시 시스템 🚦

전문가 등급을 **신호등 색으로 한눈에** 보여주고, 고객이 그 레벨을 보고 전문가를 골라 신청하는 구조입니다.
레벨 계산은 **매일 새벽 자동**으로 돌려서 운영자가 손댈 일이 없게 합니다.

### 레벨 단계
| 신호 | 레벨 | 조건 (예시, 관리자 설정값) | 고객에게 보이는 의미 |
|---|---|---|---|
| 🟡 | **Lv.1 새싹** | 승인 완료, 완료 0~9건 | "새로 온 전문가" — 첫 이용 할인 쿠폰과 묶어 노출 |
| 🟢 | **Lv.2 인증** | 완료 10건+, 평균 별점 4.5+, 최근 30일 노쇼 0 | "검증된 전문가" |
| 🟢⭐ | **Lv.3 우수** | 완료 50건+, 별점 4.7+, 수락 후 완료율 98%+ | "믿고 맡기는 전문가" |
| 🟢👑 | **Lv.4 마스터** | 완료 150건+, 별점 4.8+, 재이용 고객 비율 20%+, 자격증 확인 | "동네 최고 전문가" |
| 🔴 | **주의 (상태)** | 레벨과 별개로, 페널티 기간 중일 때 켜짐 | 지정콜 시 "최근 약속 위반 이력이 있습니다" 안내, 전체콜 대상에서 제외 |

- 🔴는 **등급이 아니라 일시적인 상태**입니다. 페널티 기간이 끝나면 자동으로 원래 색으로 돌아옵니다.
  → 신규 전문가를 빨간색으로 보여주면 콜을 아예 못 받으니, 신규는 🟡, 빨강은 "약속 위반"으로만 씁니다.
- **강등**: 최근 90일 기준을 못 맞추면 한 단계 내려갑니다. 그래서 레벨이 "과거 실적"이 아니라 "지금 품질"을 보여줍니다.
- 레벨 산정 지표: 완료 건수, 평균 별점, 수락 후 완료율, 노쇼·지각 횟수, 재이용률, 신고 건수, 서류 인증(자격증·범죄경력 회보서)

### 고객이 레벨을 쓰는 방식
| 화면 | 기능 |
|---|---|
| 전문가 찾기 | 지도 핀·목록 카드에 신호등 아이콘 표시, **레벨 필터**(예: 🟢 이상만) |
| 전체콜 요청 | "최소 레벨" 선택 — 기본값 "전체", 선택 시 해당 레벨 이상에게만 콜 발송 |
| 전문가 프로필 | 신호등 + 다음 레벨까지 남은 조건(전문가 본인에게만), 완료 건수·별점·재이용률 |
| 결제 화면 | (선택) **레벨별 출장비 차등** — Lv.3 이상 지정 시 +3,000~5,000원 |

### 전문가 쪽 혜택 (레벨업 동기)
| 레벨 | 혜택 |
|---|---|
| 🟡 새싹 | 기본 노출, 첫 10건 수수료 할인 (초기 정착 지원) |
| 🟢 인증 | 전체콜 우선 발송 순위 상승 |
| 🟢⭐ 우수 | 소개비 수수료율 인하(예: -5%p), 추천 영역 노출 |
| 🟢👑 마스터 | 수수료율 추가 인하, 입점 구독료 할인, 실버케어 등 **신뢰 필요 카테고리 우선 자격** |

> 💡 레벨별 출장비 차등을 넣으면 **수수료 수익도 레벨에 비례해 오르는 구조**가 됩니다.
> 고객은 돈을 더 내고 고레벨을 고르고, 전문가는 그 콜을 받으려고 품질을 관리하게 됩니다.

### 매칭 로직 반영
- 전체콜 발송 순서: **레벨 → 신뢰점수 → 거리** 순 정렬
- 단, 새싹이 콜을 하나도 못 받는 일이 없도록 상위 N명 발송 시 **새싹 슬롯 1~2개 보장**

## 7. 화면 구성 (IA)

### 7-1. 공통
- 스플래시 → 온보딩(3장) → 로그인/회원가입(휴대폰 인증, 카카오 간편로그인)
- 역할 선택: **고객으로 시작 / 전문가로 등록**

### 7-2. 고객 앱
| 탭 | 화면 | 주요 기능 |
|---|---|---|
| 홈 | 카테고리 그리드, 긴급 콜 버튼, 내 주변 전문가 수 | "지금 바로 부르기" CTA |
| 요청하기 | 카테고리 → 증상 선택/사진 → 주소 → 시간 → 출장비 확인 → 결제 | 증상 템플릿(예: "문 잠김", "물 샘") |
| 전문가 찾기 | 지도/목록, 필터(분야·거리·별점·현재 접속중) | 전문가 프로필 → 지정 콜 |
| 진행현황 | 매칭 상태, 전문가 위치·도착예정, 채팅, 안심전화 | 실시간 상태 업데이트 |
| 내역 | 이용내역, 결제/환불 내역, 리뷰 작성 | 영수증 |
| 마이 | 주소관리, 결제수단, 알림설정, 고객센터, 약관 | |

### 7-3. 전문가 앱
| 탭 | 화면 | 주요 기능 |
|---|---|---|
| 홈 | **출근(콜 받기) ON/OFF 토글**, 오늘 콜·수익 요약 | ON일 때만 위치 공유·콜 수신 |
| 콜 목록 | 실시간 주변 요청(지도/리스트), 콜 알림 팝업(수락 제한시간 카운트다운) | 수락 / 넘기기 |
| 진행중 작업 | 출발 → 도착 체크인 → 작업완료(사진) → 추가금 기록 | 단계 버튼 하나씩 |
| 정산 | 정산 예정/완료 내역, 수수료 내역 | |
| 내 프로필 | 분야·지역·자격증·포트폴리오 사진·리뷰, 신뢰점수 | |
| 입점/구독 | 입점수수료 결제·구독 상태, 페널티 내역 | |

### 7-4. 관리자 웹 (1인 운영 핵심)
- 대시보드: 오늘 요청 수, 매칭률, 평균 매칭시간, 매출, 미매칭 요청 알림
- 전문가 승인 대기 목록 (서류 확인 → 승인/반려)

- 카테고리·출장비·수수료율·페널티 규칙 설정
- 공지/푸시 발송

## 8. 실시간 매칭 로직 (MVP 버전)

1. 요청 생성 시: 해당 카테고리 + **출근 ON** + 반경 3km 이내 전문가 조회
2. 신뢰점수 순으로 정렬 → **동시 푸시**(상위 N명) → 선착순 수락 1명 배정 (DB 트랜잭션으로 중복 수락 방지)
3. 3분 내 미수락 → 반경 5km → 10km 확대 재푸시
4. 10분 내 미매칭 → 자동 전액환불 + 관리자에게 알림 (공급 부족 지역 데이터로 축적)

> 부산은 구 단위(해운대·수영·남·부산진·동래·연제·사하·북·사상·금정·강서·중·동·서·영도·기장)로
> 전문가 활동지역 설정 + 실제 거리 계산을 병행. 초기엔 **인구 밀집 구(부산진·해운대·수영·남·동래)** 위주로 전문가 모집 집중 권장.

## 16. 확장 로드맵 — 실버케어 & 1인가구 서비스

MVP 이후 **같은 플랫폼 구조(선결제·레벨·페널티)를 그대로 쓰면서** 카테고리만 늘리는 방식으로 확장합니다.
그래서 MVP 데이터 구조에 "대리신청"과 "정기 서비스"를 미리 넣어둡니다.

### 16-1. 실버케어 (어르신 생활지원)
| 서비스 | 예시 | 비고 |
|---|---|---|
| 안부 방문 | 주 1회 방문해서 안부 확인 + 사진·메모를 보호자에게 전송 | 정기 서비스 |
| 병원 동행 | 병원 접수·대기·귀가 동행 | 시간제 요금 |
| 장보기·심부름 대행 | 생필품 구매·약 수령 | |
| 집 안전 점검 | 미끄럼 방지, 안전손잡이 설치, 가스·전기 점검 | 기존 집수리 전문가 연계 |
| 가사 지원 | 청소·정리·반찬 | |
| 디지털 도우미 | 스마트폰·TV·인터넷 사용법 안내 | 기존 인터넷 전문가 연계 |

**핵심 기능**
- **보호자(자녀) 대리신청**: 서울에 사는 자녀가 부산 부모님 집으로 신청하고 결제 → 완료 리포트(사진·메모)를 자녀에게 알림톡으로 발송
- **신뢰 조건 강화**: 🟢👑 마스터 또는 🟢⭐ 우수 + **범죄경력 회보서 인증** 전문가만 실버케어 콜 수신
- 정기 구독: 주 1회 / 격주 / 월 1회 자동결제 (빌링키) → **반복 매출**
- ⚠️ 규제: 신체 수발·의료 행위는 **노인장기요양보험법상 요양 서비스 영역**이라 제외. "생활지원"으로 범위를 한정하고 약관에 명시

### 16-2. 1인가구 서비스
| 서비스 | 예시 |
|---|---|
| 소소한 집수리 | 전구 교체, 커튼·선반 달기, 실리콘 보수 |
| 가구 조립·이동 | 이케아 조립, 무거운 가구 옮기기 |
| 벌레·해충 퇴치 | 바퀴벌레·벌레 긴급 출동 |
| 정기 청소 | 원룸 정기 청소 구독 |
| 반려동물 | 산책·방문 돌봄 |
| 이사 패키지 | 원룸 소형이사 + 청소 + 인터넷 이전 묶음 |

**핵심 기능**
- **여성 전문가 지정 / 여성 안심 배지**: 혼자 사는 여성 고객이 선택 가능
- **안심 방문 모드**: 전문가 도착·완료를 지정한 지인에게 자동 공유, 방문 중 긴급 버튼
- **묶음 상품**: 여러 서비스를 한 번에 결제 (객단가 상승)

### 16-3. 확장 순서 제안
| 단계 | 시점 | 내용 |
|---|---|---|
| 1 | MVP 안정화 후 | 1인가구 "소소한 집수리·가구 조립·벌레 퇴치" — 기존 전문가 풀로 바로 가능 |
| 2 | 레벨 데이터가 쌓인 후 | 실버케어 "안부 방문·디지털 도우미·안전 점검" — 🟢⭐ 이상 전문가로 시작 |
| 3 | 정기결제 검증 후 | 실버케어 정기 구독, 원룸 정기 청소 구독 |
| 4 | 이후 | 지자체·복지관 B2G 제휴 (독거노인 안부 확인 사업 위탁 등) |

> 💡 실버케어와 정기 서비스는 **매달 반복 결제**가 생기는 구조라, 건당 소개비 모델보다 매출이 안정적입니다.
> 레벨 시스템이 "믿을 수 있는 사람만 어르신 집에 간다"는 근거가 되므로, MVP 레벨 데이터가 확장의 기반입니다.

#### DB 스키마 구성 요약
- **상태 변경은 전부 RPC 함수로만**: `accept_request`(행 잠금으로 동시 수락 방지), `advance_request`(출발→도착(GPS 필수)→작업→완료→고객확인), `cancel_request`(시점별 환불률 자동), `report_no_show`(유예시간 후 자동 노쇼 처리)
- **금액은 서버가 계산**: 요청 생성 시 카테고리 출장비 + Lv3+ 프리미엄 자동 계산, 결제 금액 불일치 시 차단
- **정산 자동 생성**: 고객 완료확인 시 레벨·새싹 할인을 반영한 수수료로 `settlements` 생성
- **🚦 레벨/🔴 페널티 자동화**: `recompute_expert_levels()`(매일), 페널티 등록 시 경고/정지/퇴출 자동 판정
- **1인 운영 자동화**: `process_matching_queue()`(1분마다 반경 확대 + 10분 미매칭 자동환불 요청), 설정값은 `app_settings`에서 수정
- **Edge Function**: PG 결제 검증(`payment-confirm`·`portone-webhook`), 환불 실행(`process-refunds`), FCM 콜 푸시(`matching-tick`), 상태 알림(`request-notify`) — 정산 지급(지급대행)은 다음 단계
