# 그림·그래프 표현 지시서

숨결 화면 가운데의 **호흡 그림**(입자 그래픽)과 관리자·보관함의 **데이터 그래프**를 고치거나 새로 만들 때 따르는 규칙입니다.
코드는 `public/app/breath.js`(호흡 그림), `public/admin/admin.js`(관리자 그래프), `public/app/app.js`(보관함 통계)에 있습니다.

---

## A. 호흡 그림 (가운데 입자 그래픽)

### A-1. 핵심 원칙
1. **그림 = 호흡 상태.** 장식이 아닙니다. 사용자는 숫자를 보지 않아도 그림만 보고 지금 들이쉬는지, 멈추는지, 내쉬는지 알 수 있어야 합니다.
2. **들숨은 차오르고 밝아지고, 날숨은 식고 어두워집니다.** 이 방향을 모든 호흡법에서 똑같이 지킵니다.
3. **멈춤은 움직이지 않습니다.** 멈춤 단계에서는 채움 정도를 고정하고, 미세한 떨림(jitter)만 남깁니다.
4. **부드럽게만 움직입니다.** 갑자기 튀거나 깜빡이는 표현을 쓰지 않습니다. 단계 전환은 모두 사인 곡선 완급(`ease`)을 거칩니다.
5. **호흡법마다 그림 하나.** 같은 모양을 두 호흡법이 같이 쓰지 않습니다. 모양은 그 호흡법의 이름·느낌과 연결됩니다(용암 → 화산, 달빛 → 달).

### A-2. 채움 값 `L` (모든 그림의 공통 입력)
- `L` 은 0(빈 상태) ~ 1(가득 찬 상태) 사이 값입니다.
- 단계별 기본 동작:

| 단계 `t` | `L` 변화 | 그림 |
|---|---|---|
| `in` 들이쉬기 | `from`(기본 0) → `to`(기본 1) | 아래에서 위로 차오름, 밝아짐, 살짝 커짐 |
| `hold` 멈추기 | 직전 값 유지 | 정지, 미세한 떨림 |
| `out` 내쉬기 | 1 → 0 | 위에서부터 식음, 어두워짐 |
| `holdOut` 비우고 멈추기 | 0 유지 | 어두운 윤곽만 |
| `ready` 준비 | 0.15 고정 | 은은한 윤곽 |

- 한숨 호흡처럼 들숨을 나누면 `from`/`to` 로 구간을 지정합니다(예: 0→0.78, 0.78→1).
- 단계 안 진행률 `p` 에 `ease(p) = 0.5 − 0.5·cos(πp)` 를 적용해 `L` 을 만듭니다. 직선 보간을 쓰지 않습니다.
- 그림 전체 크기는 `1 + 0.05·L` 배로 숨 쉬듯 커졌다 작아집니다. 5%를 넘기지 않습니다(어지러움 방지).

### A-3. 입자 하나의 밝기
- 각 입자는 `k`(0~1, 채워지는 순서)를 가집니다. 보통 아래쪽이 0, 위쪽이 1입니다.
- 기본 채움 함수: `fill(k, L) = clamp((L·1.06 − k) / 0.06)` → 채움 경계가 칼처럼 잘리지 않고 약 6% 폭으로 번집니다.
- 밝기 `b`(0~1)는 12단계로 나눠 색을 고릅니다. 꺼진 입자도 완전히 사라지지 않고 **어두운 색 + 투명도 42%** 로 윤곽을 남깁니다(그림 모양이 항상 보이게).

### A-4. 현재 그림 6종

| 호흡법 | 그림 `shape` | 채움 방식 | 주색 |
|---|---|---|---|
| 용암 호흡 8·8 | `volcano` 화산 | 아래→위 채움. 들숨·멈춤 동안 분화구에서 불티(spark)가 올라감 | 용암 주황 `#ff6a3d` (꼭대기는 노랑) |
| 박스 호흡 4·4·4·4 | `box` 사각형 | 빛 꼬리가 네 변을 한 단계에 한 변씩 돎(왼쪽 위로 → 위 → 오른쪽 아래로 → 아래). 안쪽은 `L` 에 따라 은은하게 | 등불 금색 `#f2c46b` |
| 달빛 4-7-8 | `moon` 달 | 초승달 → 보름달로 차고(들숨), 멈춤 동안 보름달, 날숨에 기움. 바깥 달무리는 `L` 비례 | 달빛 크림 `#f1dca0` |
| 공명 호흡 5.5·5.5 | `wave` 파도 | 5줄 사인파. 들숨에 진폭이 커지고(0.06→0.36) 위로 올라감, 날숨에 잔잔해짐 | 바다 파랑 `#6aaeff` |
| 한숨 호흡 3+1·6 | `lungs` 폐 | 기관지는 바로 켜지고, 양쪽 폐가 아래→위로 채워짐. 두 번째 짧은 들숨에서 끝까지 | 장밋빛 `#ff8fa3` |
| 교호 호흡 좌4·우6 | `nadi` ∞자 | 왼쪽 고리(달·은청색)와 오른쪽 고리(해·금색). 들이쉬는 쪽 고리가 채워지고, 내쉴 때 들이쉰 고리는 비워지며 반대쪽 고리에 빛 띠가 위→아래로 흐름 | 보라 `#b9a6ff` |

### A-5. 화면 구성 규칙
- 배경은 밤색 `#07060a` 단색 + 그림 뒤 둥근 빛(반지름 = 그림 크기 1.5배, 밝기 `0.05 + 0.16·L`).
- 입자는 `lighter`(더하기) 합성으로 그려 겹칠수록 빛나게 합니다.
- 화면에 떠다니는 흰 먼지 170개는 천천히 위로 흐르고 반짝입니다. 들숨에는 조금 빨라집니다.
- 그림 위치: 위쪽 단계 문구 아래와 아래쪽 카드 위 사이의 빈 공간 가운데. 크기는 `min(화면 폭 × 0.42, 빈 공간 높이 × 0.5)`. 카드가 바뀌면 부드럽게 이동합니다.
- 단계 문구 색: 들숨 = 호흡법 주색, 멈춤 = 크림 `#eadcb0`, 날숨 = 청록 `#6fc7b4`. 그림 색과 문구 색이 같은 단계를 가리키게 합니다.
- 입자 수는 화면 크기에 따라 최대 2,600개. 휴대폰에서 끊기지 않는지 반드시 확인합니다.
- 접근성: `prefers-reduced-motion` 이면 떨림과 불티를 끕니다. 그림은 `aria-hidden` 이며, 같은 정보는 단계 문구·숫자·음성으로 함께 전달합니다.

### A-6. 새 그림을 추가할 때 (지시문 틀)
코덱스에 이렇게 요청하면 됩니다.

> `breath.js` 의 `SHAPES` 에 `<이름>` 그림을 추가해 줘.
> - 모양: <무엇을 닮았는지, 좌표 범위 −1~1 안에서>
> - 채움 방식: <아래→위 / 가운데→바깥 / 경로를 따라 이동 등>, `k` 를 어떻게 정할지
> - 색: 켜진 색 4단계 `lit`, 꺼진 색 4단계 `dim`, 뒤 빛 `glow`
> - 움직이는 모양이면 `dynamic: true` 와 `pos(i, s)`
> - `PATTERNS` 의 해당 호흡법 `shape` 를 바꾸고, A-1 원칙과 A-2 단계 동작을 지킬 것
> - 휴대폰 360px·400px 화면에서 스크린샷으로 확인할 것

그림 객체 형식:
```js
SHAPES.myShape = {
  lit: [[r,g,b] ×4],   // 켜진 색 (band 0~3)
  dim: [[r,g,b] ×4],   // 꺼진 색 (윤곽용, 너무 어둡지 않게)
  glow: [r,g,b],       // 그림 뒤 둥근 빛
  init(i) { /* ax[i], ay[i] 좌표(−1~1), kk[i] 채움 순서, band[i] 색 묶음 0~3 */ },
  b(i, s) { return fill(kk[i], s.L); },   // 밝기 0~1. s = { L, ph(단계), p(진행률), cyc(한 사이클 진행률), t(초) }
  // 선택: dynamic: true, pos(i, s) → y 좌표 / emit: true → 불티
};
```

### A-7. 하지 말 것
- 들숨에 어두워지거나 날숨에 밝아지는 표현
- 멈춤 단계에서 그림이 계속 커지거나 움직이는 표현
- 숫자 카운트와 맞지 않는 속도(그림이 단계보다 먼저 끝나거나 늦게 끝남)
- 빨강·초록 깜빡임, 화면 전체 번쩍임, 1초에 3번 넘는 밝기 변화
- 그림 위에 글자를 겹쳐 그리기(문구는 HTML 로 위·아래에)

## B. 데이터 그래프 (관리자·보관함)

### B-1. 원칙
1. **그래프는 실제 숫자만 그립니다.** 예시 숫자나 지어낸 추세를 넣지 않습니다. 데모 데이터는 `@demo.soomgyeol` 계정으로만 만들고 화면에 "데모"로 표시합니다.
2. **하나의 축척.** 막대 높이·눈금·라벨을 같은 최대값 기준으로 계산하고, 범례에 최대값을 적습니다.
3. **색은 의미별로 고정합니다.** 아래 색표를 바꾸지 않습니다.
4. 빈 데이터는 빈 그래프 대신 "아직 데이터가 없어요." 문구를 보여줍니다.
5. 라이브러리 없이 SVG 로 그립니다(외부 패키지 금지 규칙). 각 막대에 `<title>` 로 날짜·값을 넣어 마우스를 올리면 보이게 합니다. SVG 에는 `role="img"` 와 `aria-label` 을 붙입니다.

### B-2. 색표
| 의미 | 색 |
|---|---|
| 완료 세션 / 핵심 지표 | 용암 주황 `#ff6a3d` |
| 가입 / 보조 지표 | 청록 `#6fc7b4` |
| 정상·결제 완료·활성 | 초록 `#7fd8a8` |
| 대기·해지 예약·테스트 | 크림 `#eadcb0` (테스트는 점선 테두리) |
| 실패·환불·만료·오류 | 빨강 `#ff7a7a` |
| 축 글자 | 흐린 회색 (`--muted`) |

### B-3. 현재 그래프
| 위치 | 내용 | 규칙 |
|---|---|---|
| 관리자 > 현황 | 최근 14일 막대(완료 세션·가입, 날짜별 2개 막대) | 한국 시간 날짜 기준, x축 라벨은 이틀 간격 `MM-DD` |
| 관리자 > 현황 카드 | 회원·활성·세션·프리미엄·전환율·순매출·환불·오류·문의 | 오류·답변 대기 문의가 1 이상이면 빨간 숫자 |
| 보관함 상단 | 이번 주 호흡 수·시간(분)·연속 기록일 | 숫자 + 단위 작게, 고정폭 숫자(`tabular-nums`) |
| 보관함 목록 | 전 기분 → 후 기분 (예: `2 → 4`) | 기록이 없으면 `–` |
