# 숨결 구글 플레이 등록 가이드

이 폴더는 숨결 웹앱(`/app`)을 **신뢰할 수 있는 웹 활동(TWA)** 방식의 안드로이드 앱으로 감싼 프로젝트입니다.
앱을 열면 배포된 웹앱이 주소창 없이 전체 화면으로 열립니다. 웹을 고치면 앱을 다시 올리지 않아도 바로 반영됩니다.

| 항목 | 값 |
|---|---|
| 패키지 이름 | `app.soomgyeol.breath` (한 번 올리면 변경 불가) |
| 버전 | versionCode 1 / versionName 0.1.0 |
| 대상 SDK | 36 (Android 16), 최소 SDK 23 (Android 6) |
| 앱이 여는 주소 | `https://soomgyeol.onrender.com/app?src=android` **(가정: 배포 주소 확정 후 교체)** |
| 업로드 키 지문(SHA-256) | `7E:F2:33:DF:C9:72:55:D3:25:74:B8:80:59:5A:D9:FC:59:5A:2E:FD:3A:BB:81:0D:83:59:37:3E:B2:4C:FF:B4` |

## 1. 등록 전에 꼭 해야 할 것

1. **웹앱 배포**: `twa.properties` 의 `host` 주소에 숨결 서버가 HTTPS 로 떠 있어야 합니다. 주소가 다르면 `host` 를 바꾸고 다시 빌드하세요.
2. **도메인 연결 파일**: 서버 환경 변수 `ANDROID_CERT_SHA256` 에 지문을 쉼표로 넣으면 `/.well-known/assetlinks.json` 이 자동으로 만들어집니다.
   - 업로드 키 지문(위 표) + **플레이 콘솔 > 테스트 및 출시 > 앱 무결성 > 앱 서명 키 인증서의 SHA-256** 두 개를 모두 넣으세요.
   - 이게 빠지면 앱 위쪽에 주소창이 보입니다(심사 거절 사유가 될 수 있음).
3. **약관의 `[운영자 확인 필요]` 항목 채우기**: 개인정보처리방침 URL은 필수 제출 항목입니다.

## 2. 플레이 콘솔 입력값 (복사해서 쓰기)

**앱 이름 (30자)**: 숨결 - 마음에 맞는 호흡 코치

**간단한 설명 (80자)**:
화날 때, 긴장될 때, 잠 안 올 때. 지금 마음에 맞는 요가 호흡을 빛과 소리로 안내해요.

**자세한 설명**:
```
숨을 고르면, 마음이 놓여요.

"심호흡하세요"라는 말은 쉽지만, 몇 초 들이쉬고 몇 초 내쉴지, 지금 어떤 호흡이 맞는지는 혼자 정하기 어렵습니다. 숨결은 두 가지 질문으로 지금 마음에 맞는 호흡을 골라 주고, 화면의 빛과 음성이 한 호흡씩 함께 셉니다.

■ 지금 마음에 맞는 호흡 추천
"화가 나요", "긴장돼요", "잠이 안 와요", "머리가 복잡해요" 중에서 고르고 시간을 정하면, 왜 그 호흡이 맞는지 설명과 함께 추천합니다.

■ 빛과 소리로 따라 하는 호흡
수천 개의 빛 입자가 화산·달·파도·폐 모양으로 숨에 맞춰 차오르고 식습니다. "들이쉬세요, 하나, 둘, 셋" 음성 안내와 호흡에 맞춰 화음이 바뀌는 잔잔한 음악이 함께 나옵니다.

■ 여섯 가지 호흡법
공명 호흡(5.5·5.5), 박스 호흡(4·4·4·4), 한숨 호흡(3+1·6), 용암 호흡(8·8), 달빛 4-7-8, 교호 호흡(나디 쇼다나). 호흡법마다 근거와 주의사항을 함께 담았습니다.

■ 기분 기록과 보관함
호흡 전후 기분과 한 줄 메모를 남기고, 이번 주 호흡 시간과 연속 기록일을 확인할 수 있습니다.

무료로 공명·박스·한숨 호흡을 하루 3회 이용할 수 있습니다.

※ 숨결은 휴식과 긴장 완화를 돕는 웰니스 앱이며 의료 기기나 치료법이 아닙니다. 숨이 차거나 어지러우면 바로 멈추고 평소 호흡으로 돌아오세요.
```

**카테고리**: 건강/운동 · **태그**: 명상, 호흡, 스트레스, 수면
**연락처 이메일**: [운영자 입력] · **개인정보처리방침 URL**: `https://<도메인>/privacy`
**계정 삭제 URL**: `https://<도메인>/account-deletion`

**그래픽** (`store/` 폴더):
- 앱 아이콘 512×512: `icon-512.png`
- 그래픽 이미지 1024×500: `feature-graphic-1024x500.png`
- 휴대전화 스크린샷 1080×1920: `phone-1-welcome.png` ~ `phone-6-records.png`

| 광고 포함 | 아니요 |

| 콘텐츠 등급 | 폭력·성적 콘텐츠·도박 없음, 사용자 간 소통 없음 → 전체이용가 예상 |

| 건강 앱 | 의료 기능 없음, 웰니스(명상·호흡)로 선택 |
| 정부 앱 / 금융 기능 | 아니요 |

**데이터 보안 (Data safety)**:

| 데이터 | 수집 | 목적 | 비고 |
|---|---|---|---|
| 이메일 주소 | 예 | 계정 관리 | 필수 |

## 4. 결제 정책 주의

구글 플레이로 배포하는 앱 안에서 디지털 구독을 판매하려면 **구글 플레이 결제**(또는 한국의 대체 결제 프로그램 등록)를 써야 합니다.
그래서 앱으로 열렸을 때(`?src=android`)는 **구매 화면과 가격을 숨기고** 무료 기능만 보이게 처리했습니다.
웹에서 이미 프리미엄을 산 사람은 앱에서도 같은 계정으로 프리미엄을 씁니다.
앱 안에서 판매하려면 다음 단계로 플레이 결제(Digital Goods API) 연동이 필요합니다.

## 5. 출시 순서

1. 플레이 콘솔에서 앱 만들기 → 위 입력값·그래픽·설문 채우기
2. **테스트 > 비공개 테스트** 트랙 만들고 `soomgyeol-0.1.0-1.aab` 업로드 (Play 앱 서명 사용에 동의)
3. 앱 서명 키 SHA-256 을 서버 `ANDROID_CERT_SHA256` 에 추가 → 테스트 기기에서 주소창 없이 열리는지 확인
4. **개인 개발자 계정은 테스터 12명 이상이 14일 연속 비공개 테스트**에 참여해야 프로덕션 출시를 신청할 수 있습니다.
5. 프로덕션 출시 신청 → 심사(보통 며칠)

## 6. 다시 빌드하기

```bash
# 필요: JDK 17+, Android SDK (platform 36, build-tools 36)
cd android
echo "sdk.dir=/경로/android-sdk" > local.properties
# keystore.properties (저장소에 올리지 않음):
#   storeFile=../keystore/upload.jks
#   storePassword=…  keyAlias=upload  keyPassword=…
# twa.properties 에서 versionCode 를 1 올림
./gradlew bundleRelease
# 결과: app/build/outputs/bundle/release/app-release.aab
```

업로드 키(`upload.jks`)와 비밀번호는 **저장소에 없습니다.** 따로 받은 파일을 안전한 곳(비밀번호 관리자 등)에 보관하세요.
잃어버려도 Play 앱 서명을 쓰면 플레이 콘솔에서 업로드 키 재설정을 요청할 수 있습니다.
