# FACE:D 벤치마킹 기반 업그레이드 계획 — 2026-11-26

기준 문서: `2026-11-07-upgrade-log.md`
원칙: **서버·AI 계정 없이 기기 안에서 끝나는 것부터**. 1인 운영 부담(서버비·CS·개인정보 처리)을 늘리지 않으면서 체감 품질을 올린다.

## 1. 벤치마킹 대상과 핵심 관찰

| 구분 | 서비스 | 확인된 강점 | FACE:D 시사점 |
|---|---|---|---|
| 셀피 카메라 | SNOW | AI 프로필, **AI 증명사진**, AI 헤어샵, 어두운 사진 밝히기(AI 플래시), 갤러리 사진을 배경으로 쓰기 | "업무" 목적을 **증명/프로필 규격 출력**까지 확장하면 차별점 |
| 셀피 카메라 | B612 | 한 장 → 여러 스타일 변환(AI Style), **얼굴 대칭 보정**, AI 지우개 영역 인식 개선 | 추천 3개를 "한 번에 비교 그리드"로, 대칭은 규칙형으로 구현 가능 |
| 리터치 | Facetune | Skin 2.0(**피부 결 유지, 플라스틱 느낌 방지**), AI 헤드샷, 헤어·의상 | 피부 보정에 "결 보존" 지표/슬라이더 필요. 생성형은 유료 구독 뒤에 있음 |
| 리터치 | Meitu | 중안부·하안부 비율 분리 조정 | 형태 강도는 이미 분리됨 → 구역별 세분화는 후순위 |
| 리터치 | YouCam | AI Agent(문장 편집), 잡티·다크서클 제거, 배경 제거 | 문장 편집은 서버 필요 → 보류. **다크서클·잡티 점 보정**은 로컬 가능 |
| 포토부스 | 포토이즘 / 인생네컷 | 포토이즘 성장(점포 469→568, 매출 347억→569억, 2023→2025), **컬러 배경·콘셉트 브랜드 분리**, 캐릭터·아티스트·시즌 프레임, 팬덤 전용 앱 | 네컷은 "기능"보다 **프레임 콘텐츠·시즌 갱신**이 재방문을 만든다 |
| AI 헤드샷 | Dreamina·CapCut 등 | 한 장으로 다수 비즈니스 스타일, 의상 합성, 업스케일 | 채용 담당자 후기: **과보정은 역효과** → FACE:D의 "자연스러움 유지" 포지션이 오히려 강점 |

### 결론 — 포지셔닝
> **"티 안 나게, 용도에 딱 맞게."**
> 경쟁앱은 생성형으로 얼굴을 바꾸는 방향(서버비·구독 필요). FACE:D는 **얼굴 유지 + 용도별 규격 완성 + 네컷 콘텐츠**로 간다. 서버 없이 가능하고, 토스 미니앱의 "가볍게 바로 쓰기" 성격과도 맞는다.

| 잡티·다크서클 | YouCam, Facetune | 붉은기·그림자 완화 | ❌ 점 단위 보정 없음 |

| 어두운 사진 | SNOW AI 플래시 | 밝기 안내만 | △ 자동 노출/역광 보정 없음 |

| 네컷 연속 촬영 | 포토부스 기본 | 한 컷씩 추가 | ❌ 카운트다운 4연속 없음 |
| 네컷 프레임 콘텐츠 | 시즌·콜라보·컬러 | 색상·문구·날짜·여백 | ❌ 테마 프레임 팩·시즌 교체 구조 없음 |
| 생성형 배경/헤어/의상 | 다수 | 어댑터만 준비 | ⏸ 서버 확보 전 보류 (의도된 상태) |

## 3. 다음 업그레이드 범위 (우선순위)

모두 **기기 내 처리, 사진 외부 전송 없음, API 키 없음**.

### P1 — 이번 스프린트 (체감 효과 큼, 공수 작음)

1. **전후 비교**
   - 미리보기 길게 누르면 원본, 놓으면 결과. 슬라이더 분할 보기 옵션.
   - 파일: `UnifiedEditor.tsx`, `editorRender.ts`
   - 테스트: 길게 누르기 시 캔버스 픽셀이 원본과 일치.

2. **업무용 규격 프리셋 ("증명·프로필 모드")**
   - 프리셋: 증명 3×4cm(354×472), 여권형 3.5×4.5cm(413×531), 링크드인/명함 원형, 이력서 4:5.
   - 랜드마크로 **정수리~턱 비율·눈높이 라인** 자동 배치, 벗어나면 안내 문구.
   - 단색 배경(흰/연회색/연하늘) 원터치 — 기존 배경 분리 재사용.
   - ⚠ 공식 제출용(여권 등) 규격 적합성은 보장하지 않는다는 문구 표기. 규격 수치는 출시 전 기관 공지로 재확인.
   - 파일: `editorModel.ts`(프리셋 정의), `ExportSheet.tsx`, `engine.ts`

3. **자동 수평 보정**
   - 양쪽 눈 중심 각도로 ±10° 이내 자동 회전 제안(적용/취소). 얼굴 형태는 건드리지 않음.
   - 파일: `engine.ts`, `editorRender.ts`

4. **피부 결 보존 강화 (Skin 2.0 대응)**
   - 블러 후 원본 고주파 성분 일부 재주입(주파수 분리). 슬라이더 "결 살리기 0~100".
   - 판정 지표: 보정 전후 피부 영역 고주파 에너지 비율 ≥ 0.5 (테스트로 고정).
   - 파일: `public/portrait-worker.js`

### P2 — 다음 스프린트

5. **네컷 카운트다운 4연속 촬영** — 3초 카운트다운, 컷 사이 2초, 재촬영할 컷만 선택 교체. (`Workbench.tsx`, `platform.ts` 카메라 권한)
6. **네컷 테마 프레임 팩** — 프레임을 JSON+SVG 데이터로 분리(`frames/*.json`), 앱 업데이트 없이 시즌 팩 추가 가능한 구조. 첫 팩: 컬러 배경 6종(포토이즘 컬러드 흐름), 연말·크리스마스, 졸업·입학. 캐릭터/아티스트 콜라보는 라이선스 필요 → 직접 제작 일러스트만.
7. **잡티·다크서클 점 보정** — 탭한 지점 주변 피부색으로 소형 인페인팅(로컬, 반경 제한), 눈 아래 랜드마크 영역 밝기 소폭 상승.
8. **어두운 사진/역광 자동 보정** — 얼굴 영역 기준 노출·감마 보정, 현재 "밝기 안내"를 "한 번에 고치기" 버튼으로.

### P3 — 검토만 (서버 확보 후)
- 생성형 배경·헤어·의상·문장 편집: 기존 `server/ai-handler.mjs` 어댑터 활성화. 선행 조건은 11-07 문서 그대로.
- 결정 기준: 월 활성 사용자와 "준비 중" 버튼 탭 수(로컬 카운터)가 일정 이상일 때만 비용 검토.

### 하지 않는 것
- 눈 키우기·턱 깎기 등 강한 성형형 변형 (포지션과 충돌, 토스 검수 리스크)
- 얼굴 기반 성격·운세 판단 (11-07 원칙 유지)
- 실존 캐릭터·아티스트 프레임 무단 사용

## 4. 검증 기준 추가

| 항목 | 테스트 |
|---|---|
| 전후 비교 | `upgrade.spec.ts` — 길게 누르기 원본 표시, 해제 시 복귀 |
| 규격 프리셋 | 출력 픽셀 크기 정확, 눈높이 라인 허용 오차 ±3% |
| 자동 수평 | 5° 기울인 테스트 사진 → 보정 후 눈 각도 < 1° |
| 결 보존 | 고주파 에너지 비율 ≥ 0.5, 기존 보정 강도 회귀 없음 |
| 4연속 촬영 | 가짜 카메라 스트림으로 4장 캡처·한 컷 교체 |
| 프레임 팩 | 잘못된 JSON 로드 시 기본 프레임으로 안전 복귀 |

실제 사진군(피부색·안경·역광·머리카락) 및 토스 실기기 검증은 11-07 미완 항목과 함께 묶어서 진행.

## 5. 1인 운영 관점 메모

- **콘텐츠 자동화**: 프레임 팩을 데이터로 분리하면 시즌마다 코드 수정 없이 JSON+SVG만 추가 → Canva/Figma에서 만든 프레임을 내보내 넣는 반복 작업으로 정착 가능.
- **지표 판단**: 로컬 카운터에 `beforeAfterView`, `idPresetUsed`, `burstShoot`, `framePackUsed` 추가 → 어떤 기능이 실제로 쓰이는지 보고 P3 투자 여부 결정.
- **비용 0 유지**: P1·P2 전부 서버 없이 가능. 서버비가 생기는 시점은 P3 하나뿐.
