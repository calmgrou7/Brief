# 진로산사 (v0.2 — 2D 메타버스 코칭방)

중·고등학생이 **산사 마당을 아바타로 거닐며** 친구들, 코치(길잡이)와 진로 이야기를 나누는 2D 탑뷰 메타버스입니다.

- 기획서: [`docs/PLAN.md`](docs/PLAN.md)
- 메타버스: `public/` + `server.js` (Node.js + WebSocket)
- 혼자 걷는 7일 진로 일기(v0.1): `public/solo/`

## 산사 마당 구성
| 장소 | 기능 |
|---|---|
| 🚪 산문 | 입장 지점 |
| 🏯 길잡이 법당 | 코치와 모여 이야기하는 곳. 코치가 "모두 법당으로 부르기"를 누르면 학생 화면에 안내가 뜨고, 버튼을 누르면 자동으로 걸어감 |
| 🗿 생각의 돌탑 | 오늘의 질문에 답하면 돌탑 곁에 **내 등불**이 켜짐. 다른 학생이 탭해서 읽을 수 있음 |
| 🔔 종각 | 종을 치면 방 전체에 종소리와 물결 |
| 🌲 솔바람 정자 · 🌙 달빛 정자 | **정자 안 사람끼리만 보이는 소모임 대화** (코치는 모두 볼 수 있음) |

## 실행
```bash
npm install
COACH_CODE=원하는코치코드 npm start
```
- 학생: http://localhost:8080 (방 이름을 바꾸면 반별로 분리: `?room=2학년3반`)
- 코치: http://localhost:8080/?coach=1 → 코치 코드 입력
- 이동: 방향키·WASD 또는 화면 탭(길찾기 자동) / 대화: 아래 입력창, Enter

## 코치(길잡이) 도구
- 공지 올리기, 오늘의 질문 바꾸기, 모두 법당으로 부르기
- 학생 아바타 탭 → 채팅 5분 멈추기 / 등불 탭 → 부적절한 등불 내리기
- 위기 표현이 나오면 코치 화면에만 경고가 뜨고, 학생에게는 청소년상담 1388 안내가 뜸

## 미성년자 안전장치
욕설 필터(자모 축약·띄어쓰기 우회 포함), 전화번호 자동 가림, 1초 도배 방지, 메시지 80자 제한, 방 정원(기본 40명), 별명 사용 안내.
대화와 등불은 **서버 메모리에만** 있고 저장하지 않습니다(재시작하거나 날짜가 바뀌면 사라짐).

## 배포 (Render)
`render.yaml`이 포함되어 있습니다. Render 대시보드 → New → Blueprint → 이 저장소 선택 → `COACH_CODE` 입력.
무료 플랜은 15분 동안 접속이 없으면 잠들었다가, 다음 접속 때 깨어나는 데 30초 정도 걸립니다. 수업에 쓰기 전에 미리 한 번 접속해 두세요.
