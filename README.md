# 채움 ver2.0 — 법인 컨설팅 설계사용 가결산 진단

회계사무실 **비교식 재무제표(재무상태표·손익계산서)** PDF를 올리거나 직접 입력하면 연말 결산을 추정하고,
정책자금·대출·승계 목적별 재무비율을 진단한 뒤, 결산 전 조치 시나리오와 리포트 3종(대표용·회계사무실 요청서·상담노트)을 만듭니다.

- 기획: [`docs/01-기획서.md`](docs/01-기획서.md)
- 가결산 모듈 설계: [`docs/02-가결산-모듈.md`](docs/02-가결산-모듈.md)

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 계산 엔진 테스트
npm run build    # 배포용 빌드(dist/)
```

리포트 화면의 **PDF로 저장** 버튼은 브라우저 인쇄(A4)를 사용합니다.

## 구조

| 경로 | 내용 |
|---|---|
| `src/engine/` | 계산 엔진(순수 함수 + 테스트). 연환산, 재무비율, 추정 현금흐름, 시나리오 레버, 비상장주식 약식 평가, 리포트 문장 |
| `src/engine/params.ts` | 연도별 세율·목표 비율 기본값 — 세법이 바뀌면 이 파일만 갱신 |
| `src/import/` | 비교식 재무제표 PDF 읽기(pdf.js, 브라우저 안에서만 처리) → 계정 분류 → 원본 합계 검증 |
| `src/ui/` | 화면(자료 입력 → 진단 → 시나리오 → 리포트) |

## 시제품 범위와 한계

- PDF 불러오기는 텍스트가 들어 있는 원본 PDF만 읽습니다(스캔 이미지는 미지원). 장·단기대여금은 가지급금 여부를 사람이 확인하도록 표시합니다.

- 데이터는 브라우저(localStorage)에만 저장됩니다. 로그인·서버 저장은 다음 단계(Supabase)에서 추가합니다.
- 법인세는 세무조정 없이 세전이익을 과세표준으로 본 추정치, 주식가치는 상증법 보충적 평가 약식입니다.
- 목표 비율은 상담용 기본값이며 기관별 실제 심사 기준과 다를 수 있습니다.
