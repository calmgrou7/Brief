# Brief: 아침 트렌드 검수 시스템

운동·실버세대·건강 분야에서 **이미 있는 수요**를 매일 찾고, 그중 하나를 한 사람과 한 문장으로 좁혀 브랜딩까지 다듬는 1인 사업자용 루틴입니다.

## 흐름

| 시간 | 누가 | 무엇을 |
|---|---|---|
| 매일 06:41 (KST) | 예약 작업 (Claude) | 최근 2주 자료에서 새 신호 3~6개를 Notion에 추가하고, 상승 신호에 타깃 고객과 브랜드 한 줄 초안을 씁니다. `검토 중` 아이디어 하나에는 「다듬기 제안」을 붙입니다. |
| 아침 10분 | 사업자 | 대시보드에서 신호 지도 → 브랜딩 카드 → 다듬지 않은 신호 순서로 봅니다. |
| 검수 후 | 사업자 | Notion에서 문장을 고치고 `상태`를 바꾼 뒤 `아침 검수`를 체크합니다. |

## 구성 요소

- **Notion 데이터베이스 「트렌드 브레인스토밍」**: 모든 신호와 아이디어를 저장합니다.
  - 칸: 키워드, 분야, 신호, 변화율, 출처, 근거, 링크, 아이디어, 타깃 고객, 브랜드 한 줄, 상태, 아침 검수, 기록일
  - 상태 흐름: 새 신호 → 검토 중 → 소싱 확인 → 진행 (또는 보류)
- **대시보드 「아침 검수 보드」**: 열 때마다 Notion을 실시간으로 읽습니다. 원본 HTML은 [`dashboard/morning-review.html`](dashboard/morning-review.html)에 있습니다.
  - 신호 지도: 분야 × 신호 방향 격자
  - 뾰족하게 다듬은 아이디어: 브랜드 한 줄 카드와 다듬기 정도 (타깃·한 줄·근거·수치 4칸)
  - 아직 다듬지 않은 신호: 좁히기 질문과 함께
- **예약 작업 「아침 트렌드 신호 수집·다듬기」**: 매일 새 세션으로 실행되며, 실행이 끝나면 푸시 알림을 보냅니다.

## 뾰족함 기준

1. **한 사람**: 나이대가 아니라 불편을 느끼는 순간까지 씁니다. 예: "무릎 때문에 헬스장이 겁나는 60대 초반"
2. **한 문장**: 그 사람에게 건네는 약속을 30자 안팎으로 씁니다.
3. **근거**: 원문에서 확인한 사실과 링크를 남깁니다. 수치는 원문에 있을 때만 적습니다.
4. **다른 한 가지**: 경쟁 제품과 다른 점 하나를 정합니다.
