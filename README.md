# 채움파트너스 v2

병원·약국·동물병원 전문 여신 컨설팅 홈페이지. 브릿지노드의 패밀리 사이트로 링크되지만, 서버와 DB는 독립적으로 운영됩니다.

- 공개 사이트: 메인(자금 진단표, 자금 근거 표, 절세 계산기, 신청 폼), 자금 진단 신청, 게시판(공지/자금 칼럼/상담 문의), 개인정보 처리방침
- 관리자 `/admin`: 상담 신청 관리(상태, 메모, CSV), 게시글 작성/수정, 문의 답변, 사이트 정보, 웹훅 알림, 비밀번호 변경

## 실행

```bash
npm install
ADMIN_PASSWORD=원하는비밀번호 npm start
```

http://localhost:3000 에서 확인. 첫 실행 때 관리자 계정(`admin`)이 만들어집니다. `ADMIN_PASSWORD`를 주지 않으면 임의 비밀번호가 콘솔에 한 번 출력됩니다.

## 환경 변수

| 이름 | 설명 |
| --- | --- |
| `PORT` | 기본 3000 |
| `DATA_DIR` | SQLite 파일 위치. 배포 시 영구 디스크 경로로 지정 |
| `BASE_PATH` | 브릿지노드 도메인 하위 경로로 붙일 때만 (예: `/chaeum`). 독립 도메인/서브도메인이면 비워 둠 |
| `ADMIN_USER`, `ADMIN_PASSWORD` | 첫 실행 때 만들 관리자 계정 |

## 연결 방식

- 서브도메인 권장: `chaeum.bridgenode.co.kr` → 이 서버. 상단 띠의 "브릿지노드 홈" 링크는 관리자 설정에서 바꿉니다.
- 하위 경로: 브릿지노드 서버(리버스 프록시)에서 `/chaeum/*`를 이 서버로 넘기고 `BASE_PATH=/chaeum`.

## 자동화

관리자 > 사이트 설정 > 웹훅 주소에 Zapier/Make/Slack 웹훅을 넣으면 새 신청과 문의가 JSON으로 전송됩니다. 카카오 알림톡, 문자, 구글 시트 기록 등으로 연결하세요.
