# 정우회 회원 플랫폼

기업가 대표 모임 **정우회**의 회원명부·가디언(추천인)·임원진·행사·연혁을 관리하는 대시보드.

- 기획서: [`docs/PLAN.md`](docs/PLAN.md)
- 초기 회원명부: [`data/members_seed.csv`](data/members_seed.csv)

## 실행
설치 없이 `index.html`을 브라우저로 열면 됩니다. (GitHub Pages / Render 정적 사이트로 그대로 배포 가능)

## 현재 버전 (1단계 MVP 프로토타입)
| 메뉴 | 기능 |
|---|---|
| 대시보드 | 전체 회원, 올해 신규 입회, 현 임원, 다음 행사 D-day, 월별 입회 추이, 가디언 TOP 5, 최근 입회, 다가오는 행사 |
| 회원명부 | 표/카드 보기, 이름·회사·제품 검색, 구분·입회연도 필터, 엑셀(CSV) 내보내기, 회원 등록 |
| 회원 상세 | 소개 카드 레이아웃(사진·회사 이미지·출생연도·명함·제품·입회연도·추천회원), 추천한 회원, 직책 이력 |
| 가디언 | 추천 횟수 자동 집계 랭킹, 추천 계보 트리 |
| 임원진 | 직책별 현 임원, 직책 지정·변경·해제(이전 직책 자동 이력화), 직책 목록 설정 |
| 행사 | 연도별 행사, 문구·공지 보관/복사, 서류 링크(구글드라이브 등), 내년으로 복제 |
| 연혁 | 연도별 타임라인, 임원 취임 자동 기록 |
| 관리·백업 | 엑셀(CSV) 일괄 등록, JSON 백업/복원 |

> 데이터는 현재 **브라우저(localStorage)** 에 저장됩니다. 여러 회원이 같은 데이터를 보려면 2단계에서 Supabase로 연결합니다 (`index.html`의 `Store.load/save`만 교체).
