# (가칭)기업정책지원사업 — MVP

대표님이 앱에서 **기업상태를 체크**하면 → 맞는 **정책자금을 매칭**해 보여주고 →
직접 하기 어려우면 **정책지원마스터 도움 신청(폼 + 개인정보 동의)** 으로 DB에 쌓이고 →
앱을 설치한 분들에게는 **매주 새 정책자금 공고를 푸시 알림**으로 보내는 앱입니다.

1인 운영자가 손을 덜 쓰도록 **공고 수집·알림 발송·신청 알림·개인정보 파기를 자동화**하는 데 초점을 맞췄습니다.

---

## 1. 사용자 흐름

```
[홈] ─▶ [기업상태 진단 4단계·12문항] ─▶ [결과: 추천 자금 + 지역 공고]
                                            │
                    ┌───────────────────────┼────────────────────────┐
                    ▼                                                ▼
     [정책지원마스터 도움 신청 폼]                          [주간 알림 설정]
      · 도움 항목 / 관심 자금 / 연락처                       · 관심 지역·분야 선택
      · 개인정보 수집·이용(필수)                             · 웹푸시 구독
      · 제3자 제공(선택) · 마케팅 수신(선택)                  · 매주 월 09:00 맞춤 공고 발송
                    │
                    ▼
     DB 저장 + 동의 이력 + 웹훅(카톡/슬랙/구글시트)  ─▶  [관리자 /admin] 상태관리·메모·CSV
```

| 화면 | 내용 |
|---|---|
| 진단 | 사업자 유형, 업종, 지역 / 업력, 상시근로자, 매출 / 대표 연령, 여성·수출·매출감소·폐업이력, 인증(특허·벤처·이노비즈·메인비즈·연구소) / 자금 용도·금액, 신용, 체납·연체 |
| 결과 | 소진공·중진공·신보·기보·지역신보·지자체 이차보전 등 12개 자금을 **적합도 점수 + 추천 사유**로 정렬, 체납/연체 경고, 지역 진행 공고 |
| 신청 | 진단 결과와 자동 연결(관리자가 진단 내용을 보고 바로 상담 가능), 스팸 방지(허니팟·요청 제한) |
| 알림 | PWA 설치 후 웹푸시. 안드로이드/PC 크롬 바로 지원, 아이폰은 iOS 16.4+ **홈 화면에 추가** 후 지원 |

## 2. 수집되는 DB

| 테이블 | 용도 | 개인정보 |
|---|---|---|
| `diagnoses` | 진단 응답·결과 (익명 기기ID) | 없음 |
| `leads` | 상담 신청 (성함·연락처·상호·관심자금·상태·메모·**파기예정일**) | 있음 |
| `consents` | 동의 이력 (항목·동의여부·약관버전·시각·IP) — 분쟁 시 증빙 | 있음 |
| `programs` | 수집한 정책자금 공고 | 없음 |
| `push_subscriptions` | 알림 구독 + 관심 지역/분야 | 기기 토큰 |
| `notification_logs` | 발송 결과 | 없음 |

기본은 SQLite 파일(`data/app.db`) 하나라 백업이 쉽습니다. 규모가 커지면 `docs/schema.sql`로 Supabase에 옮기면 됩니다.

## 3. 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
```

```bash
cp .env.example .env
```

```bash
npm run vapid
```
출력된 두 줄을 `.env`에 붙여넣고 `ADMIN_TOKEN`을 길고 랜덤한 값으로 바꿉니다.

```bash
npm start
```

- 앱: http://localhost:3000
- 관리자: http://localhost:3000/admin (ADMIN_TOKEN으로 로그인)
- 테스트: `npm test`

`BIZINFO_API_KEY`가 비어 있으면 예시 공고(`data/mock-programs.json`)로 동작합니다.
[기업마당](https://www.bizinfo.go.kr) → 정책정보 개방 → API 신청으로 무료 키를 받아 넣으면 실제 공고가 수집됩니다.

## 4. 자동화 포인트 (1인 운영용)

| 자동화 | 방법 |
|---|---|
| 공고 수집 + 주간 알림 | 서버 내장 스케줄러가 **매주 월 09:00(KST)** 실행 (`WEEKLY_CRON`으로 변경). 외부 스케줄러를 쓰려면 `npm run weekly` |
| 신규 신청 즉시 알림 | `LEAD_WEBHOOK_URL`에 Zapier/Make/n8n/슬랙 웹훅을 넣으면 신청마다 JSON 전송 → 카톡·문자 알림, 구글시트 적재, CRM 등록 |
| 신청 관리 | `/admin`에서 상태(신규→연락완료→진행중→완료) · 메모 · 진단 요약 확인 · 엑셀 CSV 다운로드 |
| 개인정보 파기 | `npm run purge`를 매일 실행하면 보유기간(기본 3년)이 지난 신청 자동 삭제 |
| 성과 지표 | 관리자 상단: 최근 7일 진단·신청 수, **진단→신청 전환율**, 구독자 수 |

## 5. 배포 (권장)

- **Render / Railway / Fly.io**: Node 서버 1개 + 영구 디스크(`DB_PATH`)를 연결합니다. 웹푸시와 PWA 설치는 **HTTPS가 필수**인데, 이 서비스들은 기본으로 제공합니다.
- **구글플레이 출시**: [docs/google-play.md](docs/google-play.md) 단계별 가이드 참고 (TWA 방식, 웹 수정 시 앱 자동 반영)

## 6. 운영 전 체크리스트 (중요)

- [ ] `server/catalog.js`의 자금 조건·한도를 **매년 1월 공고 기준으로 갱신**
- [ ] `public/privacy.html`의 보호책임자, 위탁업체(호스팅사 등) 기재
- [ ] 제3자 제공 시에는 **제공받는 자를 구체적으로** 기재 (현재는 "협력 기관" 일반 문구)
- [ ] 정책자금 **제3자 부당개입** 관련 유의: 중진공·소진공 등은 브로커의 "승인 보장", "기관 사칭", "과도한 성공보수"를 금지·제재합니다. 앱 문구에 승인 보장 표현을 쓰지 말고, 수수료가 있다면 계약 전에 명확히 고지하세요. (신청 폼 하단에 기본 고지 문구가 들어가 있습니다.)
- [ ] 사업자번호 진위확인(국세청 API) 추가 검토
