# 채움기업컨설팅관리대시보드

채움파트너스 고객사의 기본정보·진행업무·접촉이력·인증·보험·연도별 재무·차년도 목표를 한 화면에서 관리하는 컨설턴트용 대시보드입니다.
**노션이 원본 데이터**이고, 대시보드는 노션을 읽고 씁니다. 노션에서 입력하면 대시보드에 나타나고, 대시보드에서 추가·수정·삭제하면 노션에 반영됩니다.

- 기획서: [`docs/01-기획서.md`](docs/01-기획서.md)
- 노션 프로젝트 홈: 채움파트너스 › 채움기업컨설팅관리대시보드

## 지금 되는 것 (P1 · UI v3 Light Consulting Workspace)

| 화면 | 내용 |
|---|---|
| 오늘 | 오늘 처리할 일·지난 일·연락 필요 업체(누르면 해당 필터), 빠른 작업 4개, 핵심 지표 2×2, 우선 처리할 일, 최근 활동 |
| 할 일 | 다음 액션·후속조치·30일 미접촉·90일 내 보험 만기를 급한 순으로. 필터(전체·지금·연락 필요·보험 만기·예정), 기록·완료 |
| 업체 | 검색(이름·대표자·전화·사업자번호), 진행 단계·업무·우선순위 필터, 정렬, 목록/표, 전화·문자·기록 |
| 업체 상세 | 진행 단계 표시줄, 다음 액션(완료·변경), 탭: 개요·활동·재무·정책자금·인증·보험·문서·로드맵·AI 매칭 |
| 일정 | 월 달력 + 날짜별 목록(다음 액션·후속조치·보험 만기·인증 만료·공고 마감) |
| 더보기 | 할 일, 업체 관리, 연계 대시보드, 노션 연결 점검, 로그아웃 |
| + 등록 | 신규 업체 / 접촉 기록 / 할 일·일정(다음 액션). 업체 화면에서는 그 업체로 바로 연결 |

- 별도 할 일·일정 DB는 없습니다. 노션의 다음 액션, 후속조치, 보험 만기일, 인증 만료일, 공고 마감일에서 계산합니다.
- 할 일 '완료': 후속조치는 노션 '후속완료' 체크, 다음 액션은 비워집니다(새 다음 액션을 정하라는 의미).
- 모바일 하단 탭(오늘·업체·등록·일정·더보기), 1024px 이상은 왼쪽 사이드바. 홈 화면에 추가하면 앱처럼 실행됩니다.

## 처음 연결하기 (약 10분)

### 1. 노션 통합(Integration) 만들기
1. https://www.notion.so/profile/integrations → **새 통합 만들기**
2. 이름 `채움 대시보드`, 유형 **내부(Internal)**, 기능: 콘텐츠 읽기·업데이트·삽입 체크
3. 만들어진 **내부 통합 시크릿**(`ntn_…`)을 복사 → 이것이 `NOTION_TOKEN`

### 2. 노션 페이지에 통합 연결
노션에서 **채움기업컨설팅관리대시보드** 페이지 → 오른쪽 위 `···` → **연결** → `채움 대시보드` 추가.
하위 데이터베이스 8개에 모두 적용됩니다. 이 단계를 빠뜨리면 대시보드에 “데이터베이스를 찾을 수 없습니다”가 뜹니다.

### 3. 배포 (Vercel 권장, 무료)
1. https://vercel.com → GitHub로 로그인 → **Add New Project** → 이 저장소 선택
2. **Environment Variables**에 아래 3개 입력 → Deploy

| 이름 | 값 |
|---|---|
| `NOTION_TOKEN` | 1단계에서 복사한 시크릿 |
| `ADMIN_PASSWORD` | 로그인 비밀번호(길게) |
| `SESSION_SECRET` | 아무 문자열 32자 이상 (예: 비밀번호 생성기로 40자) |

배포 주소(예: `chaeum-xxx.vercel.app`)로 PC·휴대폰 어디서나 접속합니다. 도메인은 Vercel 설정에서 연결할 수 있습니다.

### 4. 연결 확인
로그인 후 주소 뒤에 `/check`를 붙여 엽니다(관리자 화면의 ‘노션 연결 점검’ 버튼도 같음). 데이터베이스 8개가 모두 **정상**이면 끝입니다.
‘확인 필요’가 나오면 이유(권한 없음, 속성 이름 바뀜 등)가 함께 표시됩니다. 노션 연결이 실패해도 이 화면은 항상 열립니다.

## 내 컴퓨터에서 실행

```bash
npm install
```

```bash
npm run dev
```

http://localhost:3000 — `NOTION_TOKEN`이 없으면 **데모 모드**(예시 업체 5곳)로 열리고, 개발 모드 비밀번호는 `chaeum`입니다.
노션과 연결하려면 `.env.example`을 `.env.local`로 복사해 값을 채웁니다.

```bash
npm test         # 계산·노션 변환·로그인 테스트
npm run build    # 배포용 빌드
```

## 구조

| 경로 | 내용 |
|---|---|
| `src/lib/schema.ts` | 노션 DB ID·속성 이름·선택지. **노션에서 속성 이름을 바꾸면 이 파일만 고칩니다** |
| `src/lib/notion.ts` | Notion API(2025-09-03) 호출, 속성 ↔ 값 변환 |
| `src/lib/repo.ts` | 읽기(1분 캐시)·쓰기. 토큰 없으면 데모 데이터 |
| `src/lib/derive.ts` | 최근 접촉·미접촉·할 일·KPI 계산(순수 함수) |
| `src/lib/session.ts`, `src/middleware.ts` | 관리자 로그인(서명 쿠키 30일) |
| `src/app/` | 화면(Next.js App Router) |

## 보안 메모
- 모든 화면은 로그인 후에만 열립니다. 노션 토큰은 서버에만 있고 브라우저로 전달되지 않습니다.
- 삭제는 노션 휴지통 이동이라 30일 안에 노션에서 복구할 수 있습니다.
- 검색엔진 수집을 막아 두었습니다(`noindex`).
