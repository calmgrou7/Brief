# 브루노트커피 홍보 쇼츠 대본 (36초 = 본편 29초 + 엔딩 7초)

- 앱: 브루노트커피 (토스 미니앱, 브라운리) · "내 취향의 한 잔을 기록하는 레시피" / 앱 안 문구 "오늘의 한 잔, 내 취향대로."
- 타깃: 집에서 커피를 내려 마시는 홈카페족
- 콘셉트: "어제 맛있던 그 비율, 기억 안 나죠?"라는 공감 → 기록하면 매번 같은 맛
- 톤: 앱과 같은 짙은 초록·크림·골드, 고운바탕 서체, 직접 그린 아이스 라떼 잔(움직이는 마블링, 얼음, 붓기)
- 1080×1920 · 30fps · 오리지널 로파이 사운드(저작권 걱정 없음)
