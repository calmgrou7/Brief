# 한장견적 홍보 쇼츠 기획서

## 1. 핵심 메시지
> **"견적서, 이제 노트북 없이 토스에서 바로."**

| 항목 | 내용 |
|---|---|
| 앱 | 한장견적 (토스 미니앱, 브라운리) |
| 기능 근거 | 견적서 작성 → 발송 → 수락 → 미입금 → 완료 관리, 사업자 정보 1회 등록, 무료 플랜 월 5건 |
| 차별점 | 앱 설치 없이 토스에서 바로 실행 |
| 타깃 | 현장에서 견적 요청을 받는 1인 사업자·프리랜서 (인테리어/시공, 촬영, 디자인, 출장 서비스, 공방) |
| 페인포인트 | 견적 하나 보내려고 PC 켜기 → 엑셀 양식 찾기 → 금액 계산 → PDF 변환 → 메신저 전송 |

## 2. 영상 구성 (26초 · 1080×1920 · 30fps)

| 시간 | 장면 | 화면 문구 | 목적 |
|---|---|---|---|
| 0–3.4초 | 훅 | 고객 메시지 "사장님, 견적서 오늘 받을 수 있을까요? 🙏" / **견적서 하나 보내려고 또 노트북 켜세요?** | 첫 프레임부터 문구가 떠 있어 스크롤을 멈추게 함 |
| 3.4–7초 | 공감 | 견적 하나 보낼 때마다: 엑셀 양식 찾기 · 금액 다시 계산 · PDF로 변환 · 메신저로 전송 → 줄 긋기 → **이제 그만.** | 번거로움 공감 |
| 7–9.8초 | 등장 | 앱 아이콘 + **한장견적** / 토스에서 바로 쓰는 견적서 | 브랜드 각인 |
| 9.8–13.2초 | 기능 1 | **견적서부터 영수증까지** + 상태 태그(작성/발송/수락/미입금/완료), 실제 화면 + 현황 카드 강조 | 문서 관리 |
| 13.2–16.4초 | 기능 2 | **사업자 정보는 한 번만** / 상호·사업자번호를 견적서에 자동 표시 | 반복 작업 제거 |
| 16.4–19.6초 | 기능 3 | **매월 5건 무료** / 부담 없이 지금 바로 시작 | 시작 부담 낮추기 |
| 19.6–22.6초 | 장점 | 다운로드? 필요 없어요 ✔ 앱 설치 없이 ✔ 토스에서 바로 ✔ 폰 하나로 끝 | 핵심 차별점 |
| 22.6–26초 | CTA | 토스 앱에서 검색하세요 → 검색창에 "한장견적" 타이핑 → [지금 바로 견적 쓰기] / 바로가기 링크는 설명란에 👇 | 행동 유도 |

> 앱 화면은 토스 미니앱 스토어에 올라간 공식 스크린샷 3장을 썼어요. 실제 견적서 PDF 결과물 화면이 있으면 기능 1을 그 화면으로 바꾸는 게 전환에 가장 좋아요.

## 4. 사운드
영상에 오디오는 넣지 않았어요. 업로드할 때 **쇼츠 앱에서 인기 음원을 직접 넣는 걸 추천해요** (알고리즘 노출에 유리하고 저작권 걱정이 없어요). 차분한 로파이나 경쾌한 비트가 잘 맞아요.

## 5. 다음 단계 (재사용·자동화)
- `scene.html`의 문구만 바꾸고 `node render.js 파일명.mp4`를 실행하면 30초 안에 새 버전이 나와요. 훅 A/B 테스트에 바로 쓸 수 있어요.
- 추천 훅 변형:
  - A (현재): "견적서 하나 보내려고 또 노트북 켜세요?"
  - B: "고객이 견적 달라는데 지금 밖이라면?"
  - C: "견적서 보내는 데 몇 분 걸리세요?"
- 같은 영상을 그대로 인스타 릴스와 틱톡에도 올릴 수 있어요 (9:16, 26초).
- 업종별 버전(인테리어/촬영/디자인)은 훅 문구와 고객 메시지만 바꾸면 돼요.
