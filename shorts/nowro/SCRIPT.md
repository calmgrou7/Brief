# 나우로 부산 홍보 쇼츠 대본 (38.5초 = 본편 31.5초 + 엔딩 7초)

- 앱: 나우로 부산 (토스 미니앱, 브라운리) · "오늘의 부산 축제부터 전시까지 한눈에" / 앱 안 문구 "바다와 골목, 오늘의 부산."
- 콘셉트: **부산의 하루를 빠르게 보여주고(바다 → 골목 → 밤 공연), "그걸 어떻게 다 찾지?"를 앱으로 해결**

- 앱 부분은 아이콘과 같은 검정과 라임색. 엔딩은 브릿지노드 다크 버전
- 1080×1920 · 30fps · 오리지널 시티팝 풍 사운드(저작권 걱정 없음)
