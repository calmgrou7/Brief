# 쇼츠 제작 명령어 매뉴얼

녹음 파일을 첨부하고 아래 형식으로 한 줄만 보내주시면 됩니다.

## 1. 기본 명령어 (이것만 기억하세요)

```
/쇼츠 [브랜드] [번호] [스타일]
```

예시
```
/쇼츠 벤처 VS_04 인포
/쇼츠 벤처 VS_05 일러스트
/쇼츠 보험 IN_01 카드
```

말로 하셔도 됩니다: "벤처 4번, 인포그래픽으로 만들어줘"

## 2. 항목별 선택지

### 브랜드
| 입력 | 의미 | 번호 규칙 |
|---|---|---|
| 벤처 | 벤처의 기준 (벤처기업확인 컨설팅) | VS_01, VS_02 … |
| 정책 | 정책자금 | PF_01 … |
| 보험 | 지혜로운 보험생활 · 보험지기 | IN_01 … |

### 스타일
| 입력 | 모습 | 어울리는 주제 | 샘플 |
|---|---|---|---|
| 카드 | 네이비·골드, 큰 글씨 카드 | 의뢰 유도, 업무·비용 안내, 사전검토 | VS_01 |
| 인포 | 밝은 종이 바탕, 그래프·도표 | 판단 기준, 원인 분석, 비교 | VS_02 |
| 일러스트 | 대표님·'기준이' 캐릭터, 동화풍 | 놓치기 쉬운 상황, 일정·주의사항 | VS_03 |

스타일을 비워두면 주제를 보고 제가 고릅니다.

## 3. 선택 옵션 (필요할 때만 덧붙이기)

| 옵션 | 쓰는 법 | 효과 |
|---|---|---|
| 제목 | `제목: 만료일 놓치면 생기는 일` | 상단 고정 제목 지정 (없으면 원고에서 뽑음) |
| 마무리 | `마무리: 고정댓글` | CTA 문구를 "프로필 링크" 대신 "고정 댓글 링크"로 |
| 강조 | `강조: 3년, 재확인` | 자막에서 색으로 강조할 단어 |
| 크기 | `크기: 1x1` / `크기: 둘다` | 정사각형(1080×1080) 버전 추가. 기본은 세로 9:16 |
| 음악 | `음악: 잔잔` / `음악: 없음` | 배경음 추가 여부 |
| 스레드 | `스레드: 같이` | 영상과 함께 Threads 업로드 문구 작성 |
| 원고 | `원고: 같이` | 녹음 전에 대본부터 받기 |

예시
```
/쇼츠 벤처 VS_04 일러스트 제목: 3년 전에 됐으니 이번에도? 스레드: 같이
```

## 4. 수정 명령어

영상 받은 뒤 고칠 곳만 짧게 말씀해 주세요.

```
/수정 VS_04 12초 자막 "재확인"으로
/수정 VS_04 캐릭터 표정 더 밝게
/수정 VS_04 글자 크게
/수정 VS_04 싱크 0.3초 늦게
```

## 5. 원고·문구만 필요할 때

```
/원고 벤처 재확인 2편          → 녹음용 대본만
/스레드 VS_04                  → Threads 업로드 문구만
/주간 벤처                     → 이번 주 올릴 주제 3개 + 원고
```

## 6. 녹음 파일 규칙

- 파일 이름: `VS_04.m4a` 처럼 번호로 저장하면 가장 정확합니다.
- 문장 사이 0.5초 쉬기 → 자막이 정확하게 끊깁니다.
- 원고를 조금 다르게 읽으셔도 괜찮습니다. 녹음 내용을 기준으로 자막을 맞춥니다.
- 녹음 앞뒤의 "아", 빈 구간은 자동으로 잘라냅니다.
