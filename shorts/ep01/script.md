# 벤처 심사실 EP.01 — 「벤처기업 인증, 뭐가 좋은데?」

- 형식: 세로 쇼츠 1080×1920, 약 40초, 카드 8장 + 픽셀 캐릭터 + 8비트 BGM
- 대상: 1인 대표, 창업 3년 안쪽 대표
- 목표: 벤처인증 '혜택'으로 관심을 끌고 → '4개의 문' 구조를 보여준 뒤 → 다음 편(혁신성장 유형)으로 이어보기

## 등장 캐릭터 (오리지널)

| 캐릭터 | 생김새 | 역할 |
|---|---|---|
| 대표 | 검정 터틀넥, 짧은 검은 머리 | 진행자, 질문하는 역할 |
| 투자 매니저 | 남색 수트, 금색 넥타이 | 벤처투자 유형 |
| 연구소장 | 회색 곱슬머리, 동그란 안경, 실험복 | 연구개발 유형 |
| 혁신 심사위원 | 빨간 캡, 초록 후드 | 혁신성장 유형 |
| 예비 창업자 | 민트 비니, 노란 티, 백팩 | 예비벤처 |
| 세무 담당 | 올림머리, 베이지 조끼, 계산기 | 세금 혜택 |
| 행정 담당 | 긴 머리, 핑크 가디건, 클립보드 | 신청 절차 |

## 업로드 문구 (쓰레드·릴스·쇼츠 공용)

```
벤처기업 인증, 투자 받은 스타트업만 받는 거라고 생각했나요?
들어가는 문은 4개, 하나만 통과하면 됩니다.
1인 대표라면 '혁신성장 유형'부터 확인해 보세요.

다음 편 → 1인 기업도 되는 혁신성장 유형

#벤처기업 #벤처인증 #1인기업 #1인대표 #창업지원 #정책자금 #절세
```

## 사실 확인 메모 (올리기 전에 최신 기준과 대조하기)

- 벤처투자 유형: 적격 투자자에게 받은 투자 5천만 원 이상, 자본금 대비 투자금액 10% 이상
- 연구개발 유형: 기업부설연구소 등 보유, 연간 연구개발비 5천만 원 이상, 업종별 매출 대비 연구개발비 비율, 사업성 평가
- 혁신성장 유형: 기술의 혁신성과 사업의 성장성 평가 우수
- 예비벤처: 법인 설립이나 사업자등록을 준비 중인 사람
- 유효기간 3년
- 세금 감면: 조세특례제한법 제6조(창업벤처중소기업) 50% 5년, 지방세특례제한법(취득세·재산세). 감면율과 일몰 시점은 매년 세법 개정으로 바뀔 수 있음
