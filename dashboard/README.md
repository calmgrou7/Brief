# 브릿지노드 총괄 관리 대시보드

미니앱 · 웹앱 · 토스 인앱 프로젝트를 **기획 단계부터 출시 후 운영까지** 한 화면에서 관리하는 대시보드입니다.
서버·빌드 없이 `index.html` 파일 하나로 동작합니다.

## 실행
`dashboard/index.html`을 브라우저(Chrome/Edge/Safari)로 열면 됩니다. 처음에는 예시 데이터가 보이며,
[백업·설정 → 예시 데이터 비우고 시작]으로 실제 데이터를 등록하세요.

## 탭 구성
| 탭 | 내용 |
|---|---|
| 개요 | 전체 진행률, 미니앱/웹앱/토스 인앱별 진행률·상태 수, **다음 절차**(자동 집계), 전체 파이프라인 |
| 프로젝트 | 단계 버튼을 눌러 완료 처리 → 진행률·상태 자동 계산. 다음 절차·기간·URL·메모 |
| 출시·업데이트 | 버전별 기록(최초 출시/업데이트/핫픽스), 검수 상태(준비중→검수요청→검수중→반려/승인→출시완료), 배포 서버, **n차 업데이트** 자동 계산 |
| 도메인·서버 | 도메인 만료일 D-day(60일 노랑/30일 빨강), SSL 만료, 자동갱신 여부, 서버 비용·갱신일 |
| 계정 보관함 | 토스 콘솔·도메인·서버·스토어 계정 ID/비밀번호를 마스터 비밀번호로 암호화 보관 |
| 백업·설정 | JSON 백업/복원, 출시 이력 병합 가져오기, 초기화 |

## 프로젝트 상태 판정 규칙 (자동)
- 보류 체크 → **보류**
- 최근 기록이 검수요청/검수중 → **검수중**, 반려 → **반려 대응**
- 출시완료 기록 1건 이상 + 모든 단계 완료 → **출시·운영중**
- 첫 단계(기획) 미완료 → **기획중**, 그 외 → **진행중**

## 보안
- 데이터는 이 브라우저의 localStorage에만 저장됩니다 (외부 전송 없음).
- 계정 보관함: PBKDF2-SHA256(310,000회) → AES-GCM 256 암호화. 마스터 비밀번호는 저장되지 않으며 **분실 시 복구 불가**.
- 10분간 미사용 시 자동 잠금. 백업 파일에도 암호문만 포함됩니다.
- 백업 JSON은 공개 저장소에 커밋하지 마세요.

## 자동화 연동 (출시 이력 병합)
토스 콘솔(앱인토스)의 심사 상태는 현재 수동 입력입니다. 배포 스크립트/CI가 아래 JSON을 생성해
[가져오기]하면 이력이 병합됩니다(같은 프로젝트+버전은 갱신).

```json
{ "releases": [
  { "projectName": "동네가게 예약", "version": "1.2.1", "kind": "update",
    "status": "requested", "date": "2026-11-02", "server": "NCP Prod #1",
    "buildNo": "24", "note": "버그 수정" } ] }
```
`status`: `prep` | `requested` | `review` | `rejected` | `approved` | `released`
`kind`: `first` | `update` | `hotfix`
