# 숨결 · 광고 쇼츠 기획안

## 1. 제품 한 줄
**"빛과 소리를 따라 나에게 맞는 호흡"** — 앱 설치 없이 토스에서 바로 여는 호흡 가이드 미니앱.

스크린샷으로 확인한 기능
| 기능 | 화면 |
|---|---|
| 오늘의 호흡 찾기 — 기분과 여유 시간으로 나에게 맞는 호흡 | 홈 "잠깐, 숨을 고를 시간" |
| 마음 상태 고르기: 화가 나요 / 긴장돼요(발표·면접·중요한 통화 전) / 불안하고 답답해요 / 머리가 복잡해요 / 잠이 안 와요 / 그냥 숨 고르고 싶어요 | "지금 마음이 어떤가요?" |
| 상황에 맞는 호흡 추천 | "지금 당신에게 필요한 호흡" |
| 원이 커지고 작아지는 대로 따라 쉬는 호흡 세션, 음성 안내·배경 음악 | "들이쉬기 5.5초" |
| 1·3·5·10·20분 선택 | "공명 호흡" |

## 2. 타깃과 상황
- **주 타깃:** 발표·면접·중요한 통화 직전처럼 **긴장되는 순간**의 직장인·취준생 (앱의 "긴장돼요" 항목과 일치)
- **보조 타깃:** 잠이 안 오는 밤, 머리가 복잡한 사람

## 3. 핵심 메시지
1. **지금 마음을 고르면, 맞는 호흡을 골라줘요**
2. **원을 따라 쉬기만 하면 돼요** (빛과 소리)
3. **앱 설치 없이 토스에서 바로, 1분이면 충분**

## 4. 크리에이티브 핵심: "광고가 같이 숨을 쉰다"
- 중반부에 화면 전체가 앱 세션처럼 바뀌고, 큰 원이 **실제로 한 번 들이쉬고 내쉬는 속도로** 커지고 작아짐 → 시청자가 광고 안에서 제품을 체험
- 앞뒤는 라인아트 일러스트 (HERITAGE STUDIO B 시리즈 톤), 색은 앱 브랜드의 크림 `#F7EEDD` · 테라코타 `#A9502F` · 올리브 `#6E7F3A`
- 다른 광고보다 템포를 늦춤: 컷 수를 줄이고 전환을 부드럽게
- 길이 약 24초

## 5. 스토리보드
| # | 시간 | 화면 | 자막 |
|---|---|---|---|
| 1 훅 | 0–3초 | 노트북 앞 사람, 어깨가 잔뜩 올라가 있고 "발표 5분 전" "답장 주세요" 쪽지가 몰려듦 | 발표 5분 전, **숨이 턱 막힐 때** |
| 2 마음 고르기 | 3–6초 | 폰: "내게 맞는 호흡 찾기" → "지금 마음이 어떤가요?"에서 "긴장돼요" 탭 | 지금 **마음을 고르면** |
| 3 추천 | 6–9초 | 폰: "지금 당신에게 필요한 호흡" → "이 호흡 시작하기" 탭 | 나에게 맞는 호흡을 **골라줘요** |
| 4 같이 숨쉬기 | 9–16초 | 화면 전체가 짙은 갈색, 큰 원이 들이쉬기(커짐)–내쉬기(작아짐) 한 번 | 같이 한 번, **숨 쉬어볼까요?** / 원 안: 들이쉬기 → 내쉬기 |
| 5 변화 | 16–19초 | 같은 사람, 어깨가 내려가고 쪽지가 잎사귀로 바뀌어 날아감 | 단 1분, **숨 고르는 시간** |
| 6 CTA | 19–24초 | 크림 배경, 앱 아이콘, 버튼 | **숨결** · 토스에서 '숨결' 검색 |

## 6. 문구 원칙
- 의학적 효과(불안 해소·치료 등)는 말하지 않음. "숨 고르는 시간"처럼 행동만 말함
- 앱 화면은 실제 스크린샷 사용
- CTA 하나: **토스에서 '숨결' 검색**
