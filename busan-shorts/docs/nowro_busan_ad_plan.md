# 나우로 부산 · 광고 쇼츠 기획안

## 1. 제품 한 줄
**"오늘의 부산 축제부터 전시까지 한눈에"** — 앱 설치 없이 토스에서 바로 여는 부산 여행 가이드 미니앱.

앱 스크린샷으로 확인한 핵심 기능
| 기능 | 화면 | 광고에서 보여줄 장면 |
|---|---|---|
| 날짜별 행사 모아보기 (축제·공연·전시·체험) | 홈 "바다와 골목, 오늘의 부산." | 날짜를 고르면 오늘 행사가 쭉 |
| 지도에서 행사 위치 보기 + 길찾기 | "지도에서 만나는 오늘" | 지도에 핀이 톡톡 떨어짐 |
| 오늘 코스 만들기 (최대 4곳 선택, 안 고르면 자동 추천) | "오늘 코스 만들기" | 자동 추천 → 코스 생성 |
| 이동 코스 (시간·대중교통) | "가까운 코스" | 핀 사이로 동선이 그려짐 |

## 2. 타깃과 상황
- **주 타깃:** 부산에 놀러 온 2030 여행자 — 도착은 했는데 "오늘 뭐 하지?"인 사람
- **보조 타깃:** 주말에 갈 곳을 찾는 부산 시민
- **문제 상황:** 축제·전시·공연 정보가 여기저기 흩어져 있어 검색만 하다 시간이 감. 여행 앱을 또 깔기도 귀찮음.

## 3. 핵심 메시지 (우선순위)
1. **앱 설치 없이, 토스에서 바로** — 진입 장벽 제거 (가장 강한 차별점)
2. **날짜만 고르면 오늘의 부산 행사가 한눈에**
3. **고르기만 하면 코스까지 자동으로**
