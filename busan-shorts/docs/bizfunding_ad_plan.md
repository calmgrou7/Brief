# 기업정책지원사업 · 광고 쇼츠 기획안

## 1. 제품 한 줄
**"우리 회사에 맞는 지원사업 찾기"** — 앱 설치 없이 토스에서 바로 여는 지원사업 공고 찾기 미니앱 (민간 서비스).

스크린샷으로 확인한 기능
| 기능 | 화면 |
|---|---|
| 우리 회사 조건 설정 (지역·업종·규모·관심분야, 기기에 저장) | 홈 "우리 회사에 맞는 지원사업을 찾아보세요" |
| 기업 규모·관심 지원분야·접수기간으로 맞춤 조회 | 필터 → "맞춤 지원사업 보기" |
| 공식 API 수집 공고 목록, 기간 지난 공고 제외 옵션 | "전체 공고 검색 결과" |
| 공고 요약, 원문 확인 안내 | 공고 상세 |
| 맞춤 조회 결과, 관심사업 저장 | "우리 회사에 맞는 공고" |
| 검토할 사업을 메일이나 PDF로 정리 | 홈 안내 문구 |

## 2. 타깃과 상황
- **주 타깃:** 1인 사업자·소상공인·초기 스타트업 대표. 지원사업이 있다는 건 알지만 찾아볼 시간이 없는 사람
- **문제 상황:** 기관마다 공고 사이트가 다르고 조건도 제각각이라 하나씩 확인하다 지치고, 놓치기 쉬움

## 3. 핵심 메시지
1. **조건만 정하면 우리 회사에 맞는 공고만** 모아 보여줌
2. **관심사업 저장, 메일·PDF 정리**까지 한곳에서
3. **앱 설치 없이 토스에서 바로**

## 4. 크리에이티브 방향
- 앞부분은 라인아트 일러스트(사장님 책상 위로 공고 창이 쌓임) → 공감으로 시작
- 제품 화면은 실제 스크린샷을 라인아트 폰 안에
- 색: 앱 아이콘의 네이비 `#0F2F55` + 그린 `#00C48C`, 강조 단어는 그린 하이라이트
- 길이 약 23초

| 6 CTA | 18–23초 | 네이비 배경, 아이콘, 버튼 | **기업정책지원사업** · 토스에서 '기업정책지원사업' 검색 |

## 6. 문구 원칙 (중요)
- **"민간 서비스"임을 CTA에 표기** — 정부·공공기관 공식 앱으로 오해하지 않도록
- "지원금 받을 수 있어요", "선정 보장" 같은 결과 약속은 쓰지 않음. 찾기·정리 기능만 말함
- 공고 개수(화면의 1,402개)는 날마다 바뀌므로 자막 숫자로 쓰지 않음
- 실제 기관명은 쓰지 않고 일반 명칭으로 표현
